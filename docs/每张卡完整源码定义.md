## 文件卡片（`Ket`）的完整结构

```jsx
function FilesCard() {
  const card = useCard();
  const scrollRef = useCardScroll(card.id);
  const sessionPath = useStore((s) => s.currentSessionPath);
  const fileCount = useStore((s) => countSessionFiles(s, s.currentSessionPath ?? null));

  const persistedTab = readRendererState(card.rendererState);      // 用户上次选的 tab
  const [fallbackTab, setFallbackTab] = useState(() => defaultTab({ sessionFileCount: fileCount }));
  const activeTab = persistedTab ?? fallbackTab;

  // 有未读文件时，session-files tab 打 marked 角标
  const hasUnread = activeTab !== "session-files" && fileCount > lastSeenCount;
  const tabs = TAB_DEFS.map((t) => t.id === "session-files" && hasUnread ? { ...t, marked: true } : t);

  const drawers = getVisibleDrawers({ currentSessionPath: sessionPath, todos });
  const drawerIds = filterVisible(DRAWER_ORDER, drawerState);

  return (
    <div className={workspaceCardSurface}
         data-workspace-drawers={drawerIds.length > 0 ? drawerIds.length : undefined}
         style={{ "--workspace-drawer-count": drawerIds.length }}>
      <div className={workspaceCardMain}>
        <PreviewTabBar tabs={tabs} activeTab={activeTab} onSelect={(id) => setTab(card, id)} />
        <div className={workspaceCardTabPanel} role="tabpanel">
          <TabContent tab={activeTab} card={card} scrollRef={scrollRef} />
        </div>
      </div>
      {drawerIds.length > 0 && (
        <div className={workspaceDrawerStack}>
          {drawerIds.map((id, index) => (
            <div className={workspaceDrawerLayer} data-workspace-drawer={id}
                 style={{ "--workspace-drawer-index": index }}>
              {DRAWER_COMPONENTS[id]()}
            </div>
          ))}
        </div>
      )}
    </div>
  );
}
```

**三层结构：**

```
workspaceCardSurface          卡容器（管理抽屉层数）
├─ workspaceCardMain          主区
│   ├─ PreviewTabBar          tab 栏（对话文件 / 工作室）
│   └─ workspaceCardTabPanel  内容面板
└─ workspaceDrawerStack       抽屉栈（最多 64% 高）
    └─ workspaceDrawerLayer × N   每层 z-index 递减，负 margin 叠 10px
```

抽屉组件表：

```js
const DRAWER_COMPONENTS = { progress: ProgressDrawer, status: StatusDrawer };
const DRAWER_ORDER = ["progress", "status"];   // IY
```

## 预览卡片（`Ust`）的 chrome

```js
chrome: [
  { id: "chalkboard.preview.tabs",    slot: "titlebar-left",  titlebarTrack: "stretch" },
  { id: "chalkboard.preview.actions", slot: "titlebar-right" },
]
```

**预览卡片的 tab 在 `titlebar-left`**（`titlebarTrack: "stretch"` 表示它拉伸占满左侧）。这和文件卡片的 tab 在卡内不同 —— 预览的 tab 在**顶栏左岛**。

这就是为什么 `rve` 会有左岛：**预览卡片有左岛（tab 栏），chat 和 files 卡片没有。**

## 落地清单（按每张卡）

### chat 卡片（主内容区）
- `data-islands="right"`，无左岛
- chrome 全在 titlebar-right：面板按钮（10/20/25/30）
- `closable: false`，无 × 按钮

### files 卡片（右侧工作区主卡）
- `data-islands="right"`
- 卡内：TabBar（对话文件 / 工作室）+ TabPanel + DrawerStack
- `closable: true`，卡头有 × 按钮
- 抽屉栈最多 64% 高，叠纸效果（-10px margin + z-index 递减）

### preview 卡片
- `data-islands="both"`，**左岛放 tab 栏**（`titlebarTrack: "stretch"`）
- 右岛放 actions
- `closable: true`
- 宽度 320~900，默认 400
