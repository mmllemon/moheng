## 本轮实际验证结果（2026-10-16）

- `npm run validate:release-candidate`：**285 PASS、0 FAIL**，包含静态发布候选、报表工作室、WP2–WP8、审计、架构、后台任务、TS 缺陷契约、UI、导航/XLSX、公网访问安全、现有系统管理/密码和本轮系统扩展共 13 组检查。
- `node scripts/validate-system-expansion-v2.mjs`：20/20 通过。
- 变更/新增的 15 个 TypeScript/TSX 文件使用全局 TypeScript `transpileModule` 做语法解析：15/15 无语法诊断。该检查不等于完整类型检查。
- 独立编译运行新增工具单测：3/3 通过（项目审批角色白名单、AES-256-GCM 上下文绑定、缺失密钥/空凭据拒绝）。它们是隔离的 Node 冒烟测试，不代表完整 `npm test` 已通过。
- `docker-compose.yml` YAML 解析通过；`git diff --check` 通过。
- 完整 `npm run build` 与 `npm run lint` 被 `TS2688` 阻塞（缺少 `@types/node`）；`npm test` 被 `tsx: not found` 阻塞；`npm run db:generate` 被 `prisma: not found` 阻塞。原因是当前运行环境为 Node.js 22.16.0（项目要求 Node.js >=24）且没有安装 `node_modules`。命令与退出码记录在交付包外的环境验证日志中。
- 因此未执行 Prisma schema 校验/客户端生成、真实数据库迁移、真实 PostgreSQL 备份与恢复、完整测试套件、浏览器端 E2E 或公网部署验收。不得把上述项目表述为通过。
