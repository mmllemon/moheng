## 1. 本轮重构范围

本轮将 Pro-Tier 设计规范映射到施工单位成本管理场景，保留既有业务路由、数据接口、API、Prisma Schema、数据库迁移及财务业务规则。

- **材质主题**：新增象牙雅白、香槟曜金、黑曜极光、冰川天青四套 CSS 变量主题，并支持跟随操作系统。旧版深色偏好可映射到黑曜主题。
- **个性化密度**：支持舒朗/紧凑、主题默认/靛青/青玉/朱砂强调色、宽屏内容和减少动效；偏好保存在当前浏览器本地，不写入业务数据库。
- **导航与命令面板**：保留左侧可折叠导航、项目上下文和快捷操作；顶栏入口升级为全局命令面板，支持 Ctrl/Cmd+K、按项目名称/编号或页面名称过滤、↑/↓ 选择、Enter 跳转、Esc 关闭。
- **键盘巡检**：页面空白或表格行拥有焦点时，可使用 J/K 或上下方向键巡检；输入框、选择框、文本区域及可编辑区域不被拦截。聚焦行后 Enter 会触发行内首个按钮/链接或行操作。
- **经营总览**：改为不对称 Bento 区域，左侧展示有效合同额及项目金额对比，右侧展示累计回款和实际成本。图表使用真实的项目当前快照，不合成时间序列，也不声称是完工成本预测。
- **数据呈现**：全局启用等宽数字倾向，统一收敛边框、阴影、状态胶囊和动效时间；增加较低对比的悬浮行分隔及窄屏适配。
- **规范文档**：保留上传的设计规范副本，更新 README、变更日志、操作手册和开发维护指南。

## 3. 暂未完成的发布闸门

当前工作环境为 Node.js 22.x，项目声明要求 Node.js 24+，且没有安装完整工作区依赖。因此以下项目**尚未执行**：

1. 完整 TypeScript `tsc` 类型检查和 API/Web 生产构建；
2. Prisma `validate/generate` 以及真实 PostgreSQL 迁移；
3. 浏览器多主题截图检查、窄屏实机检查、命令面板与表格快捷键端到端回归；
4. Windows 部署环境的完整业务回归。

发布前须在 Node.js 24+、已安装锁定依赖的环境中执行完整构建，并在浏览器中逐一验证四套主题、全局命令面板、表格键盘巡检、竣工结算与应收页面、权限和关键财务流程。当前版本只可视为 **RC 候选**，不得标记为生产验收通过。
