# WP13：成本与系统管理工作台导航重组验收清单 v2.8.0-rc.1

## A. 产品名称和导航

- [ ] 侧栏显示“成本工作台”，不再显示“项目工作台”。
- [ ] 成本工作台的横向业务页签不包含“项目成员与权限”。
- [ ] 侧栏有独立的“系统管理工作台”入口和“项目成员与权限”入口。
- [ ] 系统账号管理入口仅向系统管理员显示；页面/接口仍有真实服务端授权。
- [ ] 系统账号管理不再包含项目角色分配面板，项目角色调整统一在项目成员与权限页处理。

## B. 路由兼容

- [ ] `/cost` 显示项目驾驶舱。
- [ ] `/system` 显示系统管理首页。
- [ ] `/system/members` 仍读取顶部所选项目并使用现有角色管理 API。
- [ ] `/system/accounts` 不依赖项目选择器；旧 `/settings/users` 重定向到新路径并保留 query/hash。
- [ ] `/workspace` 与 `/workspace/<业务子路由>` 重定向到相应 `/cost` 路由，query/hash 保留。
- [ ] `/workspace/members` 重定向到 `/system/members`。
- [ ] 报表预览返回路径、命令面板和快捷入口继续工作。

## C. 权限和数据保护

- [ ] 项目 OWNER/MANAGER/ESTIMATOR/VIEWER 既有权限范围未因换导航改变。
- [ ] 非 ADMIN 用户不能通过系统账号管理页面创建账号；API 继续拒绝未授权请求。
- [ ] 最后一名项目负责人保护、审计记录写入及项目数据范围保持原样。
- [ ] 无 Prisma Schema/migration 或财务金额口径变化。

## D. 环境验收

- 静态候选检查结果填入 `docs/阶段验收记录-v2.8.0-rc.1.md`。
- [ ] Node.js 24+ 环境执行 `npm ci`、`npm run validate:release-candidate`、`npm run lint`、`npm run test`、`npm run build`。
- [ ] 浏览器验证菜单、宽/窄视口、项目切换、成员管理、系统账号权限、旧路由跳转和预览返回。
- [ ] Windows 原生部署验收通过后，方可移除 RC 标识。
