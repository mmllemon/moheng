# 右侧浮层的纸纹层

日期：2026-10-25

## 你的判断对了：卡片外还有一层，那层是纸

hana 的 `Nr` 组件结构：

```jsx
<div className={Ye.floatingPanel} id={k}>
  <div className={`${Ye.floatingPanelInner} ${Pe.tray}`}>
    <Hd />                                  {/* 纸纹层，tray 的第一个子元素 */}
    <div className={Pe.trayHeader}>…</div>
    <div className={Pe.cardStack}>
      <div className={Pe.cardLift}>
        <div className={Pe.card}>…</div>    {/* 卡片，--bg-card */}
      </div>
    </div>
  </div>
</div>
```

`_tray` 就是「卡片外面那层」，它显式声明了两件事：

```css
._tray_8a862 {
  background: var(--bg);                    /* #f8f4ed，比卡片暗 */
  position: relative;
  --paper-texture-surface: var(--bg);       /* 纸纹的底色参照 */
  isolation: isolate;                       /* 让 z-index:-1 的纸纹层不跑出去 */
  border: none;
  box-shadow: 0 8px 32px var(--shadow), 0 2px 8px #0000000a;
}
```

对比：

| 层 | 底色 | 圆角 | 纸纹 |
|---|---|---|---|
| tray（面板） | `--bg` `#f8f4ed` | 无 | **有** |
| card（卡片） | `--bg-card` `#fcfaf5` | 22.09px | 无（叠在纸纹上） |

## moheng 之前为什么看不到

`workspace-panel.css` 里有一段自制纸纹：

```css
.workspace-panel::before {
  background: oklch(from var(--paper-texture-surface) calc(l + 0.02) c h);
  -webkit-mask-image: var(--paper-texture-mottle);
  mask-image: var(--paper-texture-mottle);
}
```

但 **`--paper-texture-mottle` 从未定义**。`mask-image` 为空，`::before` 只剩一层 `oklch` 平涂，没有纹理。

而且它只用了一层 mask，hana 用的是三层（mottle 1024px / fiber 720px / grain 256px）叠加，纹理层次完全不同。

## 修正

删掉自制的 `::before`，改用 `PaperTextureLayer` 组件，挂在 `.workspace-panel` 的第一个子元素（对齐 hana 的 `<Hd />` 位置）：

```jsx
<aside className="workspace-panel" ref={panelRef}>
  <PaperTextureLayer />
  <div className="workspace-resize-handle" />
  …
</aside>
```

`.workspace-panel` 已有 `--paper-texture-surface: var(--bg)` 和 `isolation: isolate`，两个前提都满足。

## 现在三处纸纹用的是同一个组件

```
主内容区    .app-content        → PaperTextureLayer
右侧浮层    .workspace-panel    → PaperTextureLayer
```

侧栏和设置窗的纸纹机制不同（侧栏用三层 mask 合成，设置窗本身没有纸纹层），暂不动。
