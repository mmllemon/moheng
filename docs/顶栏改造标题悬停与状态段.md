# 顶栏改造：标题悬停提示 + 状态段

> 按 Hana 的 `_chatTitleStack` 结构重做 moheng 顶栏。
> 日期：2026-10-23。

## 1. 决策

顶栏只放**短状态**，长说明改为**标题悬停提示**，既不上顶栏也不占页面。

理由（不是「Hana 这么做」，而是实测差异）：

| | Hana 状态段 | moheng subtitle |
| --- | --- | --- |
| 长度 | 2-5 字 | **30-86 字** |
| 性质 | 状态标记（可变） | 业务口径说明（固定） |
| 例子 | `记忆开`、`hana` | `业主侧变更必须关联主合同；内部审批、外部确认和凭证核验分开记录。` |

Hana 的 `width: fit-content` 让标题栈只占内容宽度，前提是内容本身短。
moheng 塞 65 字进去，即使 fit-content 也会占满，挤压右侧图标。


## 6. 过程中修掉的问题

### 问题一：圆点间距变成 8px

第一版给圆点加了 `margin: 0 2px`，实际间距 6 + 2 = 8px。
Hana 是 6px（part 内 gap 6px + status gap 6px）。

去掉 margin 后由 status 的 gap 控制，实测 6.0px 精确对齐。

### 问题二：状态段拼成 "XM-2026-000001项目"

`textContent` 看不出间距，用几何位置测量才确认。圆点确实在中间，只是 margin 让间距偏大。

## 8. 与 Hana 的差异（有意为之）

| 项 | Hana | moheng |
| --- | --- | --- |
| 状态段内容 | 工作区名 · 记忆开关 | 项目编号 · 项目/全公司 |
| 标题双击重命名 | 有 | 无（业务页面标题固定） |
| 标题栏高度 | 28px | 36px（顶栏整体） |

内容不同是因为产品不同：Hana 的「记忆开关」在 moheng 没有对应概念，
moheng 的「项目编号」在 Hana 也没有。**结构对齐，内容按各自业务填。**
