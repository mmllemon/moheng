## 3. 关键改造

### 3.1 样式架构

- 旧 3,058 行 `styles.css` 移入 `styles/legacy.css`，整体包进 `@layer legacy`，并移除 `!important`。
- 新 `styles/v6.css` 不依赖 `!important`，以无 layer 规则覆盖 legacy；`main.tsx` 按 tailwind → legacy → v6 顺序加载。
- 结果：旧页面不用逐页重写也能获得统一的纸/墨/线/字号；新页面可以直接使用 V6 tokens。

### 3.2 品牌与材料

- 42px 朱砂印章（feTurbulence 粗边 + 白色“墨”）；毛笔“墨衡”用 Ma Shan Zheng 子集。
- 宣纸纹理 1024×1024，`multiply`，固定在纸面；不在弹窗/表格内部重复铺。
- 字体自托管：Noto Serif SC 子集 370KB、Spectral 19KB、Ma Shan Zheng 1.9KB，均 OFL。

### 3.3 壳层

- 224px 侧栏、3px 墨脊、1px 铜折线、18px 折影；侧栏与主区同一张纸。
- 54px 顶栏；项目上下文条 40px；系统二级导航 38px。
- 移动端 248px 抽屉、遮罩、路由变化自动关闭；顶栏菜单按钮。
- 成本 tab 单行横向滚动，当前 tab 自动滚到中间。

### 3.4 组件与交互

- PageHeader：34px 衬线标题 + 一句口径 + 一主一次操作；所有英文 eyebrow 隐藏。
- 统计条：4 列（移动 2 列），线分隔、无卡片阴影、数字衬线等宽。
- 表格：纸色表头、双线合计、行 hover 铜线、金额右对齐；移动端最小宽度 + 横向滚动。
- 按钮：墨色主按钮、纸色次按钮、描边危险按钮；移动端收起次要操作。
- 下拉：纸面浮层、朱砂勾、打开时手写下划线；键盘上下/回车/Esc。
- 日期：选中日朱砂圈、今日铜点、上月/下月/今天/清除。
- 复选框：淡朱砂底 + 手写勾（仅表示选择，不表示审批）。
- 弹窗：纸面、2px 角、sticky 底栏；Esc 关闭（Layout 全局兜底，2026-10-20 补）。
- 空/错/加载：纸面空态、铜色 spinner、朱砂左线错误。

### 3.5 页面

- **经营总览**：删掉“单项目单柱图 + 两张侧卡”的 Bento，改为“合同额 Hero + 成本标尺 + 2×2 统计 + 台账 + 待办 + 近期变动”。理由：演示数据只有 1 个项目，柱状图没有结构信息；台账才是经营入口。

## 4. 设计决策论证

### 4.1 为什么把四套主题收敛为一张纸？

旧系统提供象牙/香槟/曜石/冰川四套材质 + 三套强调色。实际结果是：同一条业务在不同主题下出现不同的蓝色/紫色高亮，深色主题还有白卡泄漏；维护成本覆盖 35 个页面 × 4 套变量。V6 的品牌资产是“纸与墨”，不是“可换皮”。本版只保留宣纸纸面，把密度、减少动效、宽屏保留在界面设置中。深色“墨夜”如需回归，应作为独立主题重新设计，而不是继续叠加。

### 4.2 为什么没有删页面？

35 个页面分别承担：合同、预算、进度款、变更、结算、分供、成本、分析、报表中心/设计器/工作室/预览、系统 10 个治理页、往来单位、待办、账号安全、成员权限、助手。报表中心/设计器/工作室看似重叠，但分别是“选台账/导出”“版式设计”“Univer 在线编辑”，合并会破坏导出与编辑链路；系统子页对应不同权限与审计对象，合并会让权限边界模糊。**本版删除的是视觉重复（侧栏“项目驾驶舱”便签、英文眉标、四套主题入口），不是业务页面。**

### 4.3 为什么保留 Univer 的原生皮肤？

`ReportStudio` 的表格画布由 Univer 渲染，强行用全局 CSS 覆盖会破坏选区、公式栏与打印。V6 只统一外框、工具条、页头与按钮；画布皮肤作为“报表纸张”的一部分保留，后续通过 Univer 主题适配而不是 CSS 穿透。

## 5. 已知缺口（不冒充完成）

1. **Univer 画布**：ReportStudio / ReportDesigner 内部仍保留自身皮肤，CSS 穿透会破坏选区、公式栏与打印。
2. **助手真实模型流式**：已临时启用验证三栏布局、空态、新建会话与只读徽标；真实模型流式消息、证据引用、取消运行仍需在具备模型密钥的环境验收。
3. **深色模式**：本版收敛为宣纸单主题，未提供深色；不要用旧 `obsidian` 变量强行打开。
4. **全量 35 页移动端逐页验收**：桌面 19 路由与移动重点页已过回归，但所有 35 页在 390/768 逐页截图级验收仍未做。
5. **legacy.css 仍保留 315KB**：已删除四套死主题规则，但旧页面兜底样式仍在；彻底清理需要逐页删除未被 V6 覆盖的旧规则。
6. **主包仍偏大**：系统/报表/审计等路由已拆包，但 Univer/语言包/vendor 仍有 >500KB chunk；需要继续做 vendor manualChunks。

## 7. 后续建议（按优先级）

1. 后续新增操作统一使用 `confirmAction` / `promptAction`，不再使用原生弹窗。
2. 为 `ReportStudio` 接 Univer 主题（纸/墨/铜），让画布与壳层一致。
3. 助手接真实模型后做一次三栏验收：流式消息、证据引用、取消运行；布局与空态已验收。
4. 若业务坚持深色：单独设计“墨夜”主题，不继承四套旧变量。
5. 把 ui:visual / ui:axe 接入 CI，作为纯字符串校验之外的浏览器级门禁。
