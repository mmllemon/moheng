# 产品范围与当前状态

最后校准：2026-10-21。本文按本轮 UI 收口后的主分支 `eec9677` 更新；版本、功能集成和验收证据分别记录，不能将历史 RC/CI 文档里的状态直接当作当前 HEAD 状态。

## 产品定位

墨衡服务施工单位项目经济成本与经营台账，核心使用者是造价/成本人员与管理人员。权限以公司、项目和角色为边界。当前技术架构是模块化单体：共享业务对象、PostgreSQL、权限/流程/审计体系；不因增加报表或 AI 提前拆分微服务。

## 当前主干已具备的业务域

- **项目与主合同：** 项目档案、项目上下文、主合同、原合同基线与当前有效合同额。
- **目标成本与实际成本：** 清单层级、目标成本、成本记录，以及成本与项目/分供合同的关联。
- **变更签证：** 公司内部流程与业主/授权代表外部确认分离；凭证、金额差异与关键状态有审计路径；提交人不得审批本人提交的业务。
- **业主侧财务：** 进度款、最终结算、应收、收款/退款分配、预付款和质保金。最终结算按最终累计确认额减既有已过账累计额计算差额；允许合法负向差额，负/零差额不允许继续填写普通扣款。
- **分供侧财务：** 分供合同与调整、结算、应付、付款/退款核销、预付款、质保金、发票核验；应付、现金支付与实际成本分别记录，不得互相替代。
- **往来单位：** 统一主数据、身份核验标记、跨项目经营档案和关联记录。仅凭名称匹配到未核验档案不会自动关联；主合同/分供合同 API 返回明确冲突，要求核验或显式选择档案。
- **系统管理与安全：** 用户和项目成员权限、安全事件、关键动作审计、系统参数/字典、授权治理与 PostgreSQL 后台任务。
- **报表中心：** 标准 CSV/XLSX 与报表工作室；项目级、公司级、往来单位级数据源、字段/单元格绑定、重复区域和样式。PR #4 已将产品完善工作合入主干，PR #6 修复报表打印；两种 XLSX 导出路径均含样式化总览页，并对数据范围、工作表、截断和限制给出说明。复杂模板的真实浏览器视觉与打印验收仍需继续。
- **AI 助手：** LangGraph + PostgreSQL checkpoint、会话/消息、持久化运行事件与 SSE 回放、取消/重试/幂等、上下文预算、模型调用边界、每用户活动任务与提交频率限制、供应商 token 用量记录和项目范围近 30 天用量摘要。工具限定为项目经营概览、成本偏差与变更资料完整性三个只读业务工具。助手已改为标题栏入口打开的全局三栏弹窗，旧 `/cost/assistant` / `/assistant` 只作为兼容入口。
- **界面与交互：** Hana 1.1.35 的纸面/外壳/设置工作区、三级交互半径与状态 token 已全仓落地；项目驾驶舱、主合同、待办、报表、变更、账号页完成结构重排；全局命令中心和助手弹窗使用同一套焦点、hover、selected 与 16px 卡片 inset 规则。

上述是源码能力盘点，不表示每个页面均已完成浏览器验收、真实模型 E2E 或用户体验确认。

## 当前仍需继续的开发工作

1. **经营链路集成回归：** 为业主最终结算负差额补齐路由级 PostgreSQL 事务测试，验证应收/过账/审计原子性和重读后的余额。
2. **往来单位交互：** 在浏览器中验证未核验同名档案的 409 提示、身份核验与显式选择流程，以及最终主体 ID 关联。
3. **金额边界：** 定义单项目金额最大值与 API 精度契约。内部 BigInt 分计算并不自动保证使用 JavaScript `Number` 的 HTTP DTO/前端往返逐分精确；需要边界测试，并决定是否改用十进制字符串或整数分接口。
4. **报表体验：** 继续验证复杂模板、多个重复区域、预览/下载一致性、打印分页和导出边界；评估报表设计器的深层编辑能力。
5. **全站 UI：** 本轮已完成 26 条主要路由的浏览器视觉/axe 回归和交互状态收口；仍需产品/业务负责人逐页签认，以及 Univer 画布内部皮肤、更多弹窗深层状态和后续新增页面的同规则巡检。
6. **AI：** 维持默认关闭，继续完成真实供应商 E2E、流式消息/来源/取消/断线重连/进程恢复实测；本轮只验证了全局弹窗布局、空态、打开/关闭、焦点恢复、深链接和响应式。

## 后续投产阶段事项（当前开发非阻塞）

本项目当前按开发状态推进；没有需要本轮核对的生产历史台账，也没有要求本轮取得正式人员签认。只有在准备接入真实历史数据或部署到目标环境后，才安排数据迁移对账、Windows 最小权限 ACL、数据库与附件联合恢复、生产 RPO/RTO、正式业务/财务/审计签认。CI 的隔离 PostgreSQL 和合成夹具是自动化开发证据，不能替代这些未来环境验收；同样不能反过来要求开发阶段凭空提供历史数据或签认。
