# 产品范围与当前状态

最后整理：2026-10-18。代码状态以当前分支、PR 和工作流为准；本文件不把历史阶段文档中的 PASS 自动当成当前产品已交付。

## 产品定位

墨衡服务施工单位的项目经济成本与经营台账。核心使用者为造价/成本人员和管理人员；权限以公司、项目和角色为边界。当前架构采用模块化单体，不因为增加报表或 AI 而提前拆分微服务。

## 源码中已有的主要业务域

- **项目与主合同：** 项目档案、项目上下文、主合同和当前有效合同额。
- **目标成本与实际成本：** 清单层级、目标成本、成本记录及其与项目/分供合同的关联。
- **变更签证：** 内部流程与外部业主/授权代表确认分离；凭证完整性与审计。
- **业主侧：** 进度款、竣工结算、应收账款、收款/退款分配、预付款、质保金。
- **分供侧：** 分供合同、调整、结算、应付、付款/退款核销、预付款、质保金和发票核验。
- **往来单位：** 主数据、身份核验标记、跨项目经营档案与关联记录。
- **系统管理：** 用户、项目成员权限、安全事件、关键动作审计、运行配置及后台任务。
- **报表：** 标准台账导出与报表工作室；支持项目级、公司级及往来单位维度的数据源、单元格绑定和重复区域设计。当前产品分支已为标准台账和报表工作室的 XLSX 导出增加首张样式化总览页，并将分供付款/退款流水与应付、实际成本分开暴露；复杂模板的完整浏览器验收仍未完成。
- **AI 助手：** 有会话/运行后端与第一版工作台代码，限定三个只读业务工具；当前分支增加配置就绪提示、单轮 token/超时/重试边界、分供付款/退款证据以及目标成本扫描截断时的不可判定状态。真实模型供应商 E2E、浏览器内测与生产准入仍未完成。

上述是源码模块盘点，不表示每个页面均已完成用户验收或所有业务边界均已覆盖。

## 明确不能宣称已完成的事项

1. **产品整体：** 尚未完成逐模块需求追踪、业务流程覆盖和实际用户验收，不能宣称“功能全部完善”。
- **发布状态：** 当前版本仍处于 RC（release candidate）阶段；生产准入尚未完成，须以最新候选提交的自动化、真实浏览器、部署及恢复演练证据共同判定。
2. **UI：** 主业务页面已共享日期/下拉控件；本轮修正可见触发器的 label ID、弹层关联、错误说明和键盘/读屏属性，并以 35 个核心业务页面的静态约束防止原生日期/下拉控件回退。视觉满意度仍需真实浏览器检查和产品负责人确认。
3. **报表：** 渲染与 XLSX 生成有实现和自动化测试，但仍需验证预览与导出的一致性、复杂模板的边界、分页/打印、不同区域的数据扩展与异常提示。
4. **AI：** 模型运行时与只读工具代码已接入；真实模型端到端、长期运行/重连/取消、可解释来源体验及成本/限流/隐私准入未全部完成，默认不启用。
5. **部署：** GitHub Actions 的隔离 PostgreSQL 通过不等同于真实脱敏预发布快照核对、Windows 实机、浏览器 E2E 和生产恢复演练完成。
6. **尚未承诺的拓展能力：** 完整库存业务、财务总账/税务、完整采购验收/发票/结算三单匹配及企业级外部集成，必须单独定义业务流程、数据口径和验收标准，不能从已有台账字段推断为已交付。
