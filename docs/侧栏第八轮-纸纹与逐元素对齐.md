## 一、抽屉纸纹（用户指出的问题）

### 现象

侧栏有纸纹，抽屉没有。滑出时能看出「纸不一样」。

### hana 的机制

```css
/* CapabilitiesPanel-Y4qMszTt.css */
._hi_12639, ._lo_28564 {
  position: absolute;
  inset: 0;
  mask-repeat: repeat;
  mask-composite: add;
  mask-size: var(--paper-texture-mottle-tile),
             var(--paper-texture-fiber-tile),
             var(--paper-texture-grain-tile);
}

._hi_12639 {
  background: oklch(from var(--paper-texture-surface)
                    calc(l + var(--paper-texture-peak) * var(--paper-texture-strength, 1)) c h);
}

._lo_28564 {
  background: oklch(from var(--paper-texture-surface)
                    calc(l - var(--paper-texture-peak) * var(--paper-texture-strength, 1)) c h);
}
```

**两层叠加**：`::before` 提亮、`::after` 压暗，各挂一层三合一 mask（mottle 1024px / fiber 720px / grain 256px）。

由 `html[data-paper-texture]` 开关启用。

### moheng 侧栏已有，抽屉缺

```css
/* 侧栏（已有） */
.app-sidebar::before, .app-sidebar::after { ... }
html[data-paper-texture] .app-sidebar::before { display: block; }
```

**抽屉没有任何对应规则。**

### 修正

给 `.sidebar-drawer` 补完全相同的机制：

```css
.sidebar-drawer::before,
.sidebar-drawer::after {
  content: "";
  position: absolute;
  inset: 0;
  z-index: 0;
  pointer-events: none;
  display: none;
  border-radius: inherit;
  mask-repeat: repeat;
  mask-composite: add;
  mask-size: var(--paper-texture-tile-size);
}

html[data-paper-texture] .sidebar-drawer::before,
html[data-paper-texture] .sidebar-drawer::after { display: block; }

.sidebar-drawer::before {
  background: oklch(from var(--sidebar-bg) calc(l + var(--paper-texture-peak) * var(--paper-texture-strength, 1)) c h);
  mask-image: var(--paper-texture-mask-hi);
}

.sidebar-drawer::after {
  background: oklch(from var(--sidebar-bg) calc(l - var(--paper-texture-peak) * var(--paper-texture-strength, 1)) c h);
  mask-image: var(--paper-texture-mask-lo);
}

/* 内容必须在纸纹之上 */
.sidebar-drawer > * { position: relative; z-index: 1; }
```

### 实测

```
侧栏 ::before  display=block  mask=rice-mottle-hi
抽屉 ::before  display=block  mask=rice-mottle-hi   ✓
与侧栏同一张纸  mask 完全一致  ✓
```

### 一处结构性问题（顺带修掉）

**页脚内容被挤压**：名字显示成「系」，头像挤没。

原因：页脚宽 238px，但 `sidebar-user-row` 把头像 + 名字 + 两个 32px 按钮都放在同一 flex 行，总宽超限。

hana 的结构是**左右两组**：

```
_fpUserBar (justify-content: space-between)
  ├─ _fpUserIdentity  头像 + 名字    flex: 1 1 auto, min-width: 0
  └─ _fpUserActions   图标按钮组     flex: 0 0 auto
```

已按此重组，并给名字区加 `overflow: hidden` + `text-overflow: ellipsis`。

### 尺寸覆盖的一个坑

`.sidebar-footer-icon` 设 30px 无效，因为：

```css
/* hana.css:1685，特异性 0,2,1 */
html .sidebar-footer-icon { width: var(--icon-btn-size-lg); }
/* --icon-btn-size-lg = calc(22px + var(--icon-btn-pad) * 2) = 26px */
```

`--icon-btn-pad` 实际是 2px 不是 4px，所以算得 26px。用同等特异性 + 后置声明覆盖：

```css
html .app-sidebar-footer .sidebar-footer-icon,
html .sidebar-drawer .sidebar-footer-icon {
  width: 30px; height: 30px; flex: 0 0 30px;
  border-radius: 50%; corner-shape: round;
}
```
