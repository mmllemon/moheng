## 4. WP8 阻塞说明

当前容器只有 Node.js `v22.16.0`，仓库要求 `>=24.0.0`，没有项目完整 `node_modules`，尝试访问 npm registry 时出现 DNS `EAI_AGAIN`。WP8 实际命令结果：`npm run lint` 与 `npm run build` 因缺少 `@types/node` 报 TS2688 失败；`npm test` 因 `tsx: not found` 失败；`npm run db:generate` 因 `prisma: not found` 失败。因此不能声称完整 `tsc`、Vite build、Prisma 验证/生成、数据库集成或浏览器 E2E 已通过。

正式候选交付前应在 Node.js 24+ 的 Windows/CI 环境中安装锁定依赖并运行 WP8 步骤，尤其验证目标成本预检后到最终写事务之间的并发冲突、角色越权、动态预警规则，以及业主/分供付款退款和审计事务。

**结论：** v2.0.0-rc.1 已具备新增 WP2–WP7 源码，可进行受控验收；完整 WP8 Gate 未通过，仍为发布候选版本。
