# WP10：报表中心修正与工作区入口增强验收清单 v2.5.0-rc.1

- 基线：`v2.4.0-rc.1`
- 目标候选：`v2.5.0-rc.1`
- 本清单中浏览器/数据库/XLSX 标记为实测项；静态源码命中不能代替实测。

## A. 自动延伸区域的数据匹配

- [ ] 每条集合记录具备稳定 ID，查询包含业务排序字段与 ID tie-breaker。
- [ ] 同一个重复区域的所有单元格使用同一条记录对象，不会对每个单元格独立查询。
- [ ] 绑定字段的 `sourceId` 与重复区域的 `sourceId` 不一致时，模板保存/发布/预览被拒绝。
- [ ] 多个不同数据源区域按各自记录数独立扩展；下方标题、页脚、合并区域偏移正确。
- [ ] 空集合保持一个空样板行，不把后续版式上移。
- [ ] 业务外键关联在后端数据源层完成，不凭显示名称、数组索引或 Excel 行号关联。
- [ ] 查询使用上限加一条识别截断；截断会显示警告，且被截断集合对应的“完整总额”不显示部分结果。
- [ ] 往来单位的分供合同清单超过 10,000 条时，合同/应付/成本/发票相关汇总显示为空并提示截断，不把前 10,000 条的合计当作全部数据。
- [ ] 2 条分供合同、3 条收款的测试数据能在不同区域准确展示，各字段仍与所属记录一致。

## B. 预览列宽

- [ ] 只有 2–4 列并且视口宽度为 1920px 时，最后一列宽度保持模板设定，不自动填满剩余宽度。
- [ ] 列数较多时可水平滚动，不压缩字段到不可读的宽度。
- [ ] 长文本在列内换行并受最大宽度约束；金额/日期格式正常。
- [ ] 打印布局单独适配纸张宽度，屏幕预览规则不被打印 CSS 反向影响。

## C. 报表中心主页面

- [ ] 主页明确区分快速预览台账、项目综合报告、公司经营报告和单位经营档案。
- [ ] 标准台账按成本、业主财务、分供分类；搜索、空状态、选择状态与权限错误路径正常。
- [ ] 模板设计、模板生命周期和导出任务历史入口仍然可达。

## D. 工作台按钮与范围

- [ ] 目标成本页可预览/导出 `target-cost`。
- [ ] 实际成本页可预览/导出 `actual-cost`。
- [ ] 进度款页可预览/导出 `progress-bills`。
- [ ] 变更签证页可预览/导出 `changes`。
- [ ] 分供合同页可预览/导出 `downstream-contracts`。
- [ ] 分供应付页可预览/导出 `downstream-payables`。
- [ ] 业主应收和收退款页面分别导出对应报表；其他业主财务子页可进入项目综合报告。
- [ ] 项目驾驶舱打开正确的项目综合报告，并绑定当前项目 ID。
- [ ] 当前账号无权访问指定项目时，服务端拒绝预览和导出；前端隐藏按钮不是安全边界。

## E. 往来单位经营档案默认模板

- [ ] 单位档案页可直接进入专属经营档案预览/导出，并提供编辑报表模板入口。
- [ ] 编辑入口加载该单位已保存的个人模板；无已保存模板时才创建默认定义，不能静默生成重复模板。
- [ ] 默认模板显示单位摘要/身份核验状态、可访问关联项目、合同和独立成本明细。
- [ ] 模板记录绑定明确 `businessPartyId`，不可跨单位查看或套用。
- [ ] 普通用户只能看到与其可访问业务关系相符的数据；管理员权限按现有规则。
- [ ] 迁移后已有模板数据不丢失，旧迁移未被编辑；单位删除受外键/归档约束保护。
- [ ] 单位名称相同或历史回填身份未核验时显式提示，不能默认视为同一签约主体。

## F. 金额、导出与兼容性

- [ ] 大额 DECIMAL 金额用整数分精确汇总；超出 Excel 数值精度的金额不静默舍入。
- [ ] 预览与 XLSX 使用同一模板版本、字段绑定、区域排序和格式定义。
- [ ] 导出任务复核权限、幂等和失败状态；结果过期策略正常。
- [ ] Excel 与 WPS 打开文件无修复提示，样式、列宽、冻结、筛选、换行和打印分页符合预期。

- [ ] 完成角色矩阵、跨项目、跨单位、重复区域及后台导出浏览器 E2E。
- [ ] Windows 原生部署、备份恢复和升级/回滚演练通过。
