# 窗口控制区「两层」的成因与修正

日期：2026-10-25

## 现象

截图看像两层圆角框：外层一条药丸形容器，里层每个按钮各带一圈圆角描边。头像是实底 + 1px 边框 + 50% 圆角，最明显。

## 实测（修前）

```
island  162×32  bg 88% 纸色  border 1px  radius 14.7272px  shadow 0 2px 8px  padding 0 2px
btn0-3  28×28   bg 透明     border 3px 透明  radius 9.20448px
btn4    28×28   bg #f4f0ea  border 1px  ✓  radius 50%  ✓
```

`btn4` 就是头像：自带实底、1px 边框、50% 圆角，叠在 island 的圆角容器里，形成框中框。

## hana 的真值

```css
/* island：自身无 background / border / radius / padding，只有 ::before 画底衬 */
._windowControlsIsland_5f7ae {
  position: fixed;
  display: flex;
  align-items: center;
  gap: var(--chalkboard-titlebar-action-gap, 0px);
  isolation: isolate;
  pointer-events: none;
}

._windowControlsIsland_5f7ae::before {
  content: "";
  position: absolute;
  inset: 0;
  z-index: var(--z-under);                                  /* -1 */
  background-color: var(--titlebar-action-bg, var(--icon-halo-bg, var(--bg)));
  border: var(--titlebar-action-border, var(--panel-card-border));
  backdrop-filter: var(--titlebar-action-veil, none);
  border-radius: calc(var(--titlebar-action-radius, ...) * var(--corner-radius-scale, 1));
}

/* 按钮 */
._sdbBtn_e792e {
  width: calc(24px + 2px * 2);            /* 28×28 */
  border: 3px solid transparent;
  background-clip: padding-box;
  border-radius: calc(var(--chalkboard-titlebar-action-radius, var(--radius-sm)) * scale);
  isolation: isolate;
}

/* 按钮的 ::before 只向外扩 3px，不画实底（实底是 island 画的） */
._sdbBtn_e792e::before { inset: calc(-1 * var(--card-top-btn-hover-inset, 3px)); }
```

变量真值：

```css
--chalkboard-titlebar-action-radius: calc(var(--panel-card-radius) - 2px);   /* ≈ 18.4px */
--chalkboard-titlebar-action-gap: 0px;
```

**按钮的圆角是 18.4px，不是 50%。** 因为 `gap: 0`、按钮 28px，相邻按钮只差 28px，18.4px 圆角在视觉上接近连续的一条。

另外 `_trafficStrip`（侧栏那套窗口控制）有单独一条：

```css
._trafficStrip:not([data-collapsed]) ._sdbBtn_e792e::before {
  background-color: var(--sidebar-bg, var(--bg));
  border: none;
  backdrop-filter: none;
  box-shadow: none;
}
```

说明按钮底衬只在**独立场景**才画，岛内不画。

## 修正

**一、island 自身什么都不画，全交给 `::before`**

```css
.window-controls-island {
  position: fixed;
  display: flex;
  align-items: center;
  gap: 0;
  isolation: isolate;
  pointer-events: none;
  /* 无 background / border / border-radius / padding */
}

.window-controls-island::before {
  content: "";
  position: absolute;
  inset: 0;
  z-index: var(--z-under, -1);
  background-color: var(--chalkboard-titlebar-action-veil-bg, color-mix(in srgb, var(--bg) 88%, transparent));
  border: var(--chalkboard-titlebar-action-border, 1px solid var(--overlay-light));
  border-radius: calc(var(--chalkboard-titlebar-action-radius, var(--radius-md)) * var(--corner-radius-scale, 1));
  corner-shape: squircle;
  box-shadow: var(--titlebar-action-shadow, 0 2px 8px rgba(0, 0, 0, 0.08));
  backdrop-filter: var(--chalkboard-titlebar-action-veil, blur(8px));
}
```

**二、岛内按钮不可见**

```css
html .window-controls-island .titlebar-icon::before,
html .window-controls-island .titlebar-avatar::before { display: none; }

html .window-controls-island .titlebar-avatar {
  border: 0;
  background: none;
}
```

**三、头像圆角改成 hana 的值**

```css
.titlebar-avatar {
  border: 3px solid transparent;
  background: none;
  background-clip: padding-box;
  border-radius: calc(calc(var(--panel-card-radius) - 2px) * var(--corner-radius-scale, 1));  /* 18.409px */
  corner-shape: squircle;
}
```

## 实测（修后）

```
island  156×30
        bg rgba(0,0,0,0)  border 0  radius 0  padding 0  shadow none
        ::before  inset 0  bg 88%纸色  border 1px  radius 14.7272px  z=-1

btn0-3  28×28  bg 透明  border 3px 透明  radius 9.20448px  ::before display:none
btn4    28×28  bg 透明  border 0     radius 18.409px      ::before display:none
```

两层合并成一层：整条药丸底衬由 island 的 `::before` 画一次，按钮只提供图标。

## 一个判断错误的过程

中间我给每个按钮也加了同色 `::before` 底衬，试图靠「相邻 3px 外扩重叠」连成一片。截图显示仍有分隔感，因为每个按钮的底衬是独立圆角，重叠处会露出两个不同的曲线。

hana 的做法更简单：**岛画一次，按钮不画**。`_trafficStrip` 那条规则也印证了按钮底衬是独立场景才用的。
