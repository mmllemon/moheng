## 二、叠纸：我的结构理解错了

### 真相

`workspaceCardSurface` 的第二个子元素是 `workspaceDrawerStack`：

```jsx
<div className={workspaceCardSurface} data-workspace-drawers={w} style={{'--workspace-drawer-count': w}}>
  <div className={workspaceCardMain}>…</div>
  {w > 0 && (
    <div className={workspaceDrawerStack}>
      {layers.map((id, i) => (
        <div className={workspaceDrawerLayer} style={{'--workspace-drawer-index': i}}>…</div>
      ))}
    </div>
  )}
</div>
```

```css
._workspaceDrawerStack_a0cbd {

  display: flex; flex-direction: column;
  min-height: 0;
  max-height: 64%;
}

._workspaceDrawerLayer_322c5 {
  position: relative;                                   /* 文档流，不是 absolute */
  z-index: calc(var(--workspace-drawer-count, 0) - var(--workspace-drawer-index, 0));
  flex: 0 0 auto;
  min-height: 0;
  display: flex; flex-direction: column;
  overflow: hidden;
  background: var(--panel-card-bg);
  margin-top: calc(-1 * var(--workspace-drawer-overlap));   /* -10px */
  padding-top: var(--workspace-drawer-overlap);              /* 10px */
}

/* 有抽屉时主区只保下沿圆角 */
._workspaceCardSurface[data-workspace-drawers] ._workspaceCardMain {
  z-index: calc(var(--workspace-drawer-count) + 1);
  background: var(--panel-card-bg);
```

**这就是「上卡压住下卡、下卡只露尾巴」**：抽屉的 `margin-top: -10px` 让它上沿藏进上面那张卡下面 10px；主区交出下沿圆角 + 拿到投影，于是两者的分界清晰。

### 我错在哪

上一轮我把它改成 `position: absolute` + `display: contents`，理由是「`_jianDrawer` 是 absolute」。但 `absolute` 的是**笺（暖米色便签）**，不是**会话抽屉的叠纸层**。两个不同组件：

| | 笺 `_jianDrawer` | 会话抽屉 `_workspaceDrawerLayer` |
|---|---|---|
| 位置 | `absolute`，左右 6px 浮层 | 文档流，负 margin 叠纸 |
| 底色 | `#FAF0E2` 暖米色 | `--panel-card-bg` |
| 用途 | 笔记 | 本次对话 / 后台任务 |

## 三、高度调节把手

### 真值（`contributed-keybindings-BWxnaFR2.js` + `ChatTranscript` CSS）

hana 的 layout group 是 CSS Grid：

```jsx
<div data-layout-node-id data-layout-orientation="column"
     style={{ display: 'grid', gridTemplateRows: mu({ node, sizing }), gridTemplateColumns: '100%' }}>
  {panels.map((id, i) => (
    <div data-layout-panel-node-id data-layout-panel-child-id={id}
         style={{ gridRow: String(i * 2 + 1), gridColumn: '1' }}>…</div>
  ))}
  {separators.map((i) => (
    <div role="separator" aria-orientation="horizontal"
         data-layout-separator-node-id data-layout-separator-index={i}
         style={{ gridRow: String(i * 2), gridColumn: '1' }} />
  ))}
</div>
```

`mu()` 产出 `minmax(0%, 1fr) 0px minmax(0%, 1fr)` 这样的行模板。

```css
._separator_704ed {
  position: relative; z-index: 4; flex-shrink: 0;
  background: transparent; touch-action: none;
}
._separator_704ed[aria-orientation=horizontal] {
  height: var(--separator-grab-box, var(--panel-edge-gap));       /* 6px */
  margin-block: calc(var(--separator-grab-box, 6px) / -2);        /* -3px */
  cursor: row-resize;
}
._separator_704ed:after {
  content: ''; position: absolute; opacity: 0;
  background: var(--accent); border-radius: 2px; corner-shape: round;
  transition: opacity .18s, transform .18s;
}
._separator_704ed[aria-orientation=horizontal]:after {
  top: 50%; left: 50%;
  height: 3px; width: 44px;
  transform: translate(-50%,-50%) scaleX(.12);
}
._separator_704ed:hover:after, :active:after { opacity: .35; }
._separator_704ed[aria-orientation=horizontal]:hover:after { transform: translate(-50%,-50%) scaleX(1); }
```

### 落地

新建 `components/CardSplitHandle.tsx`：

- `pointerdown` 后挂 `window` 的 `pointermove` / `pointerup`（对齐 hana 的全局指针语义）
- 上下限用 `MIN_PX = 120` 换算，避免压成 0
- 键盘：`ArrowUp` / `ArrowDown` 每次 2%，`Shift` 10%
- `aria-valuenow` / `-valuemin` / `-valuemax`
- 拖动时给 `body` 加 `cursor: row-resize`

容器：

```jsx
<div className="workspace-card-grid"
     style={{ gridTemplateRows: `${ratio * 100}% 6px ${(1 - ratio) * 100}%` }}>
  {fileCard}
  <CardSplitHandle style={{ gridRow: '2', gridColumn: '1' }} />
  {previewCard}
</div>
```

### 踩的两个坑

**一、`fr` 会被归一化。** `minmax(0, 0.5fr) 0px minmax(0, 0.5fr)` 和 `0.3fr / 0.7fr` 的比例一样，所以改 ratio 高度不变。必须用百分比。

**二、`0px` 行会把 handle 压成 0。** hana 的模板里分隔行是 `0px`，靠 handle 自身 `height: 6px` 溢出该行做热区。但 grid item 默认 `align-self: stretch`，在 `0px` 行里会被压成 0。改成行高 `6px` + `margin-block: -3px`，热区真实占位、视觉上被负 margin 吃掉。

### 实测

```
初始    card1 444  card2 444   handle y=447 h=6
悬停    ::after opacity 0.35  scaleX(1)
上拖80  card1 364  card2 518   handle y=370
```

## 过程中的一次事故

`CardSplitHandle.tsx` 的块注释里写了 `/* 6px 热区 */`，`*/` 提前闭合外层注释，Vite 报 `Unexpected token (28:1)`，全站 500。

这是同一类错误第 N 次（CSS 里也踩过）。规则：**块注释里不写 `/* */`，需要举例时用 `←` 或直接去掉标记。**
