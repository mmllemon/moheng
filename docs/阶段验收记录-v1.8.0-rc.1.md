# 墨衡 v1.8.0-rc.1 阶段验收记录：Pro-Tier UI 与交互优化

- 验收日期：2026-10-14
- 版本：`1.8.0-rc.1`
- 设计依据：`docs/设计系统规范-Pro-Tier-Suite-v4.2.0.md`
- 验收性质：发布候选阶段；静态检查通过，不代表已完成生产环境验收。

## 1. 本轮改造范围

### 全局布局与设置

- 将常驻设置条改为顶栏右侧的“界面设置”按钮，使用独立浮层卡片按需展开。
- 设置卡片包含四套材质主题、跟随系统、舒朗/紧凑密度、宽屏工作区、强调色、减少动效和恢复默认；设置仍保存在当前浏览器，不接触业务数据。
- 在 `/projects` 项目管理页隐藏顶部当前项目切换条；项目工作台仍保留紧凑的项目上下文。

### 项目管理卡片

- 增加项目组合概况，并重排项目卡片的合同金额、目标成本、实际成本、业主回款、成本偏差、回款率等信息。
- 汇总指标沿用现有项目与经营分析数据，不虚构工程实体进度或预计利润；无成本基线时显示“未建立基线”等明确状态。
- 项目新建/编辑对话框增加收起动画；卡片入场、悬停、进度条等具有统一微动效。

### 下拉框与日期选择器

- 新增 `SelectField` 自绘下拉组件，以 portal 渲染风格统一的选项浮层；支持选项搜索、键盘上下选择、Home/End、Enter、Escape、当前选中标识、外部点击收起和进出场过渡。
- 新增 `DatePicker` 自绘日期面板；支持周一为首列的日期网格、上/下月、方向键/分页键导航、最小/最大日期限制、今天/清除/确认操作、焦点日期与进出场过渡。
- 保留隐藏原生表单控件作为 React Hook Form 注册、验证与变更事件代理。应用页面中的原生 select/date 控件已统一迁移至自绘组件；自绘组件内部代理控件除外。
- 为设置面板、命令面板、快捷操作菜单和相关业务对话框增加动画退出状态，避免关闭时直接卸载造成硬切。

### 业务边界

- 本轮未修改合同金额生效规则、成本与结算业务算法、数据库 schema、Prisma migration 或财务数据写入接口。
- 交易/财务业务仍以服务端响应为准，没有为了视觉反馈将关键业务动作一律改为乐观提交。

3. 四套主题的浏览器截图验收、浮层定位边界、触屏设备和窄屏行为验收。
4. 项目卡片数据口径与真实数据库数据的人工复核，以及浏览器端到端业务回归。
