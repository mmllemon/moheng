# WP12：报表预览返回导航、驾驶舱图表与 XLSX 类型修复验收清单 v2.7.0-rc.1

- 基线：`v2.6.0-rc.1`
- 候选：`v2.7.0-rc.1`
- 性质：源码级回归清单。浏览器实测项未勾选前，不代表已完成端到端验收。

## A. 报表预览返回行为

- [ ] 从项目驾驶舱点击“预览 / 导出项目综合报表”，进入报表预览；点击一次“返回”直接回到驾驶舱，不重新进入自动预览、不跳出应用。
- [ ] 从往来单位经营档案、项目工作台台账、报表中心和旧版报表设计器打开预览，点击返回后回到调用页面。
- [ ] 在报表工作室手动点击预览，返回到无 `autoPreview=1`、带已保存模板 ID 的干净编辑 URL。
- [ ] 自动预览使用 `replace` 消除中间工作室路由；重复执行返回操作不会形成预览循环。
- [ ] 直接打开或刷新预览 URL，返回按钮使用经过校验的 `returnTo`；非法外部目标、`//host` 和含反斜杠路径不会被接受，默认回到报表中心。
- [ ] 全仓只有报表预览页的一个集中处理函数可使用 `navigate(-1)`；所有实际入口都传递返回 state 和/或 `returnTo`。

- [ ] 本轮返回导航修正不改变综合报表模板、重复区域的行匹配规则、项目级/公司级/往来单位经营档案的数据范围。

## B. 项目驾驶舱图表

- [ ] Y 轴金额标签在 1920px、1366px、1024px 和窄屏宽度均未被左边缘裁切，确保 Y 轴标签完整可读。
- [ ] 金额位数较长时轴标签使用千分位、万或亿的紧凑格式；单位含义清晰。
- [ ] `grid.containLabel` 生效，轴标签不会覆盖绘图区或造成水平溢出。

## C. 项目工作台导航

- [ ] 顶部导航通过组容器背景、间距和分隔线呈现分组，不显示“业主侧业务”“成本与支出业务”“项目管理”等可见组名。
- [ ] 组容器的 `aria-label` 和 NavLink 的可访问名称仍保留。
- [ ] 项目驾驶舱、收入侧、成本支出侧和项目成员导航的路由及激活状态均正确。

## D. ExcelJS 字体类型

- [ ] `apps/api/src/lib/report-studio-xlsx.ts` 使用 `const font: Partial<ExcelJS.Font> = {};` 累积可选字体属性。
- [ ] 严格 TypeScript 检查通过。
- [ ] 生成的 XLSX 在 Excel/WPS 中打开正常；字体、字号、粗体、斜体、下划线、颜色及现有单元格样式仍保留。

## E. 相关历史 UI 回归

- [ ] 报表中心保持 v2.6 的精简布局，不重新引入重复介绍卡、重复 Hero 或重复标准报表目录。
- [ ] 侧栏不显示没有真实数据与计算逻辑的“经营健康度”评分；现有项目驾驶舱快捷入口仍可用。
