# 抽屉叠纸：我理解错了

日期：2026-10-25

## 正确的样子

`_jianDrawer_57159` 是 **absolute 浮在卡片上**：

```css
._jianDrawer_57159 {
  position: absolute;
  left: var(--panel-edge-gap);                    /* 6px */
  right: var(--panel-edge-gap);                   /* 6px */
  bottom: var(--right-workspace-jian-bottom);     /* 6px */
  z-index: 2;
  height: var(--right-workspace-jian-open-height);   /* 320px */
  margin: 0;
  border-radius: calc(var(--radius-md) * var(--corner-radius-scale, 1));   /* 14.73px，四角全圆 */
}
._jianDrawer[data-open=false] { height: var(--right-workspace-jian-closed-height) }   /* 40px */
```

列表用 padding 给它让位：

```css
._fileList_52df5, _tree_6bb43 {
  padding-bottom: calc(var(--right-workspace-jian-reserved, 56px) + var(--panel-edge-gap));
  scroll-padding-bottom: same;
}
/* reserved = closed-height(40) + bottom(6) = 46px */
```

所以它是一张**独立浮起的便签**：左右各内缩 6px、四角全圆、浮在卡片内容之上，列表底部留 46px 不让内容被压住。

## 我做错的两点

**一、把 `--workspace-drawer-overlap: 10px` 当成抽屉与卡片的叠纸**

```css
/* 我写的（错） */
margin-top: calc(-1 * var(--workspace-drawer-overlap));   /* -10px */
padding-top: var(--workspace-drawer-overlap);
```

这个 10px 是**多个抽屉互相堆叠时**的层间重叠（`_workspaceDrawerLayer` 在 `_workspaceDrawerStack` 里），不是抽屉压卡片。

**二、把「主区只保下沿圆角」套在抽屉上**

```css
/* 我写的（错） */
.workspace-card-main:has(.workspace-drawer-stack) .workspace-card-surface-main {
  border-radius: 0 0 outer outer;   /* 只保下沿 */
}
```

hana 那条规则作用于 `_workspaceCardSurface[data-workspace-drawers] ._workspaceCardMain`，是**多个抽屉叠放**时主卡让出下沿圆角，好让下方抽屉的圆角露出来。单个 floating 抽屉不需要。

## 修正后

```css
.workspace-drawer-layer {
  position: absolute;
  left: var(--panel-edge-gap, 6px);
  right: var(--panel-edge-gap, 6px);
  bottom: var(--panel-edge-gap, 6px);
  z-index: 2;
  margin: 0;
}

.workspace-drawer-stack { position: static; display: contents; }   /* 只当容器 */

.workspace-card { position: relative; }   /* absolute 抽屉的定位基准 */

.workspace-card-surface-main {
  padding-bottom: calc(40px + var(--panel-edge-gap, 6px) * 2);   /* 给抽屉让位 52px */
}
```


## 顺带修掉的两个关闭入口

预览卡头原来有一个 `×`，标签栏右端又有一个 Collapse（`>`），两个关闭入口挤在一起。hana 的预览卡 `[By]` 里 chrome 只有 `titlebar-right` 的 actions，卡头没有独立 `×` —— 已删卡头那个，只留标签栏的 Collapse。

## 教训

`--workspace-drawer-overlap` 这个名字里的 "drawer" 指**多个抽屉之间**，不是「抽屉压卡片」。看到变量名先确认它作用的元素对：`_workspaceDrawerLayer` 的父级是 `_workspaceDrawerStack`，所以 overlapping 发生在栈内部。
