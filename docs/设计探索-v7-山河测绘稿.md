# 山河测绘稿 · V7 设计探索

> 概念页：`/design-v7/index.html`（静态可交互样张，不进入主导航，不写业务数据）
> 关键词：纸与墨 / 纹理与质感 / 刻度与标尺 / 国画与壁画 / 衬线与篆书 / 批注与印章 / 手写与描白 / 工程测绘 / 手写稿纸

## 1. 北极星

**把“工程项目的经营判断”画成一张可校核的测绘稿：数字像测出来的，批注像人写上去的，印章像最后落定的。**

V6 已经解决了“纸与墨”的底色；V7 要解决的是**图纸感**：页面不只是“纸上的卡片”，而是有图号、比例、坐标、图签、会签栏、批注层、落印动作的工程文件。

## 2. 三个镜头

概念页右上角可在三种镜头间切换，快捷键 1 / 2 / 3。

### 01 测绘
- 方格纸、坐标、标尺、图例、图签栏；
- 数字用 Spectral 等宽，表格像测量记录；
- 交互：拖动成本标尺，读取“占目标成本 x% · 对应金额”；
- 适合经营总览、预算、成本、结算等需要精度的页面。

### 02 山河
- 矿物色（石青/石绿/赭石/朱砂）作为大色域，不做成彩色卡片；
- 等高线、河道蓝线、场地边界成为背景结构；
- 金额主数字改用石青，图章用赭石；
- 适合项目组合、区域经营、汇报封面，不适合密集表单。

### 03 批注
- 稿纸横线、左侧红边、手写批注、落款；
- 系统数字仍用衬线，人的判断用 Ma Shan Zheng；
- 批注卡可以打开右侧抽屉，继续追加“补充批注”；
- 适合变更签证、合同会签、结算争议、审计复核。

## 3. 可交互动作

1. **镜头切换**：测绘 / 山河 / 批注，记忆在 localStorage。
2. **成本标尺**：点击或拖动标尺，读取对应金额；键盘方向键 1% 调节。
3. **落印**：点击“落印”，项目章以缩放+旋转动画落在图签栏，写入落印时间。
4. **批注**：点击图中 1/2/3 号批注点打开抽屉；抽屉内可追加批注；页边表单可直接写入新批注，图上自动出现新点。
5. **图纸聚焦**：点击“局部”，压暗非主楼元素，只保留 A-01 主楼与 1 号批注点。
6. **键盘**：1/2/3 切换镜头；Esc 关闭批注抽屉；抽屉内 Tab 循环。

## 4. 可以往生产 UI 搬的结构

### 4.1 图签栏
每个项目页底部固定一条图签：图号、比例、测绘人、校核人、批准人、落印状态。审批链不再只是一排按钮，而是“谁在图签上签了字”。

### 4.2 卷宗目录
左侧竖向目录用“00 总图 / 01 成本 / 02 合同 / 03 结算 / 04 批注”代替普通 tab；当前项用朱砂细线标记，滚动时自动切换。

### 4.3 标尺型控件
- 成本执行率、回款率、结算比例用横向标尺，不用进度条；
- 标尺有主刻度、次刻度、指针和读数；
- 拖动时读数实时变化，键盘可微调。

### 4.4 批注层
- 批注不是聊天气泡，而是图纸上的点 + 页边批注；
- 批注有作者、时间、依据、处理意见；
- 会签时把批注汇总成“批注栏”，而不是消息流。

### 4.5 印章状态
- 草稿 / 送审 / 已核 / 作废用不同印章，不用彩色胶囊；
- 落印是动作，不是静态图标；
- 印章只出现在图签、状态位和关键结论旁，不铺满页面。

### 4.6 矿物色数据编码
- 石青 = 合同/收入，石绿 = 成本/执行，赭石 = 分供/应付，朱砂 = 风险/批注；
- 色只出现在数据带、图例、批注点，不把整页染成彩色；
- 保持纸色为底，颜色像颜料落在纸上，而不是 UI 主题色。

### 4.7 衬线、篆书、手写的分工
- 标题/正文：Noto Serif SC；
- 金额/刻度/图号：Spectral；
- 印章/卷宗/批注：Ma Shan Zheng；
- 系统字段永远不用手写体，手写只属于人的判断。

### 4.8 描白与负空间
- 图纸边缘留白、图框、图签、图例都是结构，不是装饰；
- 一个页面只留一个主数字/主图；
- 删除“说明卡片”，把说明放进图注、页边、图签。

## 5. 页面级设想

| 页面 | V7 形态 |
| --- | --- |
| 经营总览 | 项目总图 + 合同/成本/回款三把标尺 + 风险批注点 |
| 预算与目标成本 | 工程量测表：清单树 + 目标/实际双标尺 + 偏差图注 |
| 业主合同 | 合同附图：金额分段的标尺、付款节点、会签栏 |
| 变更签证 | 变更批注单：左原文、右批注、底部会签与落印 |
| 竣工结算 | 结算会签页：结算书 + 差异批注 + 质保金标尺 |
| 分供合同 | 分供附图：合同链、付款节点、发票/应付对照 |
| 成本分析 | 测绘图版：偏差标尺、构成色带、月度柱图 |
| 报表中心 | 晒图纸：图号、版本、图幅、导出/打印 |
| 系统治理 | 工部档案：目录、条款、会签、用印记录 |

## 6. 生产化边界

这是**设计探索样张**，不是生产路由：

- 数据为静态演示；
- 批注只存在页面内存，不写后端；
- 落印只做视觉状态，不生成审计记录；
- 没有接入权限、导出、打印和真实项目切换。

如果方向确认，下一步应先在 `/cost` 项目驾驶舱做一版真实 React 页面，验证图签栏、标尺、批注抽屉与现有数据接口，再向预算/结算/变更推广。
