# 顶栏项目下拉归位 + 主内容区纸纹

日期：2026-10-25

## 一、项目下拉夹在面板按钮中间

`titlebar-right` 的原始顺序是：

```
工作区按钮 → 项目下拉 → PanelMenu
```

项目下拉夹在两个 chrome 之间，把面板按钮撑开了。

### hana 的 titlebar-right 只装 chrome

扫了 hana 全部 `slot: "titlebar-right"` 条目，只有两类：

```
chalkboard.system.favorite / favoriteStar / screenshot / export
chalkboard.system.minimize / full-screen / close
chalkboard.chat.panel-*（面板开关）
chalkboard.chat.panel-menu（菜单）
```

**没有项目选择器。** 它是 moheng 独有元素。

### 修法

移到左岛的 `titlebar-context` 内，跟在标题和状态段后面：

```jsx
<div className="titlebar-context" data-titlebar-slot="title">
  <strong data-page-title>{currentPageLabel}</strong>
  <span className="titlebar-status">…</span>
  {!isGlobalContext ? <div className="titlebar-project"><SelectField … /></div> : null}
</div>
```

实测：

```
右岛  ["titlebar-icon", "panel-menu-wrap"]     ← 只剩 chrome
左岛  ["titlebar-icon titlebar-mobile-menu", "titlebar-context"]
      titlebar-context 292px（x=290），内含项目下拉 178px（x=404）
```

### 显示条件

`!isGlobalContext`。逐路由实测：

```
/projects 未选项目   下拉 N   状态「全公司」
/projects 已选项目   下拉 N   状态「全公司」
/cost 项目上下文     下拉 Y   状态「XM-2026-000002 项目」
/reports 全局        下拉 N   状态「全公司」
```

`/projects` 是项目列表页，属于全局视图（项目详情是同页用 `selectedProjectId` 切换，路由不变），所以下拉不出现是对的。

## 二、主内容区没有纸纹

### 根因

moheng 有纸纹的**变量和 mask**（`hana.css` 里 3 种纹理 × hi/lo，`auth-store.ts` 也正确设置了 `html[data-paper-texture]`），但**从来没有渲染纸纹层的 DOM 元素**。

hana 的显示条件是两条：

```css
html[data-paper-texture] ._layer_0d743:not([data-paper-scope]) { display: block; }
```

1. `html[data-paper-texture]` 存在（moheng 有，实测 `"rice"`）
2. 页面上有 `._layer_0d743`

moheng 缺第 2 条。

### 纸纹层的完整真值

```css
._layer_0d743 {
  position: absolute; inset: 0;
  z-index: var(--z-under);          /* -1 */
  pointer-events: none;
  border-radius: inherit;
  display: none;
}

._hi_12639, ._lo_28564 {
  position: absolute; inset: 0;
  mask-repeat: repeat;
  mask-composite: add;
  mask-size: var(--paper-texture-mottle-tile), var(--paper-texture-fiber-tile), var(--paper-texture-grain-tile);
}

._hi_12639 {
  background: oklch(from var(--paper-texture-surface) calc(l + var(--paper-texture-peak) * var(--paper-texture-strength, 1)) c h);
}
._lo_28564 {
  background: oklch(from var(--paper-texture-surface) calc(l - var(--paper-texture-peak) * var(--paper-texture-strength, 1)) c h);
}
```

`--paper-texture-surface: var(--bg)`。

### 实现

新建 `components/PaperTextureLayer.tsx`：

```jsx
export default function PaperTextureLayer() {
  return (
    <div className="paper-layer" data-paper-texture-layer aria-hidden="true">
      <div className="paper-layer-hi" />
      <div className="paper-layer-lo" />
    </div>
  );
}
```

挂到 `.app-content`（卡片壳）里，**不放进 `.route-transition`**：那里是滚动容器，纸纹会跟着内容滚走。

```jsx
<main className="app-content" ref={contentRef}>
  <PaperTextureLayer />
  …
</main>
```

CSS 用 moheng 已有的变量名 `--paper-texture-mask-hi/lo`（hana 用的是 `--paper-texture-mottle-tile` 等，moheng 已按自己的命名整理过）。

### 实测

```
paperAttr   "rice"
layerExists true
display     block
zIndex      -1
pointerEvents none
borderRadius 22.0908px（继承卡片圆角）
mask 数量   3（mottle / fiber / grain）
bgColor     oklch(1 0.0102578 81.5667)   ← 从 #f8f4ed 提亮后的值
尺寸        1348 × 888
```

## 一处排查弯路

第一次测到 `hiBg: "none"`，以为背景没生效。实际是我读了 `backgroundImage`，而纸纹用的是 `mask-image` + `backgroundColor`。

**读 computed style 前先确认该属性对应哪个 CSS 属性名**，mask 和 background 是两套。
