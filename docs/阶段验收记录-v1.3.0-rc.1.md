## 1. 本版本改动范围

- 新增项目工作台页签“结算与应付”。
- 新增分供合同阶段结算、最终累计结算、正负调整、外部确认、正式过账和独立应付单。
- 结算明细行可选，无清单合同能直接按汇总金额完成结算；明细只有在用户主动提供时才要求合计与报审金额一致，且不要求关联预算清单。
- 新增实际付款对一个或多个应付来源的核销分配和退款反向核销。单笔付款可以拆分到同一应付单的多个到期期次；退款按原分配反向恢复。
- 新增不可覆盖的结算过账快照，记录累计前值、本次增减额和累计后值。
- 新增可选的应付到期分期；到期日自动形成一期，未发生任何付款/退款核销前可改为多期，分期总和严格等于应付净额。
- 新增预付款余额/扣回、质保金留置/释放/核销、供应商发票登记/核验/应付来源分配。
- 保持结算、付款、发票和实际成本不同账本；不把付款或发票自动当成本。
- 新增迁移 `20261014010000_settlement_payables_invoice_retention`，没有修改已交付旧迁移。

## 4. 已知业务边界

- 结算清单行是可选辅助信息，不是必需输入；纯金额模式被列入核心验收场景。
- 应付分期是可选到期安排；设置后总额必须等于应付净额，发生付款/退款核销后分期结构锁定。单笔付款可以分配到该应付单多个不同期次。
- 负向结算调整形成单独的供应商待返还/抵扣余额，自动跨应付抵扣工作流尚未实现。
- 未能可靠匹配到新应付单的历史付款保留为未核销数据，不进行模糊自动核销。
- 发票登记/核验/应付来源分配不是完整的发票、验收、结算三单匹配，不自动生成成本或总账凭证。
- 本模块是分供合同应付台账，不是完整财务总账；主合同侧竣工结算和应收账款不在本次实现范围。
