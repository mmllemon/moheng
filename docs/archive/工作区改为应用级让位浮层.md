# 工作区改为应用级让位浮层

日期：2026-10-23

用户指出：Hana 的是右侧浮层，我做成了项目页里的一个标签。方向错了。

---

## 一、我做错了什么

```
ProjectsPage
  └─ projects-ledger-layout（左右两栏）
       ├─ 左：项目台账
       └─ 右：projects-dossier
              └─ [项目档案 | 工作区]  ← 我加的标签
```

**页面级、只在 `/projects` 存在、挤压主内容宽度。**

## 二、Hana 的真实结构

```jsx
// Gq 组件的两个变体
variant: "tile"    → 嵌在卡片里
variant: "single"  → h.jsxs("div", {
  className: `${ir.previewPanel}${d ? "" : " " + ir.previewPanelCollapsed}`,
  id: "previewPanel",
  "data-preview-open": d ? "true" : "false",
  children: [resize-handle, Vt]
})
```

CSS 关键：

```css
._previewPanel_2e3ae {
  width: var(--preview-panel-width);   /* 580px */
  flex-shrink: 0;
  display: flex;
  flex-direction: column;
  border-left: 1px solid var(--overlay-light);
  transition: width var(--duration-slow) var(--ease-out);
  z-index: 10;
}
._previewPanelCollapsed_04817 { width: 0; border-left: none; }
```

**它是 flex row 里的兄弟项，`flex-shrink: 0` + 固定宽度，主内容 `flex: 1` 自动收缩。**

这就是让位，不是覆盖。

## 四、关键改动

### 4.1 状态提升到全局

```ts
// auth-store.ts
type UiState = {
  workspaceOpen: boolean;
  setWorkspaceOpen: (open: boolean) => void;
  toggleWorkspace: () => void;
}
```

对齐 Hana 的 `previewOpen`（全局状态，不分页面）。

### 4.2 组件改为自包含

```tsx
export function WorkspacePanel(props: Props = {}) {
  // 所有 hooks 必须在提前 return 之前
  const [expanded, setExpanded] = useState(...);
  ...
  const isStandalone = props.projectId === undefined;
  const hidden = isStandalone && (!workspaceOpen || !projectId);
  if (hidden) return null;
  ...
}
```

**hooks 顺序是硬约束**：第一版把 `if (hidden) return null` 放在 `useState` 之前，React 报
`Rendered more hooks than during the previous render`。

### 4.3 项目名从列表查

Layout 不传 `projectName`，组件自己查：

```tsx
const projectsQuery = useQuery({
  queryKey: ['projects'],
  queryFn: () => api.get<Array<{ id: string; name: string }>>('/projects'),
  enabled: Boolean(projectId) && !props.projectName,
});
```

## 五、moheng 特有的三个适配

Hana 的主内容是单栏聊天，收窄没问题。moheng 的项目页内部还有两栏，必须适配。

### 5.1 档案区隐藏

主内容收窄到 662px 后，`projects-ledger-layout` 的
`minmax(0, 1fr) minmax(560px, 1.3fr)` 把左侧压到 78px，「项目台账」标题被压成竖排。

```css
.app-shell:has(.workspace-panel) .projects-ledger-page .projects-dossier { display: none; }
.app-shell:has(.workspace-panel) .projects-ledger-page .projects-ledger-layout {
  grid-template-columns: minmax(0, 1fr);
}
```

**工作区打开时档案区是冗余的**（右侧已经有工作区）。

### 5.2 KPI 卡改两列

四列在 606px 宽度下每列只有 152px，数字拥挤。

```css
.app-shell:has(.workspace-panel) .projects-ledger-page .projects-kpi-strip {
  grid-template-columns: repeat(2, minmax(0, 1fr));
}
```

实测回到 303px/列。

### 5.3 面板底色提亮一档

主内容和面板都是 `--bg`（`rgb(248,244,237)`），只靠 6px 间隙完全看不出边界。

```css
.workspace-panel {
  background: var(--bg-card);                          /* rgb(252,250,245) */
  box-shadow: inset 1px 0 0 var(--overlay-light);      /* 对齐 hana 的 border-left */
}
```

用 `inset shadow` 而不是 `border-left`，因为面板有 22px 圆角，边框会在圆角处被裁成奇怪的竖线。

## 六、踩的坑

### 坑一：CSS 注释缺开头导致整段规则失效

我插入新规则时，把注释的 `/*` 弄丢了，留下裸露文字：

```css
.app-shell:has(.workspace-panel) ... { min-width: 560px; }
   对齐 hana：.app 是 flex row，.main-content 是 flex:1，   ← 没有 /*
   ._previewPanel 是 flex-shrink:0 + 固定宽度
   所以把 .app-shell 改成 row。 */
.app-titlebar { ... }     ← 整块被丢弃
```

**后果**：`.app-titlebar` 的 `display: grid`、`height: var(--titlebar-h)` 全部失效，顶栏变成 `display: block` 且高度 50px。

**发现方式**：CDP `getMatchedStylesForNode` 只返回一条 `article, aside... display:block`，说明主规则根本没解析。

**教训**：CSS 出问题时，先查运行时 CSSOM 里规则是否存在，而不是查 computed value。

### 坑二：`height: 100%` + `margin` 超出容器

```css
.workspace-panel { height: 100%; margin: 6px; }   /* 底部溢出 12px */
```

`height: 100%` 是相对容器高度，加上 margin 就超了。改用 `align-self: stretch`。

### 坑三：空 projectId 发出无效请求

```
404 /api/projects//workspace/tree?path=
```

浮层打开但 store 里没有选中项目。加 `enabled: Boolean(projectId)`。

### 坑四：Hooks 顺序错误

见 4.2。

## 八、与 Hana 的差异

| 项 | Hana | moheng |
|---|---|---|
| 面板背景 | `var(--bg)`（与主内容同色） | `var(--bg-card)`（提亮一档） |
| 分隔方式 | `border-left: 1px` | `inset box-shadow` + 6px 间隙 |
| 圆角 | 无（平铺） | 22px squircle（与卡片壳一致） |
| 主内容适配 | 单栏，无需适配 | 项目页改单栏、KPI 改两列 |
| resize-handle 拖宽 | 有 | 未做 |

**前三项是有意偏离**：moheng 的主内容是圆角卡片，Hana 是平铺。如果照抄 Hana 的平铺 + 左边框，会与卡片壳语言冲突。

**resize-handle 未做**：Hana 支持拖拽改宽，moheng 固定 580px。需要时再加。
