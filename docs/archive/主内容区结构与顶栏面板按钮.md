## 二、顶栏的三段布局

```jsx
function TitlebarFrame({ left, right, renderAction, titleSegment }) {
  const hasLeft = left.length > 0 || titleSegment != null;
  const hasStretch = left.some((a) => a.titlebarTrack === "stretch");

  return (
    <div className={titlebarFrame}
         data-titlebar-frame
         data-islands={hasLeft ? "both" : "right"}
         data-titlebar-track={hasStretch ? "stretch" : undefined}>
      {hasLeft && (
        <div className={titlebarActionIsland} data-titlebar-slot="left" data-titlebar-action-island="left">
          {left.map((a) => <span data-chrome-action-id={a.id}>{renderAction(a)}</span>)}
          {titleSegment}
        </div>
      )}
      <div className={titlebarActionIsland} data-titlebar-slot="right" data-titlebar-action-island="right">
        {right.map((a) => <span data-chrome-action-id={a.id}>{renderAction(a)}</span>)}
      </div>
    </div>
  );
}
```

**左岛 = 面板按钮 + 标题段，右岛 = 系统按钮（收藏 / 截图 / 最小化 / 关闭）。**
