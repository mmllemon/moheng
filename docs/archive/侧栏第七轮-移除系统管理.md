日期：2026-10-23

---

## 一、移除「系统管理」导航项

### 原因

同一个入口在侧栏出现两次：

```
导航列表：  系统管理        ← 已移除
页脚齿轮：  系统设置        ← 保留
```

### 修正

`Layout.tsx` 的 `navigation` 数组里删除：

```tsx
// 删除
{ to: '/system', label: '系统管理', icon: SlidersHorizontal, group: '系统管理', end: false, adminOnly: true },
```

**页脚齿轮入口保留**，`/system` 仍可访问：

```tsx
{user?.role === 'ADMIN' && (
  <button data-tooltip="系统设置" aria-label="系统设置"
          className="sidebar-footer-icon"
          onClick={(e) => { rememberPaperOrigin(e.currentTarget); navigate('/system'); }}>
    <Settings size={15} />
  </button>
)}
```

### 实测

```
侧栏导航项（7 项）:
  经营总览 / 报表中心 / 待办与预警 / 往来单位库
  成本工作台 / 项目档案 / 项目成员与权限

「系统管理」  ✓ 已移除
页脚齿轮入口  ✓ 保留
```

## 二、排序收敛为两种

### 原因

用户要求「排序的分组只做 2 种」，但代码里还有第三种 `recent`（按最近使用）。

`recent` 模式不分组，会渲染一个「项目」标题行——**这正是用户说的「项目」二字出现的地方。**

### 修正

```diff
- export type SortMode = 'time' | 'status' | 'recent';
+ export type SortMode = 'time' | 'status';

- const SORT_LABELS = { time: '按时间', status: '按状态', recent: '按最近' };
+ const SORT_LABELS = { time: '按时间', status: '按状态' };
```

`ProjectList.tsx` 删除 `recent` 分支。

默认值从 `recent` 改为 `time`，并兼容旧的 localStorage 值：

```ts
const raw = localStorage.getItem('moheng.projectSort');
// 只认 time / status。旧版本可能存了 'recent'（已废弃），回落 time。
return raw === 'time' || raw === 'status' ? raw : 'time';
```

### 实测

```
排序菜单:  按时间 / 按状态 / 双行 / 单行
分组标题:  [本年]
「项目」二字  ✓ 已删除（因为 recent 模式已不存在）
```
