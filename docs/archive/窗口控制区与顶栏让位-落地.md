## 三个真实故障

### 故障一：窗口控制区被工作区面板盖住

`elementFromPoint` 在岛中心返回 `workspace-card-top`，说明它被压住。

根因：`z-index: 60` 是相对 `.app-content` 的层叠上下文，而 `.app-content` 有：

```css
overflow: hidden;
isolation: isolate;
```

`position: fixed` 逃不出 `overflow: hidden` 祖先，`z-index` 也只在同一个层叠上下文内比较。

修法：`createPortal(..., document.body)`，挂到 body 级。

修后：

```
elementFromPoint  → 岛内 SVG（isIsland: true）
clippingAncestors → []（无裁剪祖先）
```

### 故障二：`SelectField` / `UiPreferencesBar` 是默认导出

我写了命名导入：

```ts
import { SelectField } from './SelectField';   // ✗ 报 does not provide an export named
```

实际是：

```ts
export default SelectField;
export default function UiPreferencesBar(...)
```

页面直接白屏。改成默认导入。

### 故障三：左岛我删错了（第二次）

上一轮我判断「chat 卡片无左岛」，改成 `data-islands="right"`。这又错了。

源码（`rve`）：

```js
const hasLeft = leftActions.length > 0 || titleSegment != null;
return <div data-islands={hasLeft ? "both" : "right"}>
  {hasLeft && <div data-titlebar-slot="left">{[...leftActions, titleSegment]}</div>}
  <div data-titlebar-slot="right">{rightActions}</div>
</div>;
```

**`titleSegment` 存在时 `data-islands` 就是 `"both"`。** chat 卡片的 `leftActions` 是空数组，但 `titleSegment`（标题）存在，所以有左岛。

现在：`data-islands="both"`，左岛装标题，右岛装面板按钮。

## 让位算法

```js
// 右让位：卡片右缘到窗口控制区左缘
function wot(cardRect, wcRect) {
  const overlapY = cardRect.top < wcRect.bottom && cardRect.top + 44 > wcRect.top;
  const overlapX = cardRect.left < wcRect.right && cardRect.right > wcRect.left;
  if (!overlapY || !overlapX) return null;
  return Math.max(0, Math.round(cardRect.right - (wcRect.left - 4)));
}

// 左让位：卡片左缘到侧栏开关区右缘
function vot(cardRect, stripRect, contentRight) {
  const overlapY = …;
  const overlapX = …;
  if (!overlapY || !overlapX) return null;
  return Math.max(0, Math.round(contentRight + 4 - cardRect.left));
}
```

`lib/use-titlebar-clearance.ts` 实现，用 `ResizeObserver` + 2 帧稳定：

```ts
const tick = () => {
  measure();
  settle = Math.max(0, settle - 1);
  if (settle > 0) raf = requestAnimationFrame(tick);
};
const schedule = () => { settle = 2; cancelAnimationFrame(raf); raf = requestAnimationFrame(tick); };
```

**运行时测量，不是写死 padding。** 侧栏拖动、面板开合、窗口缩放都会重新测。

接入两个地方：

```tsx
// 主内容区顶栏
<header className="app-titlebar" style={{ '--titlebar-clearance-right': `${clearance.right ?? 0}px` }}>
```
```css
.app-titlebar { padding-right: calc(var(--space-12) + var(--titlebar-clearance-right, 0px)); }
```

```tsx
// 工作区面板
<aside className="workspace-panel" ref={panelRef} style={{ '--card-clearance-right': `${cardClearance.right ?? 0}px` }}>
```
```css
.workspace-card-top { padding-right: calc(var(--space-16, 16px) + var(--card-clearance-right, 0px)); }
```

## 四条门禁断言同步

系统按钮移到 `WindowControls` 后，四条断言检查的 `layout` 里找不到代码了。按「断言失效必须修断言或修代码」的原则同步：

| 断言 | 改动 |
|---|---|
| `quick panel is wired` | 检查 `layout + windowControls` |
| `paper morph` | `quickActionsOpen` 的 focus-trap 改查 `windowControls` |
| `project selector lives in titlebar` | `titlebar-project` 改查 `windowControls` |
| `focus-trapped` | `quickActionsOpen` / `accountMenuOpen` 改查 `windowControls` |

**代码是正确的（按钮确实移到了窗口控制区），断言跟着代码走。**
