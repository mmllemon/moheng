# 窗口按钮样式与卡片外层：两处修正

日期：2026-10-24

## 一、窗口按钮：46px 直角，不是 28×28 圆角

我按顶栏按钮的规格（28×28 + 3px 透明边 + squircle）做了窗口按钮，这是错的。

Hana 的真值：

```css
/* 通用按钮规格（顶栏 / 卡片用） */
._sdbBtn_e792e, ._tileTopBtn_8667c {
  width: calc(var(--card-top-btn-size, 24px) + var(--card-top-btn-pad, 2px) * 2);   /* 28 */
  height: calc(...);                                                                /* 28 */
  border: var(--card-top-btn-hover-inset, 3px) solid transparent;
  background-clip: padding-box;
  border-radius: calc(var(--chalkboard-...));
}

/* Windows 标题栏模式下覆盖 —— 窗口按钮 */
._windowTitlebarFrame[data-window-titlebar-enabled]
  ._windowControlsIsland[data-window-titlebar-controls]
  ._tileTopBtn_8667c {
  width: 46px;                          /* ← 46px，不是 28 */
  height: var(--window-titlebar-height);
  padding-top: var(--space-4);
  border-width: 0;                      /* ← 无透明边框 */
  border-radius: 0;                     /* ← 直角 */
}
```

**窗口按钮是 46px 宽、直角、无透明边框。** 这符合 Windows 原生标题栏的观感（最小化/最大化/关闭是等宽矩形块）。

已改：

```css
.window-control-btn {
  width: 46px;
  height: var(--window-titlebar-height, 32px);
  padding-top: var(--space-4, 4px);
  border: 0;
  border-radius: 0;
}
```

## 二、按钮底衬（`::before`）—— 我完全没做

Hana 的顶栏按钮有一个向外扩 3px 的底衬：

```css
._sdbBtn_e792e::before {
  content: "";
  position: absolute;
  inset: calc(-1 * var(--card-top-btn-hover-inset, 3px));   /* 向外扩 3px */
  z-index: var(--z-under);
  background-color: var(--titlebar-action-bg, var(--icon-halo-bg, var(--bg)));
  border: var(--titlebar-action-border, var(--panel-card-border));
  backdrop-filter: var(--titlebar-action-veil, none);
}
```

**作用是：按钮浮在内容上方时，底衬保证它在任何背景上都可读。** 配合 `_tray` 的 `--titlebar-action-veil` 毛玻璃一起用。

这一项在 moheng 里暂时不需要（顶栏和卡片不重叠），但如果将来做「按钮浮在滚动内容上」，必须补。

## 三、卡片外面没有容器

你问「文件的卡片外面是不是还嵌套了卡片」。**是，我多包了一层。**

Hana 的真值：

```css
/* 卡片外壳本身 */
._tileShell_3a897 {
  width: calc(100% - 2 * var(--tile-gutter));
  height: calc(100% - 2 * var(--tile-gutter));
  margin: var(--tile-gutter);
  border-radius: calc(var(--panel-card-radius) * var(--corner-radius-scale, 1));
  corner-shape: squircle;
}

/* surface: card 时，tileShell 自带边框和背景 */
._tileCard_1790b {
  border: var(--card-border-width, 1px) solid var(--card-border-color, rgba(0, 0, 0, .08));
  background: var(--panel-card-bg);
  overflow: hidden;
}
```

**`_tileShell` 就是卡片，没有外层容器。** 它是 `_canvas_4bffb` 的直接子元素。

`_cardStack_09a29` 属于 `CapabilitiesPanel` 的 `Nr` 组件（侧边面板的卡片栈），**files 卡片走 chalkboard 的 `tileShell` 渲染，不经过它**。

我多包的 `.workspace-card-stack` 已删除。现在：

```
.workspace-panel（flex column, gap 6px, padding 8px 6px 46px）
├─ .workspace-resize-handle
├─ .workspace-card-main       388×834   ← 直接子元素
└─ .workspace-jian-drawer
```

## 四、顺带修正底色层次

去掉容器后暴露一个问题：面板和卡片同色，看不出层次。

Hana 的真值：

```css
._tray_8a862   { background: var(--bg); }              /* 面板 */
._card_6a18e   { background: var(--bg-card, var(--bg)); }  /* 卡片 */
```

**面板用 `--bg`，卡片用 `--bg-card`。**

我之前把面板写成 `--bg-card`（理由是「比主内容亮一档」），结果与卡片同色。已改回 `--bg`。

## 五、一个反复出现的错误模式

这一轮和上一轮各犯一次：

| 错误 | 原因 |
|---|---|
| 窗口按钮用 28×28 | 把顶栏按钮的规格套到窗口按钮上 |
| 卡片外多包一层 | 把 `_cardStack`（侧边面板的）当成 files 卡片的容器 |

**共同点：我看到一个类存在，就假设它用在这里，没确认它属于哪个组件、哪个条件分支。**

这和之前几次（`−` 是窗口还是卡片、tab 是滑块还是卡片式）是同一个问题。

**验证方法**：找到类名后，先问「它的父元素是谁、由哪个组件渲染」，而不是「它的 CSS 长什么样」。
