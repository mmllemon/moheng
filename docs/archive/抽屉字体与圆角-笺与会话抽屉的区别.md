# 抽屉字体与圆角：我又用错了组件

日期：2026-10-25

## 两处错的根因是同一个：混淆了「笺」和「会话抽屉」

hana 里有两个完全不同的抽屉：

| | 笺 `_jianDrawer_57159` | 会话抽屉 `_workspaceDrawerLayer_322c5` |
|---|---|---|
| 定位 | `position: absolute`，左右 6px 浮层 | **文档流**，负 margin 叠纸 |
| 底色 | `--jian-note-bg` = `#FAF0E2` 暖米色 | `--panel-card-bg`（与卡片同色） |
| 标题 | `_jianTitle_cc28c`：`0.94rem / 600 / --text-light` | `_title_c119b`：`--fs-body / 500 / --accent` |
| 内部结构 | 笔记编辑器 | `universal-card`（header / body / facts） |
| 用途 | 笔记 | 本次对话、后台任务 |

用户对比的是「本次对话」，那是**会话抽屉**。我用的是「笺」的规格，所以字体和圆角都错。

## 叠纸层的真值

```css
._workspaceDrawerLayer_322c5 {
  position: relative;
  z-index: calc(var(--workspace-drawer-count, 0) - var(--workspace-drawer-index, 0));
  flex: 0 0 auto;
  display: flex; flex-direction: column;
  overflow: hidden;
  background: var(--panel-card-bg);
  margin-top: calc(-1 * var(--workspace-drawer-overlap));   /* -10px */
  padding-top: var(--workspace-drawer-overlap);             /* 10px */
}

/* 最后一层四角全圆 */
._workspaceDrawerStack ._workspaceDrawerLayer:not(:last-child) {
  border-radius: 0 0 outer outer;
  border: 1px solid var(--card-border-color);
  border-top: 0;
  margin-left: -1px; margin-right: -1px;
  box-shadow: var(--workspace-drawer-shadow);
}

/* 关键：内部卡片被强制剥光 */
._workspaceDrawerStack ._workspaceDrawerLayer > * {
  flex: 1 1 auto;
  min-height: 0;
  max-height: none;
  overflow-y: auto;
  border: 0;
  border-radius: 0;
  background: transparent;
  box-shadow: none;
}
```

**圆角、边框、底色全部由 `layer` 提供，内部卡片必须透明。** 我之前给内部卡片自己设了 `radius: 14.7272px` + `bg` + `border`，看起来是「卡片里套卡片」。

## 列表让位

抽屉走文档流后自己占布局空间，列表不再需要 52px 让位。只留 18px 覆盖叠纸侵入的 10px：

```css
.workspace-tree {
  padding: 4px 2px calc(10px + var(--space-8));
  scroll-padding-bottom: calc(10px + var(--space-8));
}
```

实测滚到底：`lastRowBottom 377 < layerTop 394`，`covered 0`。
