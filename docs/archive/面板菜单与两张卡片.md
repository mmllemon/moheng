## 一、面板菜单（`chalkboard.chat.panel-menu`）

### 1.1 Hana 的真实实现

```js
// CardShell 里注册
On("chalkboard.chat.panel-toggle", Wve);   // 单个开关（按 entry 决定）
On("chalkboard.chat.panel-menu", Hve);     // 下拉菜单

// Hve 的组装
h.jsx(Tb, {
  buttonLabel: n2("chalkboard.panelMenu.button"),
  icon: <fD />,          // 有活动点时叠一个 5×5 圆点
  align: "end",
  items: [...o, ...a],   // 5 个面板项 + 2 个视图项
  minWidth: 144,
})
```

**菜单项（`ZW()` 定义）**：

| id | label | 作用 |
|---|---|---|
| `preview` | `chalkboard.panelMenu.preview` | 预览面板开合 |
| `terminal` | `...terminal` | 终端面板 |
| `workspace` | `...workspace` | 工作区面板 |
| `subProcesses` | `...subProcesses` | 子进程（带活动点） |
| `browser` | `...browser` | 内置浏览器（需桌面端） |
| `chatViewSerene` | `chatView.serene` | 沉浸视图（radio） |
| `chatViewClassic` | `chatView.classic` | 经典视图（radio） |

前 5 项是 `menuitemcheckbox`，后 2 项是 `menuitemradio`（中间有分隔线）。

### 1.3 moheng 的裁剪

只保留 moheng 有对应业务的两项：

| Hana | moheng | 理由 |
|---|---|---|
| `preview` | 预览 | 工作区浮层开合 |
| `workspace` | 工作区 | 同上面板 |
| `terminal` | 不做 | moheng 无终端 |
| `subProcesses` | 不做 | 无子进程 |
| `browser` | 不做 | 无内置浏览器 |
| `chatViewSerene/Classic` | 不做 | 无会话视图模式 |

```
菜单项     28px 高 / 9.20448px 圆角 / role=menuitemcheckbox
```

## 二、两张卡片（`_workspaceCardMain` + `_jianDrawer`）

### 2.1 Hana 的结构

右侧浮层里不是一张卡片，是两张：

```css
/* 卡片一：文件（占满剩余高度） */
._workspaceCardMain_a2a0f {
  flex: 1 1 auto;
  --right-workspace-jian-open-height: 320px;
  --right-workspace-jian-closed-height: 40px;
  --right-workspace-jian-bottom: var(--panel-edge-gap);   /* 6px */
}

/* 卡片二：工作室（笺）。浮在底部。 */
._jianDrawer_57159 {
  position: absolute;
  left: var(--panel-edge-gap);      /* 6px */
  right: var(--panel-edge-gap);
  bottom: var(--right-workspace-jian-bottom);
  z-index: 2;
  height: var(--right-workspace-jian-open-height);   /* 320px */
  border-radius: calc(var(--radius-md) * var(--corner-radius-scale));
  corner-shape: squircle;
  border: 1px solid var(--jian-note-border, rgba(200, 160, 110, .2));
  background: var(--jian-note-bg, #FAF0E2);          /* 暖米色 */
  box-shadow: 0 2px 8px #0000000f;
  transition: height .4s cubic-bezier(.22, 1, .36, 1);
}
._jianDrawer[data-open=false] {
  height: var(--right-workspace-jian-closed-height); /* 40px */
}
```

**关键**：工作室卡片不是纸色，是**暖米色 `#FAF0E2`**，带 1px 暖边框。这是它和文件卡片视觉分开的原因。

### 2.2 moheng 的实现

```
.workspace-panel (580px, flex column)
  ├─ .workspace-card-main    文件卡片，占满，margin-bottom: 46px
  └─ .workspace-card-studio  工作室卡片，absolute bottom 6px，40px / 320px
```

实测：

```
文件卡片     580×842，14.73px 圆角，bg rgb(252,250,245)
工作室卡片   568×40（收起）→ 320（展开），bg rgb(250,240,226)
```

**`rgb(250,240,226)` 就是 `#FAF0E2`**，与 Hana 逐位一致。

## 三、这一轮做错的两件事

### 3.1 我加了两个并列按钮

我看到截图里有两个图标，就做了两个独立开关。**实际是一个菜单按钮 + 下拉菜单。**

第二个图标是「层叠」形状，是菜单的触发按钮；左边那个「文件夹」是另一个入口。

### 3.2 我把预览和工作室塞进一张卡片

我把文件树和预览放在同一个 flex column 里，用 `border-top` 分隔。**实际是两张独立卡片**，工作室卡片有完全不同的底色（暖米色）和独立圆角、阴影。
