# 右侧浮层是「容器 + 卡片栈」：完整源码结构

日期：2026-10-24

## 结论

你的猜测对了。Hana 的右侧浮层不是一张卡，是**容器（tray）+ 卡片栈（cardStack）**，卡片按状态动态生成，最多 12 张。

我之前只挖到 `_workspaceCardMain` 就收手，把它当成了整个面板。那是这个栈里的**一张卡**。

## 完整组件：`Nr`（CapabilitiesPanel）

```jsx
function Nr({ l1Tabs, activeL1, onL1Change, onClose, agentRow, cardTopSlot,
              children, drawer, loading, emptyLabel, width, frame, id,
              loadingLabel, closeLabel, headerActions }) {

  // ── 单张卡片 ──
  const card = (
    <div className={Pe.card} data-stacked={drawer != null || undefined} data-side-panel-card>
      {cardTopSlot != null && <div className={Pe.cardTop}>{cardTopSlot}</div>}
      <div className={Pe.cardScroll}>
        {loading ? <div className={Pe.stateMessage}>{loadingLabel}</div>
              : empty   ? <div className={Pe.stateMessage}>{emptyLabel}</div>
              : children}
      </div>
    </div>
  );

  return (
    <div className={`${Ye.floatingPanel} ...`} id={id}>
      <div className={`${Ye.floatingPanelInner} ${Pe.tray}`}>

        <Hd />                                    {/* 纸纹层 */}

        <div className={Pe.trayHeader}>           {/* 一级标签栏 */}
          <div className={Pe.l1Tabs} role="tablist">
            {l1Tabs.map((tab) => (
              <button role="tab" aria-selected={tab.id === activeL1} className={Pe.l1Tab}>
                {tab.icon && <span className={Pe.l1TabIcon}>{tab.icon}</span>}
                <span className={Pe.l1TabLabel}>{tab.label}</span>
              </button>
            ))}
          </div>
          <div className={Pe.headerActions}>
            {headerActions}
            <button className={Pe.close} aria-label={closeLabel}><X size={14} /></button>
          </div>
        </div>

        {agentRow != null && <div className={Pe.agentRowSlot}>{agentRow}</div>}

        {/* ── 卡片栈：有 drawer 时叠两层 ── */}
        {drawer != null
          ? <div className={Pe.cardStack} data-side-panel-stack>
              <div className={Pe.cardLift} data-side-panel-lift>{card}</div>
              <div className={Pe.drawer} data-side-panel-drawer>{drawer}</div>
            </div>
          : card}
      </div>
    </div>
  );
}
```

## 三层结构（对应你截图里的视觉）

```
tray（浮层容器）
├─ 纸纹层 Hd
├─ trayHeader          一级标签栏 + 右侧操作 + 关闭
├─ agentRowSlot        agent 行（可选）
└─ cardStack           卡片栈（纵向）
    ├─ cardLift        主卡层（z-index: 2）
    │   └─ card        单张卡
    │       ├─ cardTop     卡头（标题 + 按钮组）
    │       └─ cardScroll  卡内容
    └─ drawer          抽屉层（可选，叠在下面）
```

**截图 1 的「文件」+「文件」两张卡，就是 `cardStack` 里纵向排的两个 `card`。**
**截图 2 多出的「后台任务」是第三个 `card`。**

## 卡片是动态生成的，最多 12 张

## moheng 现在的差距

```
Hana                          moheng
─────────────────────────────────────────────────────
tray（浮层容器，有纸纹）      .workspace-panel（有纸纹）
trayHeader（一级标签栏）      ✗ 没有（标签栏在卡内）
agentRowSlot                 ✗ 没有
cardStack（纵向 flex）        ✗ 没有（两张卡是各自绝对定位）
card × N（动态，≤12）        2 张写死（main / studio）
cardTop（卡头 + 按钮组）      .workspace-studio-head（只有工作室卡有）
cardScroll（卡内容滚动）      各卡自己滚
```

**最根本的差距：moheng 的两张卡是「大卡占满 + 小卡绝对定位浮在底部」，Hana 是「flex column 平铺，每张卡 flex: 1」。**

## 落地需要改的

**1. 容器层**
`.workspace-panel` 内加 `.workspace-card-stack`（`flex: 1; flex-direction: column; margin: 6px; margin-top: 8px`）。

**2. 卡片层**
每张卡改成 `flex: 1; min-height: 0; margin: 0`，删掉绝对定位。

**3. 卡头层**
每张卡加 `.workspace-card-top`（`padding: 12px 16px 8px; gap: 8px`），放标题 + 按钮组。

**4. 卡片定义表**
把「文件」「预览」写成定义表 + `visibleWhen`，而不是写死两个 `<section>`。

**5. 一级标签栏**
`trayHeader` 在卡片栈之上，与卡内标签不是同一层。moheng 现在把「对话文件 / 工作室」放在卡内，需要判断它属于哪一层。

按 Hana 的 `kY`，「对话文件 / 工作室」是**卡片定义**（`rightWorkspace.tabs.sessionFiles` / `rightWorkspace.tabs.workspace`），不是一级标签。所以现在的位置（卡内）是对的，但缺 trayHeader。

**这一步需要你确认**：moheng 要不要一级标签栏？Hana 的一级标签是「聊天 / 频道 / 终端」这类顶层视图切换，moheng 没有对应物。如果没有，`trayHeader` 可以只保留右侧的关闭按钮。

## 要不要现在改

改动量比前几轮大（容器 + 卡片 + 卡头三层都要动，还要引入定义表）。

建议顺序：

1. **先改容器与卡片布局**（把绝对定位改成 flex column 平铺）——这一步视觉变化最明显，也是你说的「上下两个卡片」
2. **再加卡头层**（每张卡独立的标题 + 按钮组）
3. **最后做定义表 + visibleWhen**（为将来加第三张卡做准备）
