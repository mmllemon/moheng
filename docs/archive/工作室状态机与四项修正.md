# 工作室状态机与四项修正

日期：2026-10-24

## 一、工作室的状态机（深挖结果）

Hana 的工作室不是「一种结构」，是**两态 + 四种树状态**。

### 两态：外层 / 内层

```jsx
<div className={stage}
     data-studio-stage
     data-inner={inner ? '' : undefined}
     data-studio-transition={transitionEnabled ? undefined : ''}>
  {inner && <Toolbar state showPreviewToggle tone="system" />}
  <Chrome inner query folderName onBack canAdd browse t />
  <div className={layers}>
    <div className={layerList} data-studio-layer="list"><MountList /></div>
    <div className={layerTree} data-studio-layer="tree">
      {mountId ? <Tree mountId /> : null}
    </div>
  </div>
</div>
```

| | 外层（`data-inner` 缺失） | 内层（`data-inner` 存在） |
|---|---|---|
| 工具条 | **不渲染** | 渲染（预览开关 + 筛选 + 排序） |
| 返回按钮 | `width: 0; opacity: 0` | `width: 32px; opacity: 1` |
| 添加按钮 | 展开 | `width: 0; opacity: 0` |
| 显示层 | `layerList`（挂载点列表） | `layerTree`（目录树） |
| 层切换 | `translate(0)` / `translate(100%)` | `translate(-100%)` / `translate(0)` |

### 四种树状态

```jsx
function Tree({ mountId, browse, jian, toolbarState }) {
  const mount = findMount(mountId);
  const status = mount ? checkMount(mount) : null;    // 'missing' | 'offline'
  const ready = browse.isReady(mountId);
  const treeState = status ?? (ready ? 'ready' : failed ? 'failed' : 'loading');

  let content = null;
  if (status === 'missing') {
    content = <Empty title="目录不存在" action={<Btn>重新定位</Btn>} />;
  } else if (status === 'offline') {
    content = <Empty title="设备离线" />;
  } else if (ready) {
    content = <>
      <FileTree framed={false} showHeader={false} rightWorkspaceLayout
                hideSearch showToolbar={false} toolbarState scrollRef />
      {jian && <><JianDrawer /><JianToggle /></>}
    </>;
  } else if (failed) {
    content = <div className={empty}>目录不可用</div>;
  }

  return (
    <div className={tree}
         data-studio-view="tree"
         data-studio-mount={mountId}
         data-studio-tree-state={treeState}      // ← loading / ready / failed / missing / offline
         data-jian={jian ? undefined : 'off'}>
      <div className={treeBody}>{content}</div>
    </div>
  );
}
```

**五种状态**：`loading` / `ready` / `failed` / `missing` / `offline`。

## 二、四项修正

### 修正 1：预览是独立卡片

Hana 里 `[By]`（preview）和 `[h4]`（files）是**两个独立卡片定义**，不是同一卡片的两个 tab：

```js
[By]: {
  titleKey: "chalkboard.tile.preview",
  surface: "card",
  closable: true,
  sizing: { role: "fixed", minPx: 320, defaultPx: 400 },
  chrome: [
    { id: "chalkboard.preview.tabs",    slot: "titlebar-left",  titlebarTrack: "stretch" },
    { id: "chalkboard.preview.actions", slot: "titlebar-right" },
  ],
  onClose: () => setChalkboardPreviewOpen(false),
}
```

moheng 的「对话文件 / 工作室」是 files 卡片的两个 stackItem（`kY` 定义），预览是另一张卡。这个结构已经对了（两张卡 + visibleWhen）。

### 修正 2：文件卡头只有 ×

`dve` 是卡头按钮的唯一来源：

```js
function dve(opts) {
  const list = [];
  if (opts.detached) { /* dock-back, pin */ }
  if (opts.favoritable)   list.push({ id: 'favorite',      order: 9000 });
  if (opts.starable)      list.push({ id: 'favoriteStar',  order: 9001 });
  if (opts.screenshotable) list.push({ id: 'screenshot',   order: 9002 });
  if (opts.exportable)    list.push({ id: 'export',        order: 9005 });
  if (opts.detached) { /* minimize, full-screen */ }
  if (opts.closable)      list.push({ id: 'close',         order: 9010 });
  return list;
}
```

files 卡片 `[h4]` 只有 `closable: true`，其余全是 false/undefined。**所以卡头只有 ×。**

我加的上传 / 刷新已删除。

### 修正 3：筛选和排序做成真功能

```tsx
const [deskSortMode, setDeskSortMode] = useState<'name' | 'mtime' | 'size'>('name');
const [typeFilters, setTypeFilters] = useState<Set<string>>(new Set());

const filteredEntries = useMemo(() => {
  const kindOf = (e) => {
    const x = (e.ext ?? '').toLowerCase().replace(/^\./, '');
    if (['png','jpg','jpeg','webp','gif','bmp','svg'].includes(x)) return 'image';
    if (['mp4','webm','mov','avi','mkv'].includes(x)) return 'video';
    if (['txt','md','json','csv','log','xml','yaml','yml'].includes(x)) return 'text';
    return 'other';
  };
  let list = rootEntries;
  if (typeFilters.size > 0) list = list.filter((e) => e.isDir || typeFilters.has(kindOf(e)));
  return [...list].sort((a, b) => {
    if (a.isDir !== b.isDir) return a.isDir ? -1 : 1;    // 目录永远在前
    if (deskSortMode === 'mtime') return (b.mtime ?? '').localeCompare(a.mtime ?? '');
    if (deskSortMode === 'size') return (b.size ?? 0) - (a.size ?? 0);
    return a.name.localeCompare(b.name, 'zh-CN');
  });
}, [rootEntries, typeFilters, deskSortMode]);
```

菜单：

```
筛选：图片 / 文本 / 视频（可多选，5px accent 圆点表示选中）
排序：名称 / 修改时间 / 大小（单选）
```

实测：

```
筛选「图片」前  9 个文件
筛选「图片」后  1 个（照片.png）
```

### 修正 4：工作室两态

`innerDir` 状态控制 `data-inner`：

```tsx
onClick={() => { setWorkspaceTab('studio'); setInnerDir(''); }}    // 进入内层
onClick={() => { setWorkspaceTab('files'); setInnerDir(null); }}   // 回外层
```

工具条只在 `innerDir !== null` 时渲染。

实测：

```
外层  stageInner=null  toolbarVisible=false
内层  stageInner=""    toolbarVisible=true
```

## 三、层级修正

原来把 chrome 和 stage 包在 `workspace-card-scroll` 里，导致 stage 从 y=525 才开始。

Hana 的结构里 chrome / toolbar 是卡片的**直接子元素**，只有内容区自己滚：

```
section.workspace-card
├─ .workspace-card-top        卡头
├─ .workspace-tab-bar         tab
├─ .workspace-toolbar         工具条（内层才渲染）
├─ .workspace-chrome          chrome
└─ .workspace-stage           内容区（自己滚）
```

去掉 card-scroll 后：

```
toolbar  y=99   36px
chrome   y=141  38px
stage    y=173  714px   ← 从 525 上移，高度从 362 增到 714
```

## 四、五处 CSS 顺序/层级陷阱（这一轮踩的）

**一、JSX 嵌套错误查了 6 轮**

`workspace-toolbar` 的闭合 `</div>` 丢了，导致整个 section 少一层。babel 报 `Expected corresponding JSX closing tag for <div>` 在 590，但真凶在 449。

**定位方法**：用 `@babel/parser` 直接解析拿准确行号，再用标签栈脚本逐行追踪深度。

**二、`background-clip` 被 `background` 简写重置**（上一轮）

**三、`flex: 0 0 auto` 让 `calc((100% - 6px)/2)` 算成 45px**（这一轮）

**四、`overflow-y: auto` 让 flex 子项高度塌成 0**（上一轮）

**五、`data-inner` 两态需要显式 `setInnerDir` 触发**，不会自动。
