## 三个修正

### 一、滑块宽度从 45px 到 167px

根因：`.workspace-tabs` 用了 `flex: 0 0 auto`，容器按内容收缩，`calc((100% - 6px)/2)` 算出来只有 45px。

Hana 真值：

```css
._tabs_22ed1 {
  display: grid;
  grid-template-columns: repeat(2, minmax(0, 1fr));
  gap: var(--space-2);
  margin: 0 var(--space-8);
  padding: var(--space-2);
}
._tabSlider_f4978 {
  width: calc((100% - 6px) / 2);
}
```

改成 `flex: 1 1 auto` 后：

```
tabs      342×26
滑块      167×20     ← 与 tab 按钮等宽
tab[对话文件] 167px
tab[工作室]   167px
```

### 二、项目选择器移回顶栏

从窗口控制区移到顶栏右岛。窗口控制区只装全局系统按钮（搜索 / 待办 / 快捷 / 设置 / 头像）。

## 两个实现细节

**一、抽屉是叠在卡片上，不是推上去**

我先给卡片栈加了 `padding-bottom: 46px`，那会把卡片整体推上去，与 Hana 不同。

Hana 的做法是 `data-workspace-drawers` 时主卡只保下沿圆角，抽屉 absolute 叠在下方。所以去掉 padding。

**二、折叠开关从 absolute 移到 header 内**

Hana 的 `_jianToggle_4a152` 是 `position: absolute; right: 12px; bottom: 12px`，会压在列表最后一行上。

实测确实压住了。改成放进 header 右侧（`justify-content: space-between`），不遮内容。

**这是有意偏离**：Hana 的开关浮在抽屉右下角，但那是因为它下面没有内容；moheng 的抽屉是文件列表，会被压住。

## 一处仍需确认

Hana 的抽屉内容是笔记编辑器（`data-desk-editor`）。moheng 换成文件列表后，**抽屉展开时会遮住文件卡片的列表下半部分**（这是 absolute 叠加的必然结果）。

如果你希望抽屉展开时卡片自动让位（缩小），那是另一种布局（`flex` 挤压而非叠加），需要改 `--right-workspace-jian-reserved` 的用法。要做吗？
