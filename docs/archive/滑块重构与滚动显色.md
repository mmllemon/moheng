```css
html:not([data-platform=win32]) ._sessionPanel_73d9c._is-scrolling_36f8c::-webkit-scrollbar-thumb {
  background: #80808040;
}
```

**滚动时加 `is-scrolling`，800ms 后移除。**

### 我之前的错误

我用的是 `:hover::-webkit-scrollbar-thumb`，这有两个问题：

1. 鼠标在页面任意位置都会触发，等于常亮
2. 用户**滚动时**如果鼠标不在容器上（比如用键盘或触控板），反而看不到

### 交付

新建 `lib/scroll-indicator.ts`：

```ts
export function useScrollIndicator(ref, { className = 'is-scrolling', delay = 800, selector }) {
  // selector 模式下用事件委托：scroll 不冒泡，但捕获阶段可以在 host 上收到
  host.addEventListener('scroll', onScroll, { passive: true, capture: true });
  // 滚动 → addClass，clearTimeout，setTimeout(removeClass, 800)
}
```

**一个真实的坑**：`.settings-content` 自己不滚（`scrollHeight === clientHeight`），真实滚动容器是它内部的 `.route-transition`。所以 hook 需要 `selector` 模式 + 捕获阶段监听。

### 实测

```

```

## 三、字体对比度：不是滑块，是分段按钮组

### hana 的真实实现

```js
// 档位
Sd = [-2, -1, 0, 1, 2]

// 格式化
function ri(e) { return e > 0 ? `+${e}` : String(e); }

// 选项
te = Sd.map((j) => {
  const H = ri(Cd(j));
  return { value: String(j), level: j, label: H, valueLabel: H };
});

// JSX
<G label={a("settings.appearance.contentContrast")}
   control={<Vt ariaLabel={...} options={te} value={String(we)} onChange={...} />} />
```

**`Vt` 是分段按钮组**，与「正文字号」「正文字号偏移」使用同一个控件。

### 我之前的错误

我用的是 `StepSlider`（滑块）。**形态完全错了。**

### 修正

改用 moheng 已有的 `settings-segment`（32px 高、按钮 28px、`is-active` 态），标签按 `ri()` 规则生成：

```tsx
{CONTENT_CONTRAST_LEVELS.map((level, index) => {
  const offset = index - 2;                       // -2 .. +2
  const label = offset > 0 ? `+${offset}` : String(offset);
  return <button role="radio" aria-checked={index === contrastIndex}
                 className={index === contrastIndex ? 'is-active' : ''}>{label}</button>;
})}
```

## 五、方法教训

**这轮三个问题都是「控件选错」或「机制理解错」，不是数值偏差。**

| 问题 | 我的假设 | hana 实际 |
|---|---|---|
| 滑块 | 粗 bar 分段 | 细线分段（2px 间隙）+ 叠加圆滑块 |
| 滚动显色 | `:hover` 触发 | `is-scrolling` 类 + 800ms 定时器 |
| 字体对比度 | 滑块 | 分段按钮组（与字号同一控件） |

**共同点：我从「看起来差不多」推导实现，而不是从源码找组件类型。**

正确做法：**先确认「这是哪一类控件」，再确认「它的参数」。** 控件类型错了，参数调得再准也没用。
