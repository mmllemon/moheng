# 抽屉叠纸 + 底栏滑块导航

日期：2026-10-25

## 一、抽屉叠纸

### 结构必须是两层

第一版我把 hana 的两层合并成一层，结果暖米色丢失、圆角变 0。

```jsx
{/* hana 真实结构 */}
<div className={workspaceDrawerStack}>          {/* flex: 0 0 auto; max-height: 64% */}
  <div className={workspaceDrawerLayer}>         {/* 纸层：-10px 叠纸 + panel-card-bg */}
    <JianDrawer />                               {/* 便签本体：#FAF0E2 + radius-md */}
  </div>
</div>
```

```css
/* 纸层 */
._workspaceDrawerLayer_322c5 {
  position: relative;
  z-index: calc(var(--workspace-drawer-count, 0) - var(--workspace-drawer-index, 0));
  flex: 0 0 auto;
  min-height: 0;
  display: flex;
  flex-direction: column;
  overflow: hidden;
  background: var(--panel-card-bg);
  margin-top: calc(-1 * var(--workspace-drawer-overlap));   /* -10px */
  padding-top: var(--workspace-drawer-overlap);              /* 10px */
}

/* 非末层：只保下沿圆角 */
._workspaceDrawerStack ._workspaceDrawerLayer:not(:last-child) {
  border-radius: 0 0 calc(var(--workspace-drawer-outer-radius) * scale) calc(...);
  border: 1px solid var(--card-border-color);
  border-top: 0;
  margin-left: -1px;
  margin-right: -1px;
  box-shadow: var(--workspace-drawer-shadow);
}

/* 有抽屉时主区只保下沿圆角 */
._workspaceCardSurface[data-workspace-drawers] ._workspaceCardMain {
  z-index: calc(var(--workspace-drawer-count) + 1);
  background: var(--panel-card-bg);
  border-radius: 0 0 calc(outer × scale) calc(outer × scale);
  border: 1px solid var(--card-border-color);
  border-top: 0;
  margin-left: -1px;
  margin-right: -1px;
  box-shadow: var(--workspace-drawer-shadow);
}
```

变量在卡片根部：

```css
._workspaceCardSurface_cbdb6 {
  --workspace-drawer-radius: calc(var(--panel-card-radius) - 1px);
  --workspace-drawer-outer-radius: calc(var(--workspace-drawer-radius) + 1px);
  --workspace-drawer-overlap: 10px;
  --workspace-drawer-shadow: 0 2px 4px -2px color-mix(in srgb, var(--shadow) 62%, transparent);
}
```

`margin-top: -10px` 是**无条件生效**的，单层也一样 —— 让抽屉上沿藏到主卡下面 10px，形成压叠感。

### 实测

```
收起   card 6~427   main 7~396    layer y=376  mt -10px  pt 10px  z=1
                                  drawer y=386  h=40   bg #FAF0E2  radius 14.7272px
展开   drawer y=158  h=320        layer 仍 -10px（叠纸在展开态也保持）
```

`main` 的圆角是 `0 0 22.0908px 22.0908px` —— 只保下沿，与抽屉咬合。

## 二、底栏滑块导航

### 宽度真值

```css
--chat-column-width: 720px;
--chat-copy-column: var(--chat-column-width);          /* 720px */
--chat-input-column-extra: 1.25rem;                     /* 20px */
--chat-input-column-width: calc(720px + 20px);          /* = 740px */
--welcome-chat-input-column-width: 40rem;               /* 640px */
```

**对话输入框比对话列宽多 20px**（`--chat-input-column-extra`）。

moheng 底栏原来 `fit-content` 832px，改成 `max-width: calc(720px + 1.25rem)` = **740px**。

### 滑块真值

```css
._tabs_22ed1 {
  display: grid;
  grid-template-columns: repeat(2, minmax(0, 1fr));
  gap: var(--space-2);
  margin: 0 var(--space-8);
  padding: var(--space-2);
  background: var(--overlay-subtle);
  border: 1px solid var(--overlay-light);
  border-radius: calc(var(--radius-sm) * scale);

._tabSlider_f4978 {
  position: absolute;
  top/bottom/left: var(--space-2);
  z-index: 0;
  width: calc((100% - 6px) / 2);
  border-radius: calc(max(2px, calc(var(--radius-sm) - 2px)) * scale);
  background: var(--bg-card);
  box-shadow: 0 1px 3px var(--shadow);

```

**关键：选中态不靠文字变色，只靠滑块位移。**

moheng 有 9 个标签而不是 2 个，所以列数用变量：

```css

width: calc((100% - (var(--tab-count) + 1) * var(--space-2)) / var(--tab-count));
transform: translateX(calc(var(--slider-index) * (100% + var(--space-2))));
```

### 实测

```
tabs     740×34   maxW 740px   radius 9.20448px   bg overlay-subtle   x=556 居中
slider   80×28（与单个 tab 等宽）

/cost             translateX(0)         驾驶舱
/cost/contracts   translateX(81.77px)   主合同
/cost/budget      translateX(≈409px)    预算成本
/cost/analysis    translateX(≈654px)    成本分析

文字颜色始终只有一种：rgb(95,99,103) —— 确认选中态靠滑块区分
```

### 一处与 hana 不同

hana 的 tab 是 `height: 20px`（纯文字）。moheng 的每个 tab 带 13px 图标，20px 太挤，取 **24px**（原来 28px）。

### 三个空白带：两个来自旧占位，一个来自 legacy 的 margin

修完定位后底部还有空白，量出三处：

```
1. 主内容区  cost-workspace h=931 > app-content h=888   溢出 43px
2. 右侧面板  panel padding: 6px 6px 46px                底部留 46px
3. 标签下方  gapTabsToDockBottom 42px                    含 legacy 的 18px margin
```

**第 1 处**：`.cost-workspace` 只有 `min-height: 100%`，content 跟着内容长高，把 dock 顶出容器。

```css
.cost-workspace { min-height: 100%; height: 100%; display: flex; flex-direction: column; }
.cost-workspace-content { flex: 1 1 auto; min-height: 0; overflow-y: auto; }
```

修后 `costWorkspace h=888`、`content y=6 bottom=822 h=816`（= 888 − 72）。

**第 2 处**：`padding-bottom: calc(40px + 6px)` 是我早先给浮起抽屉留的位置，但抽屉已经移进文件卡内部，这 46px 变成纯空白。

```css
.workspace-panel { padding: var(--panel-edge-gap); }   /* 四周均 6px */
```

修后 `panel pad 6px`、`cardStudio bottom=894`（= panel bottom），卡片高从 421 变 441。

**第 3 处**：`legacy.css:634` 有一条旧 margin：

```css
.cost-workspace-tabs { ... margin: -3px 0 18px; ... }
```

新规则没重置 margin，那 18px 就成了标签下方的空白。

```css
.cost-workspace-tabs { margin: 0; }
```

同时把 dock 的 `padding-bottom` 从 24px（hana `.input-area` 的值，但那是输入框悬在内容之上需要呼吸）收到 8px，并加 `align-items: flex-end`。

修后：

```
dock  h=38（原来 72）  y=856  bottom=894  padding-bottom 8px
tabs  h=30  y=856  margin 0
gapTabsToDockBottom  26 → 8
```

### 定位：不能 fixed，也不能 absolute

底栏 `cost-workspace-dock` 一开始是 `position: fixed; right: 0`，一直伸到窗口右边缘：

```
dock    x=252  w=1348  right=1600
panel   x=1200 w=400             ← 右侧工作区
tabs    x=556  w=740   right=1296   ← 压进工作区 96px
content x=246  w=948   right=1194   ← 实际内容宽度
```

改成 `absolute` 也不行：`.cost-workspace` 是 `min-height: 100%`，会随内容长高，底栏被推到页面外（实测 `y=-66`）。

最终：`.cost-workspace` 改成 `display: flex; flex-direction: column`，content 用 `flex: 1`，dock 排在 content **之后**并 `position: sticky; bottom: 0`。

```jsx
<div className="cost-workspace">
  <div className="cost-workspace-content"><Outlet /></div>
  <div className="cost-workspace-dock">…</div>
</div>
```

实测：

```
dock   x=246  y=822  w=944  right=1190
tabs   x=348  y=822  w=740
panel  x=1200                            ← 不再重叠
```

### 红圈：v6.css 的手绘笔触

选中 tab 上出现陶土红圆圈，来源是 `v6.css:146`：

```css
.cost-workspace-tab.active::before{
  content:""; position:absolute; inset:1px 0; z-index:-1;
  background:url("data:image/svg+xml,…stroke='%23a23a2a'…") center/100% 100% no-repeat;
  transform:rotate(-1.2deg); opacity:.9
}
```

`#a23a2a` 是陶土红，`viewBox 0 0 120 40` 画两个椭圆路径。

之前有一条 `.cost-workspace-tab.active::before { display: none }` 抑制它，我重写 CSS 时删掉了。已恢复抑制（保留 suppressor 而不改 v6 原规则，因为其他 `::before` 笔触可能共用同一套）。

```css
.cost-workspace-tab.active::before,
.cost-workspace-tab[aria-selected='true']::before {
  display: none !important;
  content: none !important;
}
```

实测 `::before` 的 `display: none` / `content: none`，红圈消失。

### 两条门禁断言同步

旧断言查 `.active` 类和 `scrollTo` 自动滚动，新结构用滑块 + `aria-selected`，不需要横向滚动。

| 旧断言 | 新断言 |
|---|---|
| `active cost tab auto-scrolls into view`（查 `.active` + `scrollTo`） | `active cost tab is expressed by the slider position`（查 `.cost-workspace-tab-slider` + `--slider-index` + `aria-selected`） |
| `active cost tab suppresses the legacy hand-drawn ring`（查 `::before`） | `cost tab uses the hana slider instead of the legacy hand-drawn ring`（查 `.cost-workspace-tab-slider` + grid） |
