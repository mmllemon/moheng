# WP8：XLSX 与报表设计器端到端验收清单

## 一、环境与数据库

- [ ] Windows 目标环境 Node.js 24+；`npm ci` 干净安装成功，lockfile 已审查。
- [ ] `npm run db:generate`、`npx prisma validate` 成功。
- [ ] PostgreSQL 备份已验证可用。
- [ ] `npm run db:deploy` 成功，`/health` 返回数据库可用。
- [ ] `npm run lint`、`npm test`、`npm run build` 通过。

## 二、原生工作簿导出

对八类报表逐一测试：目标成本、实际成本、进度款、变更、业主应收、业主到账/退款、分供合同、分供应付。

- [ ] XLSX 文件能在目标 Microsoft Excel 版本中打开，无修复提示。
- [ ] XLSX 文件能在目标 WPS 版本中打开，无修复提示。
- [ ] `数据`、`导出说明`工作表内容与选定项目、日期范围一致。
- [ ] ID/编号/合同号/发票号不丢前导零；金额和数量保持数值单元格；日期可筛选排序。
- [ ] 标题、副标题、列宽、列名、列顺序、隐藏列与模板定义一致。
- [ ] 冻结表头、筛选、打印区域、横竖版与重复表头符合设置。
- [ ] 超过 10,000 行时明确写出截断信息；用户可缩小筛选范围。
- [ ] CSV 旧导出依然可用，结果口径未改变。

## 三、设计器交互

- [ ] 八种报表可切换，字段绑定对应当前报表，不出现其他报表字段。
- [ ] 修改标题、副标题、说明、列标题、字段绑定/静态列、列顺序、可见性、列宽、对齐与格式后实时预览正确。
- [ ] 可以新增/删除自定义行和列；行高、标题/副标题/表头/明细行高按约束保存。
- [ ] 按 Shift 选区后可以合并；拆分后恢复网格。
- [ ] 页面设置纸张、方向、宽度适配、重复表头、说明页、页脚和页码有效。
- [ ] 预览默认最多 80 行；打印请求获取完整但最多 10,000 行数据。
- [ ] 打印截断时提示用户；浏览器打印对话框可选择另存为 PDF。
- [ ] 保存模板、刷新后重开可恢复；版本历史显示创建/更新/发布/恢复。

## 四、模板权限

- [ ] 普通用户只能查看自己的个人模板。
- [ ] 普通项目成员可读取已发布项目模板，不能写入或发布。
- [ ] 项目 OWNER/MANAGER 可编辑/发布对应项目模板，不能访问无权项目。
- [ ] 只有 ADMIN 能编辑/发布/归档系统模板。
- [ ] 在系统只读模板编辑后，保存会建立个人副本，不改变原模板。
- [ ] 发布后其他普通用户使用已发布定义；未发布修改不会改变发布快照。
- [ ] 两个管理员/编辑者并发保存时，过期版本得到 409 而不是静默覆盖。
- [ ] 跨项目 templateId、报表类型不匹配和归档模板写入都被拒绝。

## 五、预算 XLSX 导入

- [ ] 下载模板并在 Excel/WPS 中填入 1–5,000 行后成功预览。
- [ ] 表头映射自动和手工模式都可用；映射变动后必须重新校验。
- [ ] 前导零编号作为文本保留；数值型编号/上级编号得到明确警告或阻断。
- [ ] 空表头、重复表头、空必填值、无效数字、重复编号、已有编号、缺失父项和子项先于父项均失败且明确定位。
- [ ] 公式、错误单元格、`.xls`/`.xlsm`、加密 ZIP、ZIP64、超限行列/文件/解压内容、嵌入对象/外部链接被拒绝。
- [ ] 任一行错误均禁止整批写入；数据库唯一约束冲突或父项竞态时事务完整回滚。
- [ ] 正式提交前数据库变化被再次检测，失效预检不能直接入库。
- [ ] 导入成功时审计记录包含格式和数量；既有 CSV 导入行为仍兼容。

## 六、业务与安全回归

- [ ] 所有数据仍按当前账号可访问项目范围查询。
- [ ] 模板只允许当前报表字段白名单，不接受 SQL/JavaScript/任意计算表达式。
- [ ] 公式型字符串在 XLSX 中以字符串单元格保存，不能自动成为公式。
- [ ] 模板改变不改变合同原始金额/有效金额、变更状态、结算过账、应收/应付、到账/退款或成本金额。
- [ ] 审计记录包含模板创建/修改/发布/归档/恢复和预算导入动作。
- [ ] 记录 Excel/WPS 版本、浏览器版本、测试数据、截图、测试人、时间与失败日志。

只有本清单全部完成并留有证据后，才建议将 `v2.1.0-rc.1` 升级为正式发布版。
