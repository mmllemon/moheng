# 墨衡 v2.5.0-rc.1 阶段验收记录

- 日期：2026-10-15
- 基线：`v2.4.0-rc.1`
- 候选：`v2.5.0-rc.1`
- 验收性质：源码契约、可执行的纯逻辑测试与静态审查；**不是生产发布签字**。

## 1. 本轮改动

1. 修正标准报表和工作室预览列宽策略，屏幕中列宽由模板元数据确定，禁止少列时最后一列自动拉伸。
2. 重排报表中心入口：标准台账分类浏览，另设项目综合、公司经营和单位经营档案入口。
3. 为目标成本、实际成本、进度款、变更、分供合同、分供应付、业主应收/收退款、项目驾驶舱及往来单位经营档案接入统一预览/导出按钮，并提供已保存单位模板的编辑入口。
4. 新增 `PARTY` 报表域、往来单位默认模板和 `businessPartyId` 上下文隔离，使用追加迁移 `20261015030000_party_report_template_context`；不修改历史迁移。
5. 重复区域强化同源行绑定验证；字段必须绑定匹配数据源的集合区域样板行；多个区域独立展开、保留空样板行；集合查询增加稳定 ID 排序 tie-breaker。
6. 单位财务摘要使用整数分计算金额，避免 Decimal 先转浮点数后累计；来源超限后金额汇总不可输出完整值。
7. 新增纯逻辑测试覆盖不同区域长度、行字段对应、错源绑定拒绝、空集合与大金额文本精度。
