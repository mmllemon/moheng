## 3. 数据迁移与身份核验注意事项

迁移会创建统一单位主档，并尝试按规范化文本名称回填历史关联。所有历史回填主档默认为身份未核验并带有核验备注。名称一致不证明法律主体一致；对总公司/分公司、项目部、近似名称或同名供应商必须结合信用代码、签约方及原始凭证复核。单位页在身份未核验时显示警告，其跨项目汇总不能直接充当最终财务对账依据。

公司级主档的编辑/核验/停用限制为管理员；单位经营档案的数据查询按当前用户有权访问的项目过滤。正式上线前需抽查迁移回填、复核同名主体、验证普通用户不能通过详情 API 看到未授权项目数据。

不能把静态检查或隔离纯逻辑测试表述成完整构建、数据库迁移或生产财务验收通过。
