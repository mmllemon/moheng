# 阶段验收记录

- 产品：墨衡｜施工单位成本管理系统
- 版本：MVP 1.6.0-rc.1
- 阶段：源码静态检查、纯逻辑回归与界面结构检查，非生产验收通过版

## 本轮变更范围

1. 项目工作台业务导航去除收入/支出分组文字，仅保留轻背景、留白和细分隔线进行视觉分区。
2. “竣工结算与应收账款”改为重点指标区 + 四个页签：竣工结算、应收账款、收退款流水、质保金与预付款；每次显示一个工作区，宽表使用限定高度的滚动容器和吸顶表头，并添加窄屏响应式布局。
3. 品牌名称改为“墨衡”，更新侧栏、登录页、页脚、页面标题和 SVG 品牌图形；新增 `apps/web/public/moheng-mark.svg` 作为 favicon/可复用资产。应用业务图标仍采用 SVG/Lucide 图形，没有使用 emoji 图标。
4. 主导航下方新增界面偏好条：浅色/深色/系统主题、标准/紧凑密度、靛青/青玉/朱砂强调色、宽屏、减少动效、重置。偏好本地持久化，不进入共享业务数据库。深色主题包含导航、页面底色、卡片、表格、表单、弹窗、工作台页签与业主财务页面样式。
5. 初始化 Git 仓库，默认分支 `main`，包含 `v1.5.0-rc.1` 导入基线提交及 `v1.6.0-rc.1` 当前修改提交；交付 Git bundle 和普通源码 ZIP 两种格式。
6. 更新 README、开发维护指南、用户操作手册及更新日志；保留旧的数据库迁移不变。

## 验收检查

- `node scripts/validate-release-candidate.mjs`：逐项静态一致性检查，包括版本、原有迁移 hash、权限、单位主档、结算应收流程、导航无分组标题、主题/密度/强调色控制、SVG 品牌资源及业主财务四页签。
- TypeScript/TSX：使用 TypeScript `transpileModule` 对 `apps` 下所有 `.ts/.tsx` 文件执行语法解析检查。此检查不包含完整类型分析。
- 纯逻辑测试：在临时目录转译纯逻辑单元测试并使用 Node.js 测试运行器执行。测试源仍位于 `apps/api/src/lib/*test.ts`。
- 检查结果：发布候选静态检查 `66/66` 通过；纯逻辑测试 `58/58` 通过；`apps` 下 `66` 个 TypeScript/TSX 文件语法解析 `0` 错误；CSS 大括号结构检查通过；`git diff --check` 通过。
- CSS：静态检查主题选择器、布局选择器和大括号配对；未运行真实浏览器渲染回归。
- Git：仓库 `main` 工作树干净；保留 v1.5 导入基线与 v1.6 界面变更提交，使用 `v1.5.0-rc.1` 和 `v1.6.0-rc.1` 标签定位。Git bundle 验证通过且已成功克隆，源码 ZIP `unzip -t` 完整性检查通过。

## 尚未完成的正式验收

运行环境为 Node.js 22.x，低于项目 `engines` 声明的 Node.js 24+，且当前未安装工作区依赖。因此本轮没有完成完整 `tsc --noEmit`、API/Web production build、Prisma `validate/generate`、真实 PostgreSQL 迁移、Windows 原生部署或浏览器端到端测试。新增深色样式、主题切换及宽屏/紧凑布局仍需在 Edge/Chrome 与窄屏视口手动验证。

1. 在 Node.js 24+ 环境安装依赖并生成/复核 `package-lock.json`，执行完整类型检查、lint、生产构建和 Prisma 校验/生成。
