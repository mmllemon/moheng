# WP9：报表工作室端到端验收清单 v2.4.0-rc.1

## A. 环境门禁

- [ ] Node.js 24+，`npm ci` 使用提交锁文件可重复安装。
- [ ] `npm run lint`、`npm test`、`npm run build`、Prisma validate/generate 全通过。
- [ ] 测试 PostgreSQL 版本与生产兼容；历史迁移状态无漂移。
- [ ] 固定版本的 Univer 所有直接/传递依赖、许可证和生产 bundle size 已审查。

## B. 项目级模板与数据绑定

- [ ] 创建项目模板，使用已授权项目作为数据范围。
- [ ] 将 `project.name`、主合同编号、当前有效合同额和累计登记净收款分别绑定到任意指定单元格。
- [ ] 保存后刷新重开，字段绑定与样式保持。
- [ ] 将分供合同绑定到一行样板区域，不同列绑定不同字段；至少 0、1、3、100 条记录均能正确渲染。
- [ ] 添加独立的收退款、变更或应收集合；每个区域根据自身行数延伸，下方区域正确下移且不覆盖。
- [ ] 空集合保留样板空行，下方内容正常；超过区域限制时给出警告。
- [ ] 不存在/未知字段、集合字段未位于重复区域、跨行合并与区域冲突的模板应被拒绝。

## C. 公司级报表与访问控制

- [ ] 公司摘要只包含当前用户有权访问的项目；管理员和普通用户的可访问集合符合权限模型。
- [ ] 公司项目清单一行一个项目；公司分供合同、应收、收退款、实际成本、变更、进度款与应付集合字段齐全。
- [ ] 检查项目级模板不能被用于其他项目；不能通过更改 URL/body 读取无权项目。
- [ ] 当某类来源超过上限时，相关汇总值为空且显示警告，不以部分数据冒充完整财务总额。
- [ ] 核对当前有效合同额只按已生效外部确认变化计算；净收款、登记净应收、已登记净应付和实际成本标签没有混淆。
- [ ] 使用含 0.01、负向退款和接近 DECIMAL(18,2) 上限的金额数据；所有汇总必须以整数分精确计算，不发生 JS number 舍入；超出 Excel 安全数字精度的单元格按文本输出并保留完整金额。

## D. 编辑器与样式

- [ ] Univer 核心编辑器可在 React 页面创建、保存、销毁；切换路由不遗留事件或 DOM。
- [ ] 字体、字号、粗体、斜体、字体色、填充色、四边框、线型、水平/垂直对齐、换行、合并、行高列宽有效。
- [ ] 复制/粘贴、键盘导航、多工作表、工作表改名/增删和撤销/重做符合预期。
- [ ] 字段绑定占位内容可识别，预览和 XLSX 中替换成实际值而不是输出占位文本。
- [ ] 拒绝公式和外部资源；不会执行用户模板内容。

## E. 预览和输出

- [ ] 所有标准 XLSX 操作先导航正式预览页，不直接下载。
- [ ] 项目/公司综合模板预览展示模板版本、范围、生成时间、多个工作表、样式、合并、截断和警告。
- [ ] 用户可以从预览返回设计器，打印/另存 PDF，或确认 XLSX 后台导出。
- [ ] 后台任务显示状态，重试不生成多个逻辑相同文件；完成后可安全下载，过期文件不可继续下载。
- [ ] 预览后数据库变化时，界面解释导出 Worker 在执行时重新读取数据的时间差。
- [ ] Excel 与 WPS 打开文件无修复提示；列宽、行高、数字类型、日期、颜色、字体、边框、合并、冻结窗格、页脚、分页和说明工作表均符合模板。

## F. 全仓控件一致性

- [ ] 除 `SelectField` 与 `DatePicker` 内部为了表单兼容保留的原生代理外，业务页面无自绘原生 `<select>` 或 `input type="date"`。
- [ ] 普通日期选择和下拉在四套主题、舒朗/紧凑密度、弹层边界、键盘操作、校验错误和禁用态下一致。
- [ ] 日期时间混合字段单独验证，不被误替换成纯日期控件。
- [ ] 1920/1366/1024/手机视口无横向溢出；减少动效设置生效。
