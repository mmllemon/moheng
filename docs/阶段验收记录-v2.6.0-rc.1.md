# 墨衡 v2.6.0-rc.1 阶段验收记录

- 基线：`v2.5.0-rc.1`
- 候选：`v2.6.0-rc.1`
- 范围：报表中心去重精简、经营报告入口交互提示、项目成员导航分组修正、左侧经营健康度静态装饰语义修正。
- 性质：源码/静态契约候选，不等于生产验收签字。

## 本轮修改

1. 移除报表中心上方三张重复说明卡和重复 Hero 横幅，避免重复呈现标准报表数量、只读快照和权限说明。
2. 将标准台账目录改为紧凑纵向选择列表，类别过滤与项目/日期配置共处一个工作区，消除大型目录卡片与上方“报表类型”下拉的重复选项路径。
3. 项目级/公司级工作室入口增加明确 CTA 文案、箭头、hover 和键盘 focus-visible 状态，保留 `prefers-reduced-motion`。
4. 将“项目成员与权限”从成本支出 tabs 分离，置于独立“项目管理”分组；路由与 API 权限不变。
5. 原侧栏“经营健康度 / 收入与支出持续跟踪”只有静态文案，没有实际指标、公式或数据来源。为避免暗示不存在的评分系统，移除该元素并改为可点击的“项目驾驶舱”快捷入口。
6. 新增 `scripts/validate-ui-polish.mjs`，并将其加入发布候选静态检查。

## 发布门槛

在 Node.js 24+ 干净环境执行 `npm ci`、`npm run validate:release-candidate`、`npm run lint`、`npm test`、`npm run build`；随后在 Edge/Chrome 对多个视口、主题和密度做实机检查。确认报表中心只存在一个台账选择入口、工作室 CTA 易识别、项目成员导航分组准确、驾驶舱快捷按钮可正常跳转后，才可移除 RC。
