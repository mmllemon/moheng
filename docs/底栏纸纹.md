# 底栏纸纹：渐变底盖住了纸

日期：2026-10-25

## 根因

`.cost-workspace-dock` 有一条自造的渐变底：

```css
.cost-workspace-dock {
  z-index: 40;
  background: linear-gradient(to bottom, transparent 0%, var(--bg) 55%);
}
```

`z-index: 40` 远高于纸纹层的 `-1`，那条渐变把底栏区域的纸纹整个盖住了。

## hana 的底栏是透明的

```css
.input-area {
  position: absolute; right: 0; bottom: 0; left: 0;
  z-index: 5;
  padding: 0 var(--space-24) var(--space-24);
  background: transparent;      /* ← 完全透明 */
  pointer-events: none;
}
```

没有渐变底。胶囊导航的底色来自 `_input-wrapper`（`--bg-card` + 边框 + 阴影），容器本身透明，所以纸纹能透上来。

## 修正

```css
.cost-workspace-dock {
  background: transparent;
}
```

## 像素级验证

用 canvas 采样底栏左侧空白区（避开胶囊）和内容区，比较灰度分布：

```
底栏    mean 244.92   range 18   std 3.771
内容区  mean 245.28   range 25   std 4.031
```

两者都有起伏，均值差 0.36。如果被平涂盖住，`range` 会是 0 或接近 0。

## 一处注意

之前怀疑 `.app-content` 的 `background: var(--bg)` 也会盖住纸纹层。实测不会：

`.app-content` 有 `isolation: isolate`，纸纹层 `z-index: -1` 在这个层叠上下文内，画在父级背景**之上**、内容**之下**。这正是 hana 的做法（`_tray` 同样是 `isolation: isolate` + `background: var(--bg)`）。

判据：**父级自己的 background 不会盖住 `z-index: -1` 的子元素**，但**兄弟元素的高 z-index 背景会**。底栏是兄弟，所以它盖住了。
