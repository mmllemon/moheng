# 右侧浮层三个几何缺陷（tab 间距 / 卡片平齐 / 抽屉位置）

日期：2026-10-25

三项均成立，且都属于「源码看过但没按源码做」。

---

## 一、tab 栏与卡片边缘的间距

Hana 真值：

```css
._tabs_22ed1 {
  position: relative;
  flex: 0 0 auto;
  display: grid;
  grid-template-columns: repeat(2, minmax(0, 1fr));
  gap: var(--space-2);                     /* 2px */
  margin: 0 var(--space-8);                /* 左右 8px */
  padding: var(--space-2);                 /* 2px */
  border-radius: calc(var(--radius-sm) * var(--corner-radius-scale, 1));
  corner-shape: squircle;
  background: var(--overlay-subtle);
  border: 1px solid var(--overlay-light);
  box-shadow: var(--shadow-xs-soft);
  overflow: hidden;
}
```

**它自己带 `margin: 0 var(--space-8)`，外面没有包裹层。**

我之前包了一层 `.workspace-tab-bar`，给了 `padding: 6px 14px 4px`。那是 `_tabBar_2e5d8`（预览卡的多文件 tab）的规格，不是这一套。结果实际间距变成 23px（6px panel padding + 14px tab-bar padding + 8px margin 被吃掉一部分）。

修后：

```css
.workspace-tab-bar { padding: var(--space-4, 4px) 0; }
```

实测 `tabs x=1216`、`card x=1207`，间距 **9px** = 卡片边框 1px + `margin 8px`。

---

## 二、卡片上边缘与侧栏平齐

Hana 的层级：

```css
._previewPanel_2e3ae {
  width: var(--preview-panel-width);
  flex-shrink: 0;
  background: var(--bg);
  border-left: 1px solid var(--overlay-light);
  overflow: hidden;
  /* 无 margin，无 padding */
}

._previewBodyShell_c68e1 {
  flex: 1;
  min-height: 0;
  margin: var(--panel-edge-gap);      /* 6px —— 卡片自己的纸边 */
}
```

**panel 无 margin，卡片靠自身 `margin: 6px` 内缩。** 侧栏也是 `margin: 6px`，所以两者上边缘都在 6px。

我之前：

```
panel  margin: 6px + padding: 6px     → 卡片在 12px
```

多算了一次。修后：

```
panel  y=0   （无 margin）
card   y=6   ← 与 sidebar y=6 平齐
```

## 三、抽屉在文件卡内部，不是独立浮层

`Ket` 的完整 return：

```jsx
<div className={workspaceCardSurface}
     data-workspace-drawers={w > 0 ? w : undefined}
     style={{ '--workspace-drawer-count': w }}>
  <div className={workspaceCardMain}>
    <Uet tabs activeTab onSelect />
    <div className={workspaceCardTabPanel} role="tabpanel">
      <Yet tab card scrollRef />
    </div>
  </div>
  {w > 0 && (
    <div className={workspaceDrawerStack}>
      {v.map((id, i) => (
        <div className={workspaceDrawerLayer} data-workspace-drawer={id}
             style={{ '--workspace-drawer-index': i }}>
          <Drawer />
        </div>
      ))}
    </div>
  )}
</div>
```

```css
._workspaceCardSurface_cbdb6 {
  --workspace-drawer-overlap: 10px;
  position: relative;
  display: flex;
  flex-direction: column;
  flex: 1;
  min-height: 0;
}

._workspaceDrawerStack_a0cbd {
  flex: 0 0 auto;
  display: flex;
  flex-direction: column;
  min-height: 0;
  max-height: 64%;
}

._workspaceDrawerLayer_322c5 {
  position: relative;
  z-index: calc(var(--workspace-drawer-count) - var(--workspace-drawer-index));
  flex: 0 0 auto;
  background: var(--panel-card-bg);
  margin-top: calc(-1 * var(--workspace-drawer-overlap));   /* -10px 叠纸 */
  padding-top: var(--workspace-drawer-overlap);
}
```

**抽屉是 `workspaceCardSurface` 的第二个子元素，在文件卡内部下方。**

我之前把它做成 `.workspace-panel` 的直接子元素、`position: absolute` 浮在面板底部，所以看起来挂在预览卡下面。

修后：

```
workspace-card-main
  ├─ workspace-card-surface-main   （卡头 + tab + 内容）
  └─ workspace-drawer-stack        （抽屉栈）
       └─ workspace-jian-drawer
```

实测 `jianInCard: true`、`jianParent: workspace-drawer-stack`。

---

## 验证

```
panel  y=0
card   y=6      ← 与 sidebar y=6 平齐
tabs   x=1216   card x=1207   间距 9px
jian   在 workspace-drawer-stack 内部
UI 规范检查   75/75
视觉回归      26 路由 0 failure
TypeScript    前后端通过
```


四个问题全部成立。根本原因是**我一直没把「两个 tab 是两个不同组件」这件事当成分支结构来读**，把工作室的 chrome 当成了整个 files 卡片的通用结构。
