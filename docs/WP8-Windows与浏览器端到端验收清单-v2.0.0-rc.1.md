# WP8 Windows 与浏览器端到端验收清单

- 候选版本：`v2.0.0-rc.1`
- 目标环境：Windows 11 / Windows Server（实际生产部署版本需填） + Node.js 24 LTS + PostgreSQL 16
- 状态：**待在目标 Windows/CI 环境执行**。当前开发容器缺少 Node.js 24 与项目依赖，本清单不代表已通过。
- 每一项需填写执行人、日期、环境、结果和证据路径；不得以静态源码检查代替。

## A. 可重复构建与基础设施

- [ ] `node -v` 显示 `v24.x` 或更高；`npm -v` 可用。
- [ ] 审查 `package-lock.json` 差异并提交；以后安装使用 `npm ci`，不能忽略 lockfile 差异。
- [ ] `npm run validate:release-candidate` 全部通过。
- [ ] `npm run lint` 通过完整 API/Web 类型检查。
- [ ] `npm test` 通过完整 API 单元测试。
- [ ] `npm run build` 通过 API 与 Web 生产构建。
- [ ] Prisma `validate`、`generate` 通过。
- [ ] 连接串经人工核对后执行 `migrate status`；备份完成后在测试库应用 `db:deploy`，确认迁移状态与预期一致。
- [ ] 用独立的空库执行迁移；使用备份恢复到隔离测试库，验证项目、合同、审计及文件元数据均可读取。

## B. 登录、权限与项目成员

- [ ] 管理员登录、登出、会话/令牌续期正常；停用账号不能继续访问。
- [ ] 普通用户只看到有 `ProjectMember` 关系的项目。
- [ ] 手动修改项目 ID 调用项目 API、报表 API、通知 API、审计 API；未授权项目返回 403，不回传数据。
- [ ] 普通成员不能自我提升为 OWNER/MANAGER；经理只能分配允许的角色。
- [ ] 通过界面添加已启用账号，角色修改写入审计记录；不存在的/停用邮箱返回明确错误。
- [ ] 最后一名 OWNER 不可被降级；先添加第二名 OWNER 后再尝试调整，服务端结果与界面提示一致。
- [ ] 两个管理员/负责人并发执行角色更新，项目仍保留至少一名负责人。

## C. WP2 台账交换与导入保护

- [ ] 八种 CSV 报表均能下载：目标成本、实际成本、业主进度款、变更签证、业主应收、业主到账/退款、分供合同、分供应付。
- [ ] 每种报表分别验证单项目、全部有权限项目、开始/结束日期过滤；手工指定未授权项目 ID 必须失败。
- [ ] 使用 Excel/WPS 打开中文表头；验证逗号、双引号、换行、负数金额、日期与公式样本。负数金额应保持数值；危险文本不能作为公式运行。
- [ ] 超过 10,000 行时，响应 `x-report-truncated=true` 且有 `x-report-row-count`；按日期分批导出后记录数量能对账。
- [ ] 目标成本导入选择常见中英文表头，验证自动映射；手动修改映射后未重新校验时不允许提交。
- [ ] 测试空编号、空名称、非法数字、重复编号、已有编号、未知上级、父项排在子项后；预检应逐行报错，任何错误都不允许部分导入。
- [ ] 预检后并发创建同编号清单，再提交原导入；服务端应拒绝冲突，不能覆盖已有清单。
- [ ] 取消/关闭导入不写正式数据；成功导入应在一个事务中写入全部清单与审计记录。

## D. WP4 审计覆盖与财务回归

- [ ] 分别验证主合同原始金额锁定、有效合同额调整、A/B/C 外部确认/补件/争议/核验以及金额差异复核。
- [ ] 验证业主进度款申报和到账、业主竣工结算过账、应收分配、到账与退款冲销。
- [ ] 验证分供合同原始金额与已生效调整、进度结算/最终结算、应付过账、分期付款、付款与退款冲销、发票核验、质保金与预付款。
- [ ] 对每种成功写操作确认审计记录包含操作者、项目、业务实体、业务编号、时间与足够的变更摘要。
- [ ] 人工制造业务校验失败/事务异常，确认业务数据回滚且没有留下成功审计记录。
- [ ] 普通用户无法更新/删除审计记录；审计明细和 CSV 不暴露密码、令牌、密钥或 Cookie。

## E. WP5 待办与预警

- [ ] 准备待审批变更、待补件/待核验/争议凭证、进度款待审数据，验证任务显示与目标页面跳转。
- [ ] 设置已到期且未全额收回的业主应收；验证只提示净未收余额大于零的记录。
- [ ] 设置已逾期且未核销的分供应付分期；验证退款分配会正确回冲待付余额。
- [ ] 设置 30 天内结束的有效分供合同；草稿、终止合同和无结束日期合同不应误触发。
- [ ] 设置目标成本基线且实际成本超过末级目标成本合计；出现超支提醒。无正数目标成本基线时不能出现超支提醒。
- [ ] 普通用户只能看到自己项目的提醒；点击提醒会先选中正确项目再跳转。
- [ ] 确认页面明确说明为实时计算待办，未读/已读状态不是已实现功能，刷新不会永久关闭提醒。

## F. WP7 本地草稿、主题与交互

- [ ] 目标成本新建/编辑未保存时刷新页面，确认可提示恢复同一项目/同一清单的本地草稿。
- [ ] 明确取消或清除草稿后不会写入正式台账；保存成功后草稿被清理。
- [ ] 业主/分供合同、结算、应收应付、付款和退款不提供离线正式提交入口。
- [ ] 四套主题、跟随系统、舒朗/紧凑和减少动效可切换；窄屏浮层不被裁切。
- [ ] 下拉框可搜索、键盘上下/Enter/Esc 可操作；日期选择器边界、跨月与键盘行为一致。
- [ ] 命令面板、项目抽屉、提示和卡片动效正常；系统或用户减少动效时无大幅位移/循环动画。

## G. Windows 原生部署与恢复

- [ ] `.env` 使用强 JWT 密钥和独立数据库账号；不保留示例密码。
- [ ] 凭证目录配置专用 NTFS ACL，仅 API 服务运行身份和授权维护人员可访问。
- [ ] `prepare-windows.ps1` 完成依赖、Prisma Client、生产构建、迁移与种子数据。
- [ ] `start-windows.ps1` 只有在 API 和 PostgreSQL 健康时返回成功；停止脚本只停止确认身份的 API 进程。
- [ ] 运行开机任务，重启主机后确认服务恢复、日志轮转/空间限制方案明确。
- [ ] 执行数据库与凭证目录备份，将备份恢复至隔离主机/路径，验证校验和、关联关系及读取权限。
- [ ] 形成部署版本、Git commit/tag、环境配置摘要（不包含密钥）、迁移状态、E2E 日志和恢复记录。
