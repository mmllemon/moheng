# 窗口控制区可点击 + 顶栏按钮精简

日期：2026-10-25

## 一、窗口控制区按钮点不动

我上一轮把 island 的底衬改成 `::before`，顺手加了 `pointer-events: none`（跟随 hana），但**漏了 hana 给子元素的恢复规则**：

```css
/* hana 有两条 */
._windowControlsIsland_5f7ae { pointer-events: none; }
._titlebarActionIsland_d8891 > [data-chrome-action-id] { pointer-events: auto; }
```

我只抄了第一条。整个岛变成穿透的，所有按钮都点不动。

修法：

```css
.window-controls-island > * {
  pointer-events: auto;
}
```

### 实测

```
islandPE: "none"
每个按钮 pe: "auto"  hitIsSelf: true
实际点击「打开全局搜索」→ 成功，命令面板打开（hasPalette: true）
```

## 三、我又犯了同一个错

你说的是对的：**hana 有源码，我却自己在拼。**

「island 是 pointer-events: none」这条我看了，但没继续读下一条就动手。hana 的规则从来不是单条存在：

```css
._windowControlsIsland_5f7ae { pointer-events: none; }
/* ↓ 这条就是配套的，我没读 */
._titlebarActionIsland_d8891 > [data-chrome-action-id] { pointer-events: auto; }
```

同类错误清单（都是「只抄一条、漏掉配套」）：

| 错误 | 漏掉的那条 |
|---|---|
| 窗口按钮 28×28 | 漏了 `[data-window-titlebar-enabled]` 下的 46px 覆盖 |
| island 不能点（本次） | 漏了子元素 `pointer-events: auto` |
| 卡片外多包一层 | 漏了 `_cardStack` 属于 CapabilitiesPanel |
| 抽屉叠纸用 absolute | 漏了 `_workspaceDrawerLayer` 在文档流 |

**规则：抄一条 CSS 规则时，必须把它同类名/同后缀的所有配套规则一起读完。** 用 `grep -A/-B` 看上下文，而不是只取单条。
