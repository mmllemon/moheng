# 墨衡 · Hana 1.1.35 视觉规范

本规范以 **Hana 1.1.35 安装版 renderer 的实际 DOM / CSS** 为基准，不引用未经验证的重绘稿。
墨衡保留工程经营管理的业务密度，但外壳、纸张、排版、控件、弹层与设置工作区统一到 Hana 的设计语言。

## 1. 设计北极星

**一张摊开的工程经营纸。** 纸面负责安静，墨色负责判断，唯一的远山青负责交互。
不用渐变光晕、玻璃卡片堆叠、工程仪表盘式的密集描边来制造“专业感”。

## 2. 实测基准

| 项目 | Hana 1.1.35 实测 | 墨衡落地 |
| --- | --- | --- |
| 页面纸色 | `#F8F4ED` | 同值 |
| 卡片纸色 | `#FCFAF5` | 同值 |
| 侧栏纸色 | `#F4F0EA` | 同值 |
| 主墨色 | `#3B3D3F` | 同值 |
| 侧栏尺寸 | 240 × calc(100vh − 12)，left/top 6 | 同值 |
| 侧栏圆角 | 7 × 1.8409 = 12.886 | 13px，圆角矩形 |
| 侧栏边界 | 1px rgba(0,0,0,.08) | 1px 主题 overlay |
| 侧栏阴影 | 0 4px 32px rgba(0,0,0,.05) | 同值 |
| 标题层 | 44px，透明，不占内容纸面 | 同值 |
| 设置窗导航 | 208px | 同值；数据页窗口放宽到 1180px |
| 字号 | title 16 / body 14.4 / ui 13.1 / caption 12.5 / hint 11.2 | 13px 基准，关键正文 12–14 |
| 动效 | 0.1 / 0.15 / 0.25s | 同值 |

Hana 的窗口控制键是桌面端系统窗控；墨衡是 Web，不伪造 macOS 红黄绿，也不放 min/max/close。

## 3. 材质

纸纹分三层，均是可平铺的中性噪点，不携带第三方图片资产：

- `/textures/paper-rice.png`：1024px 云斑，峰值 alpha 约 0.086
- `/textures/paper-fiber.png`：720px 纤维
- `/textures/paper-grain.png`：256px 颗粒

`body::before` 固定铺三层，`mix-blend-mode: multiply`；青夜主题改用 `screen` 并降到 0.16 不透明度。
纸纹只铺在背景和侧栏，不进入表格单元格，避免数字发灰。

## 4. 色彩与主题

| 语义 | 暖纸 | 素白 | 青夜 |
| --- | --- | --- | --- |
| `--bg` | #F8F4ED | #FBFAF7 | #26343D |
| `--bg-card` | #FCFAF5 | #FFFFFF | #30414B |
| `--sidebar-bg` | #F4F0EA | #F3F1EC | #202C34 |
| `--text` | #3B3D3F | #2A2A29 | #F0F6FA |
| `--text-muted` | #5F6367 | #5F6367 | #B7C8D3 |
| `--accent` | #466B80 | #466B80 | #E6B1C4 |

- Hana 原始 accent 为 `#537D96`；墨衡统一压深到 `#466B80`，让 10–12px 文字、链接和主按钮达到 WCAG AA（4.5:1），色相仍是远山青。
- 语义色只用于状态：成功 `--green`、危险 `--danger`、提示 `--warning`。不要用装饰色表达状态。
- 青夜主题的主按钮文字改用深墨 `--on-accent`，避免粉底白字对比不足。

## 5. 外壳

```
.app-shell
├─ .app-sidebar        fixed; 6px 四周内缩；240px；13px 圆角
│  ├─ 44px toolbar     收起 / 搜索
│  ├─ 品牌行
│  ├─ 业务导航
│  ├─ 项目快速切换
│  └─ 用户 / 系统设置
└─ .app-main           margin-left: 246px
   ├─ .app-titlebar    44px 透明；上下文 + 右侧浮岛
   └─ .app-content     独立滚动
```

- 标题层不是第二条导航栏：左侧是当前页上下文，右侧是 30px 浮岛图标组。
- 全局搜索收进图标，通过 `⌘K` 打开命令面板，不再常驻一条 300px 搜索框。
- 项目切换收进标题层；全局页面显示“全公司”。
- 页脚版本号移除，版本只在设置/关于出现。

## 6. 页面与组件

- 页面标题：衬线 27px；设置内容标题：无衬线 21px。
- 卡片：`--bg-card` + 1px `--border` + 10px 圆角；不加投影，不用卡片套卡片。
- 表格：表头 10px 字距 + 0.5 透明底线；行 9px/12px 内边距；数字等宽；悬停用 8% accent。
- 按钮：32px 高、6px 圆角；主按钮实心 accent；危险按钮默认描边，悬停才染底。
- 输入框：34px 高、6px 圆角；聚焦使用 accent 边框 + 8% 外环。
- 弹层：8px 圆角、1px 边界、大阴影；命令面板 12px 圆角。
- 空状态：虚线纸面，不用插画堆叠。

## 7. 设置工作区

系统管理不再占用主内容区，而是覆盖式设置窗：

- 1180 × min(820, 100vh − 48)，16px 圆角，纸纹。
- 208px 导航；搜索、分组、32–34px 行高。
- 内容区独立滚动；页面标题直接作为设置页标题，不再重复系统导航。
- 移动端导航变为顶部静态分组，内容在其下滚动。

## 8. 交互与可访问性

- 动效三档：0.1s 状态、0.15s 控件、0.25s 面板；支持系统 reduced-motion，也支持“减少动效”偏好。
- 焦点环 2px accent，偏移 1px；设置打开时焦点落在当前导航项，不自动聚焦搜索框。
- 所有弹层使用既有 FocusTrap；Esc 先关闭最上层弹层。
- 主内容、表格、按钮在 1440 与 390 视口均无横向溢出；表格自身横向滚动。
