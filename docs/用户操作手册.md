# 用户操作手册

- 系统：墨衡｜施工单位成本管理系统
- 版本：MVP 1.6.0-rc.1 验证候选
- 适用对象：项目经理、造价人员及只读业务用户

## 1. 系统能做什么

本系统用于维护施工项目档案、业主主合同、采购/分包/租赁等分供合同、分供结算与应付账款、付款核销、预付款和质保金、供应商发票核验、目标成本、实际发生费用、业主进度款与变更签证，并将数据汇总到经营总览和成本分析页面。

当前版本为核心台账 MVP。分供合同支持阶段/最终结算、结算外部确认与过账、应付单与付款核销、预付款扣回、质保金留置/释放/核销及供应商发票登记/核验/应付来源分配。结算清单明细可选，不要求存在清单或预算编码，纯金额方式也能走完结算流程。材料收货/验收、完整发票三单匹配、供应商信用抵扣自动核销、材料库存、其他业务单据附件、原生 Excel 工作簿、报表中心、系统推送通知和离线录入尚未开放。变更签证凭证电子件不能替代单位规定必须留存的原件。

## 2. 打开系统和登录

1. 打开部署人员提供的系统网址。Windows 本机默认地址为 `http://localhost:3001`；正式内网地址以管理员配置为准。
2. 输入部署人员提供的工作邮箱和密码。
3. 点击“登录系统”。验证通过后会进入经营总览。

系统不在登录页面预填管理员账号或密码。初始管理员由部署人员根据受控的环境配置建立；如果无法登录，请联系系统维护人员核实账号状态，不要尝试共享管理员账号。

## 3. 页面导航与快捷操作

左侧导航分为“经营总览”“项目管理”和“项目工作台”。经营总览统计当前账号可访问的全部项目；选择项目进入“项目工作台”后，可通过横向页签进入项目驾驶舱、业主主合同、预算与目标成本、进度款、变更签证、分供合同与结算、实际成本和成本分析。同时可通过“往来单位库”维护单位主档；合同、项目及成本中的可关联单位名称可点击进入单位经营档案。系统管理员还可以进入“账号与项目权限”维护用户账号和项目角色。顶部会显示当前页面与项目上下文。

可进行以下操作：

- 点击左侧的收起/展开按钮切换导航宽度。
- 使用顶部项目选择器切换当前项目。录入数据前务必核对项目名称与编号。
- 点击顶部命令栏或按 `Ctrl+K`（macOS 为 `Cmd+K`），呼出全局命令面板；输入页面名称、项目名称或项目编号筛选结果，使用 `↑/↓` 选择、`Enter` 跳转、`Esc` 关闭。
- 点击顶部闪电形 SVG 快捷操作按钮，可直接前往新增成本相关模块、进度款管理或变更签证。
- 页面上的按钮、下拉筛选、表单弹窗和清单行操作都可直接点击或使用键盘操作。卡片悬停、按钮按压、页面切换和弹窗具有轻量动效；如果操作系统开启“减少动态效果”，界面会减少动画。

界面图标由 SVG 绘制，不使用 emoji 作为功能图标。顶部快捷操作属于模块入口，并不是服务端消息通知。

## 4. 经营总览（全局）

“经营总览”统计当前账号有权限访问的全部项目，不依赖工作台中的当前项目选择。管理员可以查看所有项目；普通用户只看到已授权项目。

页面分为三部分：

1. **全局指标**：可访问项目数、有效合同额合计、累计实际成本、目标成本和业主累计回款。指标按有权限访问的项目汇总。
2. **项目经营组合**：每行一个项目，展示项目状态、有效合同额、目标成本、实际成本、成本偏差、累计回款及回款/合同额比。可按项目名称、编号、业主或项目经理搜索，也可筛选项目状态。
3. **跨项目待跟进与最近操作**：展示待跟进的业主变更和近期操作流水。点击事项会切换到对应项目并打开相应业务页面。

点击项目行或“项目驾驶舱”按钮，会进入该项目的“项目驾驶舱”。全局总览用于管理层跨项目比较，不用于替代项目级业务录入或成本分析。账外实际发生、未登记收款或未确认变更不会自动补全；成本偏差也不应脱离预算口径解释。

## 4.1 项目驾驶舱（单项目）

进入某个项目后，项目工作台默认打开“项目驾驶舱”，显示该项目的核心指标、月度实际成本趋势、待处理进度款、待跟进变更和分供合同情况，并提供主合同、目标成本、进度款、变更签证、分供合同、实际成本和成本分析入口。

项目驾驶舱是该项目的工作总览；“成本分析”是专业分析页面，侧重三算指标、成本分类、预算清单偏差及成本趋势。两者分开，避免把大量图表和业务待办堆到同一页面。

## 5. 新建和维护项目

1. 打开“项目管理”，点击“新建项目”。
2. 填写项目名称、项目编号、工程类型、业主单位、合同金额、开工日期等字段。
3. 项目编号只允许字母、数字、下划线和短横线，且全系统不可重复。
4. 点击“创建项目并继续”。创建成功后，系统会选择该项目并进入项目工作台。
5. 后续可在项目卡片上选择编辑，修改项目信息。

项目状态包括施工中、待结算、已结算、已暂停。当前版本没有直接删除项目的功能，以保护历史台账关联。

## 6. 项目工作台与业主主合同

1. 在顶部切换到目标项目，进入“项目工作台”，默认显示“项目驾驶舱”；选择“业主主合同”页签进入主合同管理。
2. 填写合同编号、名称、签订日期、合同金额、是否含税、质保金比例、预付款扣回比例和付款条款。
3. 主合同页面默认显示合同摘要、原始金额、当前有效合同额和关键条款。点击“登记主合同”或“编辑合同资料”后才打开表单。保存后系统按已生效外部确认变更净额重算当前有效合同额；正式建档后原始金额不能通过普通编辑覆盖。

比例以百分比录入和展示，例如质保金 3%；后端以 `0.03` 这样的比例值保存。合同页面显示当前有效合同额和原始合同金额，两者不能混用或互相覆盖。

## 7. 分供合同与付款台账

该模块统一管理施工单位与分包商、材料供应商、租赁单位或服务商签订的合同。主合同属于收入侧；分供合同属于支出侧合同义务，与实际成本和支付流水分别核算。

### 7.1 建立和激活分供合同

1. 在项目工作台选择“分供合同与付款”，点击“新增分供合同”。
2. 填写合同编号、名称、类别、供应商/分包单位、签订日期、原始合同金额、含税口径、合同范围和付款条款。
3. 保存后合同状态为“草稿”。核对正式签约资料后，点击“激活合同”。激活需要签订日期，激活后原始合同金额和基础资料锁定。
4. 合同状态依次可按业务需要变为“执行中”“完工待结算”“结算已确认”，也可在有权限时终止。“结算已确认”不再计入执行中/完工待结算合同额，但不代表已经付清；状态变更会写入审计日志。

### 7.2 补充协议和当前合同额

合同当前金额 = 原始签约金额 + 已登记且已生效补充协议的增加/减少净额。需要调整金额时，选择“补充协议”，填写协议编号、调整方向、金额、生效日期和已签署文件的归档定位。只登记已签署并已生效的协议，不把正在谈判或等待审批的金额提前计入。

### 7.3 付款计划、付款与退款

1. 对执行中/完工待结算合同，可新增付款计划，记录阶段、计划日期和预计付款金额。计划代表预计现金流，不代表已经支付或已经发生成本。
2. 点击“登记付款/退款”登记实际现金流，选择预付款、进度款、结算款、质保金、其他付款或退款/退回。
3. 正常付款使用正金额；退款/退回也填写正金额，但必须选择“退款/退回”类型。退款必须关联一笔原始付款，自动继承该付款的付款计划；系统会把退款从累计净付款扣减，并阻止退款超过该笔原始付款、合同净已付款或付款计划净已付款。
4. 银行流水/参考号在同一分供合同内不能重复。每次付款/退款都会保留独立记录和审计，不会覆盖旧付款。
5. 付款是现金流，不会自动生成或冲减“实际成本”。实际成本应根据发票、验收、计量、结算等业务依据单独录入或核对。

### 7.4 结算与应付账款（清单明细可选）

1. 进入项目工作台的“结算与应付”页签，选择已激活且处于执行中/完工待结算的分供合同，点击“新增结算单”。
2. 选择“阶段结算”或“最终结算”，填写结算单编号、本期报审金额和需要的付款/扣款信息。默认是**纯金额模式**：没有工程量清单、材料清单或清单编码的合同，直接填汇总金额即可，不要为了通过系统而虚构清单行。
3. 如需解释金额，可打开“添加可选明细”，录入描述、数量、单位、单价和金额。提供明细后，系统要求明细合计等于报审金额；未提供任何明细行时不执行这项合计校验。明细不强制关联目标成本预算项。
4. 通过“提交审核 → 内部审核通过 → 登记外部确认 → 确认过账”推进。提交人不能审批本人提交的结算单。登记外部确认时需要填写确认金额、对方确认参考和日期；正式过账前不会生成应付单。
5. 阶段结算的确认金额表示**本期金额**；最终结算的确认金额表示**最终累计金额**。过账时系统自动计算最终累计金额与历史过账累计金额的差额。例如阶段累计 500,000 元、最终确认累计 470,000 元，最终结算只过账 -30,000 元，不能把 470,000 元再次全额累计。
6. 结算过账后系统生成独立应付单。正向结算应付净额 = 本次正向结算增量 - 预付款扣回 - 质保金留置 - 已批准其他扣款。负向调整形成供应商待返还/抵扣余额；当前系统会单独显示该余额，但自动抵扣至另一应付单的工作流尚未实现。
7. 在应付单上点击“登记付款”，输入真实支付金额和支付日期。普通付款须核销到一个或多个应付单，分配金额合计必须等于付款金额，且不能超过应付单未付余额。若应付单设置了分期，可以将一笔真实付款分配到本应付单的一个或多个期次，系统同时校验各期余额及各期分配合计。结算有到期日时默认生成单期安排；可在首次付款前点击“设置分期”，拆成多期，但所有期次金额之和必须等于应付净额。任一期发生付款或退款核销后，不可再改分期结构。合法合同预付款单独登记为“预付款”，不直接核销结算应付。退款仍关联原付款，系统按原应付与期次分配反向恢复余额。
8. 释放质保金前必须有最终结算，且释放金额不能超过当前质保金余额。释放动作生成独立的质保金应付单；质保金核销/扣罚需要留存参考依据。
9. 供应商发票先登记再核验。只有核验通过的发票才可分配至应付来源；发票分配金额不能超过发票金额或相应应付来源的正向应付基数。发票核验不会自动完成付款，也不会自动生成实际成本。
10. 如结算单被驳回，可编辑后重新提交；已确认或已过账金额不能原位编辑。结算过账会保留累计前值、本次增减额与累计后值的过账快照；过账后的更正应走结算调整单，并保留原单、调整依据和审计记录。

### 7.5 分供合同与实际成本关联

在“实际成本录入”新增成本时，可选择对应分供合同；也可以在成本台账点击“关联合同”补关联历史成本。补关联只修正来源关系，不修改成本金额、不创建付款记录。

历史成本不会仅凭供应商名称或金额自动匹配分供合同。关联前请人工核对合同编号、供应商、发票、验收/结算资料；找不到可靠依据时应保留“未关联”，不要强行匹配。

### 7.6 指标口径

- **分供合同金额**：原始签约金额叠加已生效补充协议。
- **执行中/完工待结算合同额**：当前状态为“执行中”或“完工待结算”的合同当前金额合计，不是精确的未履约承诺额。
- **实际成本**：已发生、按规定确认并录入的成本记录；仅通过合同关联汇总，不由付款额推算。
- **累计净付款**：实际付款总额减退款/退回总额。
- **未付应付**：已过账应付净额减分配到该应付单的净付款核销额；负数调整另显示为供应商待返还/抵扣，不与正向未付应付混为一谈。
- **预付款余额**：已登记预付款减关联退款及已过账结算扣回。
- **质保金余额**：已留置质保金减释放和经批准核销金额。
- **发票已分配/未分配**：核验通过后分配到应付来源的金额汇总，仅用于凭证核对，不替代应付或付款。
- **合同额减已关联实际成本的预警差额**：只是算术差额，不等于未履约承诺、未付款余额或预计成本；不能替代履约/验收计量、未开票应计成本或正式分包结算。
- **预计成本**：独立的成本预测口径。当前预计完工成本仍以目标成本为基准，不等同于分供合同额或付款计划。


### 7.7 往来单位库与单位经营档案

1. 在左侧“往来单位库”中搜索单位全称、历史名称或统一社会信用代码。单位档案统一管理建设单位、材料供应商、分包单位、租赁单位、服务商等角色；同一个单位可同时有多个角色。
2. 新建单位至少填写单位全称和角色。统一社会信用代码、注册地址、联系人、开票资料等可按掌握情况补充。单位档案中的银行资料等敏感信息应依授权维护。
3. 主合同、分供合同录入时，在“合同相对方”搜索并选择已有单位，系统会带出已维护资料；未找到时可按界面提示快速建档。选择单位后，业务单据通过单位 ID 关联，同时保留当时的合同名称快照。
4. 同名但可能属于不同法律主体时，不要随意选择或新建重复名称。系统会提示已存在同名记录；只有管理员在核实后，提供独立统一社会信用代码并明确确认，才可建立同名不同主体档案。
5. 点击合同、项目或成本记录中的可点击单位名称，可打开“单位经营档案”，查看该单位在当前账号有权限访问项目中的合同、结算、应付、收付款、发票及成本摘要，再从项目/合同行进入原始业务页面。
6. 档案标记“主体待核验”表示身份尚未基于可靠证据确认；特别是升级迁移后按旧文本名称回填的单位，不要直接把汇总金额用于最终对账。管理员应依据统一社会信用代码、签约主体、合同/资质文件完成复核，并在档案中记录核验依据。
7. 普通用户的单位经营档案仅聚合其有权限访问的项目；公司管理员可查看全公司范围。即使同一单位同时具有收入侧和支出侧角色，主合同金额、分供合同金额、结算、应收/应付、收付款和成本也会分别显示，不应相互抵销为一个无明确会计含义的“净合作额”。

## 8. 目标成本清单

1. 打开“预算与目标成本”。
2. 点击“新增条目”，填写清单编号与名称，可补充单位、工程量、单价、合价和父级。
3. 清单以树形方式展示。创建子项时，选择已有父级。
4. 如果未输入合价，页面按工程量乘单价提供计算结果。
5. 如需批量导入，请使用 CSV 导入入口，先选择文件并预览，再确认提交。

CSV 列头：

```csv
code,name,parentId,unit,quantity,unitPrice,totalPrice,sortOrder
01,土建工程,,,,,0,1
0101,基础工程,01,,,,0,1
010101,钢筋混凝土独立基础,0101,m3,320,1200,384000,1
```

请使用 UTF-8 编码，确保父项出现在子项之前。`parentId` 可填本次导入中已存在的父级编号，也可填项目内已有父项的编号或数据库 ID。项目内清单编号不得重复。当前不支持原生 `.xlsx` 文件或通过网页修改已有清单项父级。

目标成本按叶子项合计，父项与子项不会重复计入总额。

## 9. 实际成本录入

1. 打开“实际成本录入”。
2. 点击“新增成本”。
3. 选择费用类型：人工费、材料费、机械费、分包费或其他间接费。
4. 填写发生日期、摘要、金额；可补充数量、单位、单价、发票号、供应商或班组、备注。
5. 选择对应目标成本清单项（如适用）；如果费用来自采购/分包/租赁等已签合同，也选择“分供合同”，然后保存。
6. 可使用页面顶部的类型卡片、日期/关键字筛选缩小结果范围。已存在的历史成本可通过“关联合同”按钮补关联；系统不会自动猜测合同归属。

金额必须大于 0，数量和单价不能为负。录入前请核对项目和日期。管理员或有相应项目角色的用户可将成本记录归档；归档会使其退出常规统计，但记录不会从数据库物理删除。当前版本未开放批量成本导入和 Excel 导出。合同付款台账不会自动增加实际成本；不要将同一笔付款和同一笔已发生成本重复录入到成本汇总。

## 10. 进度款申报与到账

### 10.1 创建申报

1. 确认项目已建立业主主合同，然后进入“进度款管理”，点击“新建申报”。申报会关联该项目主合同。
2. 填写期次、申报日期、截止计量日期、申报金额和备注。
3. 保存后状态为“草稿”。期次在同一项目中必须唯一。

### 10.2 推进状态

按照实际审核进度推进：

- 草稿 → 已申报
- 已申报 → 审核中或已驳回
- 审核中 → 审批通过或已驳回
- 被驳回后，回到草稿再修改和重新提交

只有具备对应项目写权限的用户可以推进状态。审核通过时可以填写核定金额；不填写时系统以申报金额作为核定金额。

### 10.3 登记到账

1. 在审批通过的申报上点击“登记到账”。
2. 填写本次到账金额、到账日期，可记录参考号和备注。
3. 同一申报允许分次到账，但累计到账金额不能超过核定金额。
4. 累计到账达到核定金额后，状态自动变为已到账。

如果系统提示累计金额超限，先刷新页面并核对已有到账明细，避免重复登记同一笔收款。

### 最终结算后如何收款

当主合同最终结算已正式过账后，进度款页面仍用于查询历史申报、审批状态及原到账流水，但不再开放新的到账登记入口。后续新增到账与退款请进入项目工作台的“竣工结算与应收”页面，选择对应应收单或其分期进行登记。系统同时校验单笔应收余额和主合同净应收敞口，避免最终结算负向调整后继续超额收款。原有进度款收款的退款会保留原流水，并在历史到账明细中显示为负向“退款冲回”。

## 11. 变更签证

1. 确认项目已建立“主合同管理”中的业主主合同，然后打开“变更签证”，点击“新增变更”，填写编号、名称、类型、发生日期、公司内部送审金额和说明，并选择增加/减少合同额方向。每条变更将关联当前项目的业主主合同。
2. 按公司内部流程依次提交、进入审核并登记内部审批结果。内部核定金额用于内部管理，不会单独改变当前有效合同额；提交人不得审批本人提交的业务。
3. 外部确认凭证登记中选择 A（正式书面凭证）、B（合规电子凭证）或 C（微信、邮件、会议纪要等非正式沟通凭证），填写外部确认人及授权依据、确认时间、金额、范围、凭证定位、完整上下文，并上传对应原始文件。
4. A/B 类凭证在登记为“材料齐备”后按当前规则立即生效；C 类凭证进入“待独立核验”，必须由另一名具有项目核验权限且不同于业务提交人的人员作出核验结论。核验通过后立即生效，不需要再审批一次外部确认金额。
5. 如果证据不完整，选择“需要补充材料”；如果存在争议，选择“存在争议”。这两种状态均不计入当前有效合同额。更正已登记的生效金额不得通过覆盖原记录完成，应保留原记录并走更正/新变更流程。
6. 列表可查看内部流程状态、外部凭证状态、外部确认金额和附件。凭证下载会记录审计日志；系统同时保存文件 SHA-256 校验值。

当前有效合同额按“原始合同金额 + 已生效合同调整净额”计算。减少项按负数计入，系统会阻止使有效合同额降至负数的生效操作。正式补充协议的办理进度仍需单独跟踪，补充协议未签完不会阻止已经通过规则核验的凭证生效。

## 12. 成本分析

进入“成本分析”，选择当前项目后，可以查看合同金额、目标成本、实际成本、简化预计成本、费用分类和月度实际成本趋势。

请注意：

- 实际成本按已录入且未归档的记录汇总。
- 目标成本只统计叶子清单项。
- 当前预计完工成本是简化基线，不是基于剩余工程量、挣值或未入账承诺成本的预测结果。
- 分析结果用于经营跟踪，不应单独作为法定结算或财务决策依据。

## 13. 账号与项目权限

1. 系统管理员进入“账号与项目权限”，创建每位业务人员独立账号，初始密码至少 12 位。
2. 在该页面选定当前项目，为用户分配项目负责人、项目经理、预算/成本经办或只读角色。用户只有加入相应项目后才能访问项目数据。
3. 为确保分离职责，应使用不同账号分别办理变更提交、内部审批和 C 类凭证核验；系统会在服务端阻止提交人自审批或自核验。
4. 创建账号及角色调整会记入审计日志。账号密码重置和停用目前仍需由维护人员通过受控运维流程处理。

## 14. 账号与数据安全

- 不要共享账号或把密码写在项目备注中。
- 保存金额相关数据前，核对项目、金额、日期、单位和关联清单。
- 不要把管理员密码或 `.env` 文件发送到群聊、邮件群发或工地共享盘。
- 当前版本没有自助改密、密码找回和账号停用界面；请联系维护人员执行受控处理。
- 变更签证凭证附件保存在 API 的受控本地目录；其他单据仍需按单位档案制度保管原件。请勿直接移动或删除存储目录中的文件，并确保附件目录与数据库一起备份。Windows 部署时应配置 NTFS ACL，只允许 API 运行账号及指定备份管理员访问凭证目录。

## 15. 常见问题

**登录失败**：检查邮箱与密码，并联系维护人员核对管理员初始化设置和数据库服务。

**找不到项目**：确认当前登录用户拥有该项目访问权限；请管理员检查项目成员关系。

**项目编号重复**：项目编号全系统唯一，请使用新的编号。

**CSV 导入失败**：检查列名、UTF-8 编码、重复编号和父项顺序；不支持直接导入 XLSX。

**页面资源打不开**：联系维护人员检查 API、静态构建目录和日志；Windows 默认日志在 `apps/api/logs/`。

**误录成本**：请联系有权限的管理员归档错误记录后重新录入，并按单位流程保留审批凭据。进度款到账和变更核定属于敏感业务，应先核对审计流水再处理。

**系统重启后无法打开**：请维护人员检查 PostgreSQL Windows 服务、Windows 任务计划程序任务状态及 `api-service.log`。

## 16. 单位身份与汇总数据提示

单位名称相似不代表属于同一法律主体。名称、历史别名和人工填写的联系人只用于检索，不是可靠身份唯一键。历史单位档案默认未核验；在完成主体复核之前，单位经营档案的跨项目聚合属于待核对业务视图，并非最终财务对账凭据。银行账户、发票资料和单位变更等敏感业务应由具有相应权限的人员操作。


## 17. 业主侧竣工结算与应收账款

在项目工作台的“竣工结算与应收”进入。进度款申报审批通过后会形成应收记录；最终结算金额填写为最终累计确认金额，不能填写成阶段增量。正式过账后系统计算与历史累计确认金额的差额，只将差额记入应收账本。结算明细可不填写；填写明细时需与报审金额一致。

普通到账从应收单进入，金额不能超过该应收单未收余额以及同一主合同扣除负向调整后的净应收敞口。最终结算过账后，不再通过进度款历史页直接登记到账，应统一进入应收账款。退款必须关联原到账记录，系统保留原记录并反向恢复核销。业主预付款、质保金留置/释放和应收到账分别管理。

## 18. 分供合同与结算

“分供合同与结算”入口内提供两个子视图：“合同台账与付款”用于分供合同、补充协议、付款计划和实际付款/退款；“结算与应付账款”用于结算单、外部确认、应付单、分期、付款核销、质保金和供应商发票。两个子视图共用一个入口，但不把所有资料塞到同一张长表格。

## 19. 编号与登录记住账号

项目和业务单据在编号栏留空时由系统自动生成编号。样式一般为“项目编号-业务类型-年份-流水号”；合同编号仍可手工填写外部/纸面归档号。已生成编号不会因为名称修改自动重编，也不会回收已使用编号。

登录页的“记住账号”只保存邮箱。密码请使用浏览器或操作系统的密码管理器保存和自动填充；系统不会将密码明文保存在网页本地存储中。共用电脑上不要保存密码。


## 20. 界面外观与交互设置

在主导航栏下方的设置条中，可以直接更改以下偏好，修改会保存在当前浏览器中：

- **主题**：象牙雅白、香槟曜金、黑曜极光、冰川天青或跟随操作系统。四套主题分别采用冷靛、中性暖金、深色极光与冰川蓝的界面材质；跟随系统时会在象牙与黑曜之间切换。
- **密度**：舒朗布局保留更多间距；紧凑布局缩小表格行高和卡片间距，便于在同一视口查看更多记录。
- **强调色**：跟随主题、靛青、青玉或朱砂。只改变界面强调色，不会改变业务状态含义或财务数据。
- **宽屏**：减少内容区两侧留白，适合大显示器；再次点击可恢复标准宽度。
- **减少动效**：尽量关闭页面切换、按钮和弹窗动效，适合希望减少视觉动态效果的用户。
- **重置**：将上述选项恢复为象牙雅白、舒朗密度、跟随主题色、标准宽度及正常动效。

项目工作台导航不再使用收入侧/支出侧文字标题，而是通过轻微背景色、间距和细分隔线区分两组业务。全局命令面板支持 `Ctrl/Cmd+K`、关键词过滤、方向键选择、`Enter` 跳转和 `Esc` 关闭。焦点位于页面空白或表格行时，可用 `J/K` 或方向键在表格行之间巡检；聚焦某行后按 `Enter` 可执行该行的首个操作入口。输入框、下拉框等控件仍保留自身原生键盘行为。列表支持即时搜索、状态筛选、页签切换；在宽表格中可以横向滚动，表头在表格滚动区域中保持可见。

## 21. 产品名称与标识

系统名称为“墨衡”。侧栏、登录页和浏览器标签使用同一套 SVG 品牌标识，不依赖 emoji 或远程图标图片。主题、密度和强调色只属于个人界面偏好，不会修改共享项目数据。
