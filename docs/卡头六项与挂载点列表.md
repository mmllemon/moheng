# 卡头六项修正 + 挂载点列表外层态

日期：2026-10-25

## 一、卡头必须是 absolute 浮层，不是流元素

```css
._tileTop_931a2 {
  position: absolute; top: 0; left: 0; right: 0;
  z-index: 5;
  display: flex; align-items: flex-start; justify-content: center;
  height: var(--titlebar-h, 44px);
  background: transparent;
  pointer-events: none;
}
```

**它浮在内容之上、不占布局**，内容靠 `>header+* { margin-top: calc(6px*2 + 24px) }` 让位。

我原来是普通流元素，还给它加了 165px 右 padding，× 被推到卡片中间。

修法：

```css
.workspace-card-top {
  position: absolute; top: 0; left: 0; right: 0;
  z-index: 5;
  height: var(--titlebar-h, 44px);
  padding: 12px max(16px, var(--ttb-clearance-right, 0px)) 8px max(16px, var(--ttb-clearance, 0px));
  pointer-events: none;
}
.workspace-card-surface-main { margin-top: var(--titlebar-h, 44px); }
```

同时卡头要移到 `section` 直接子级（对齐 `_tileTop` 是 `_tileShell` 的直接子元素）。

`pointer-events: none` 只给可交互元素恢复，标题不恢复（否则它挡住下面 tab 栏）：

```css
.workspace-card-top > button,
.workspace-card-top > .workspace-card-actions { pointer-events: auto; }
```

## 二、标题样式：14px / 500 / accent

我一开始用了 `_chatTitleText`（16px / 700 / accent），那是**聊天卡自定义标题段**的样式。真正的卡头标题是 `tve` 组件的 `_tbTitle_bbf9b`：

```css
._tbTitle_bbf9b {
  font-family: var(--font-ui);
  font-size: var(--tb-title-size, var(--fs-body));    /* 14px */
  font-weight: var(--tb-title-weight, 500);
  line-height: 1;
  color: var(--accent);
}
```

实测 `14.4px / 500 / rgb(70,107,128)`。

## 六、红框那块：挂载点列表（studio 外层态）

`Fet` 的 studio 有两层，靠 `data-inner` 切换：

```jsx
<div className={stage} data-inner={inner ? '' : undefined}>
  {inner && <Toolbar />}
  <Chrome />
  <div className={layers}>
    <div className={layerList}><MountList /></div>   {/* 外层：挂载点列表 */}
    <div className={layerTree}><Tree /></div>        {/* 内层：目录树 */}
  </div>
</div>
```

`$et`（挂载点列表）每行是 `dO`：图标 + 名称 + `identityChip` + `statusMark`。

moheng 只有一个项目目录，所以外层就一行「项目根目录」。之前 `innerDir` 由 `workspaceTab` 派生、恒为 `''`，永远进不到外层。

修法：

```ts
const [enteredDir, setEnteredDir] = useState<string | null>(null);
const innerDir = workspaceTab === 'studio' ? enteredDir : null;
useEffect(() => { if (workspaceTab !== 'studio') setEnteredDir(null); }, [workspaceTab]);
```

点外层那一行 `setEnteredDir('')` 进目录树。

实测 `mountList 385×282`，每行 `369×55`。

## 七、把手：去掉负 margin

```css
/* hana 卡片栈 gap = --panel-edge-gap（6px），两张卡之间应有真实间隙 */
.card-split-handle { margin-block: 0; }
```

之前 `-3px` 把间隙吃成 0，两张卡粘在一起，看不出圆角分隔。

## 八、这一轮的教训

**我拿 `_chatTitleText` 当卡头标题，因为它的名字里有 chatTitle。**

真正的卡头标题是 `tve` → `oe.tbTitle` → `_tbTitle_bbf9b`。追链路：JSX 里 `className={[oe.tbTitle, n2]}` → `oe` 的映射表 → `tbTitle: _tbTitle_bbf9b` → CSS。

名字相似不等于同一个东西。要顺着 **组件 → 类名映射表 → CSS 类** 这条链走完，不能看到「title」就认定。
