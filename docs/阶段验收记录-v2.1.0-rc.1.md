# 阶段验收记录 v2.1.0-rc.1

日期：2026-10-15  
当前状态：Release Candidate；未完成全量发布验收。

## 本轮交付范围

- 八类现有 CSV 台账新增原生 XLSX 导出。
- 新增报表目录、模板 JSON 契约、字段白名单校验、预览 API、模板版本/发布/归档/恢复 API 和审计记录。
- 新增个人/项目/系统三种模板作用域，以及模板设计器前端。
- 新增真实数据预览、最多 80 行屏幕预览、最多 10,000 行打印数据路径与打印截断提示。
- 新增目标成本 XLSX 模板下载、上传预检、静态值解析、字段映射、确认前复检和事务写入；保留 CSV 导入。
- 新增 ZIP 结构与解压尺寸预检，不接受 ZIP64、加密工作簿、过大内容、外部链接/嵌入对象、公式及错误单元格。
- 新增数据库迁移用于存储模板、发布定义和版本记录。
- 新增报表模板、XLSX 生成和预算 XLSX 解析单元测试源，以及静态 release contract 检查。

## 静态验收判据

发布前至少应通过：

- `npm run validate:release-candidate`
- TypeScript/TSX 语法扫描
- CSS/PostCSS 解析
- `git diff --check`
- 纯逻辑/库单测（需要项目依赖）

静态代码契约通过仅能证明约定的源码标记存在，不能代替严格 TypeScript、构建、真实数据库或浏览器测试。

## 当前环境阻塞

- 当前容器是 Node.js 22.16.0，工程 `engines` 要求 Node.js `>=24.0.0`。
- `npm install --ignore-scripts --no-audit --no-fund` 在当前环境超时，工作区没有完整 `node_modules`，也没有可审查的 `package-lock.json`。
- 因依赖没有安装，ExcelJS 往返测试不能在此环境声称通过；Prisma Client 生成、迁移部署、完整 API 测试、严格类型检查和生产构建也未通过。
- 未连接真实 PostgreSQL，不可声称新迁移已在数据库通过。
- 未在实际 Windows 浏览器、Excel 和 WPS 中执行端到端验收，分页及打印最终效果待实机确认。

## 升级为正式版的必要条件

1. 使用 Node.js 24+ 干净环境安装并审查 lockfile。
2. 运行 Prisma validate/generate，备份数据库后应用迁移，并通过 `/health`。
3. 完整 API 测试、前后端 lint/build 全通过。
4. 执行 `docs/WP8-XLSX报表设计器端到端验收清单-v2.1.0-rc.1.md` 全部操作并保留记录。
5. 修复验收中发现的问题后重新打包与生成校验和。

因此本记录不将该版本标为生产发布完成。
