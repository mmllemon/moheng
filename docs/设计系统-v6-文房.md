# 墨衡设计系统 V6 · 文房 / 册页

> 状态：已落地于 `apps/web`。本文件是当前唯一有效的界面设计规范；`docs/设计系统规范-Pro-Tier-Suite-v4.2.0.md` 仅作历史归档，不再作为实现依据。
>
> 关键词：纸、墨、订口、朱批、克制、可读、可追溯。

## 1. 设计立场

墨衡不是消费级 SaaS，也不是“数据大屏”。它是一本被频繁翻阅的**工程经营册页**：项目、合同、预算、成本、回款、变更都写在纸上，读者需要在几秒内找到数字、判断风险、留下批注。

V6 的目标不是“更漂亮”，而是把界面从“卡片堆叠 + 蓝色高亮 + 装饰性动效”拉回到**纸面秩序**：

- **一张纸**：侧栏与主区共享同一张纸，不再用深色侧栏把工作区切成两块。
- **一条订口**：3px 墨脊 + 1px 铜线 + 18px 折影，建立“册页”的装订关系。
- **一枚印**：品牌用朱砂印章 + 毛笔字，不用英文副标、不用渐变 Logo。
- **一手批注**：朱批只出现在“被选中/被勾选/被圈定”的位置，不用于普通按钮。
- **数字优先**：金额、比率、日期使用衬线数字与等宽数字，表格行高与对齐优先于装饰。

## 2. 设计令牌

实现文件：`apps/web/src/styles/v6.css`（无 layer，覆盖 `styles/legacy.css` 的 legacy layer）。

规则：

- 朱砂 `--seal` **不是**通用强调色。它只用于“批注性”的状态：印章、当前 tab 圈、checkbox 勾、日期圈、打开的下拉下划线。
- 主按钮用墨色，不用朱砂；危险按钮用描边 + 朱砂文字，不用大块红底。
- 不使用渐变作为大面积背景。唯一允许的材料是宣纸纹理。
- 新增颜色必须先进入本表；禁止在页面里写新的 hex。

### 2.2 宣纸纹理

- 资源：`apps/web/public/textures/xuan-1024.webp`（1024×1024，约 259KB）。
- 用法：`body` 上叠加 `multiply`，再叠一层极浅的纵向纸色渐变；`background-attachment: fixed`。
- 原则：**只在纸面出现，不在弹窗/表格内部重复铺**。纹理强度以“近看有纤维、远看是纯色”为准；如果看起来像旧报纸，说明过重。
- 打印时关闭纹理与侧栏，见 `@media print`。

### 2.3 字体

| 角色 | 字体 | 许可 | 文件 |
| --- | --- | --- | --- |
| 标题 / 印章 | MH Serif SC（Noto Serif SC 子集） | OFL | `public/fonts/notoserifsc.woff2` |
| 数字 / 金额 | MH Serif（Spectral Semibold） | OFL | `public/fonts/spectral-semibold.woff2` |
| 品牌毛笔字 | MH Brush（Ma Shan Zheng，子集“墨衡”） | OFL | `public/fonts/mashanzheng-subset.woff2` |
| 正文 / 控件 | HarmonyOS Sans SC / PingFang SC / Microsoft YaHei | 系统 | — |

字号：

| 角色 | 字号 | 字重 | 说明 |
| --- | --- | --- | --- |
| 页面 H1 | 34px（移动 24px） | 600 | 衬线，字距 .04em |
| 弹窗 H2 | 22px | 600 | 衬线 |
| 区块标题 | 15–16px | 600 | 无衬线，前置 12px 铜线 |
| 正文 | 12.5px | 400 | 行高 1.65 |
| 表格正文 | 12.5px | 400 | 等宽数字 |
| 表头 / 标签 | 10.5–11px | 500 | 字距 .07–.14em |
| 辅助说明 | 10–11px | 400 | 不再出现 9px/10px 正文 |
| 主数字（Hero） | 56px（移动 38px） | 600 | 衬线等宽 |
| 统计条数字 | 22–24px | 600 | 衬线等宽 |

规则：

- 中文标题不再配英文 eyebrow。`.eyebrow` 与所有 `*kicker/*overline` 在 V6 中隐藏。
- 金额一律使用 `font-variant-numeric: tabular-nums`；金额小数位在同一屏保持一致。
- 正文最小 12.5px；表头/标签最小 10.5px；不再用 9px 作为“精致感”。

### 2.4 间距、圆角、阴影

- 间距基数 4px；页面左右 30px（移动 16px）；区块间距 18–28px；表格单元格 9–12px。
- 圆角：控件 3px，面板/弹窗 2px，标签 2px；不再使用 9–16px 的大圆角卡片。
- 阴影：默认 `none`；只有浮层（下拉、日期、命令面板、账号菜单、弹窗）使用 `--shadow-pop`。纸面本身靠线，不靠投影。
- 边框：常规 1px `--line`；表格外框/强调 1px `--line-2`；合计行 3px double。

### 2.5 动效

- 只保留三类：**展开/收起**（180–220ms）、**浮层淡入**（140–180ms）、**状态切换**（120ms）。
- 使用 `cubic-bezier(.2,.8,.2,1)`；不允许弹跳、视差、极光、3D 翻转。
- 页面切换不做整页 fade；`route-transition` 动画已关闭。
- 支持“减少动态效果”：`data-motion="reduced"` 时移除过渡与平滑滚动。


### 2.6 全仓去卡片化（2026-10-20 补）

V6 不允许“白色填充 + 阴影 + 大圆角”的独立卡片成为页面骨架。实现上：

- 旧样式表 5–16px 的圆角统一收敛为 2px；50% 仅保留头像/圆形状态点。
- `card / metric / stat / tile / box` 类统一透明底、无阴影；`tag / badge / pill / chip` 统一透明底 + 1px 线。
- 区块用 1px 顶/底线、左侧 2px 铜线、连续分栏组织；需要强调的档案才使用 `surface` 底。
- 项目页选择器统一在顶栏；项目上下文条只在移动端保留，避免同一状态出现两套入口。

页面族判断：

| 页面族 | 组织方式 |
| --- | --- |
| 经营总览 | Hero + 标尺 + 台账 + 待办 + 变动 |
| 项目驾驶舱 | 身份条 + 4 指标 + 趋势/待办 + 业务入口 |
| 合同/结算/成本/变更 | 页头 + 统计条 + 筛选 + 台账 + 备注 |
| 项目档案/成员 | 档案 Dossier / 双栏权限工作区 |
| 报表中心 | 入口 + 台账选择 + 参数 + 导出 |
| 系统治理 | 二级导航 + 指标条 + 表格/表单 |
| 登录安全 | 指标条 + 会话/事件表 + 分页 |
| 助手 | 页头 + 三栏工作台/纸面空态 |

## 3. 布局

### 3.1 应用壳

- 侧栏：224px；折叠 62px；移动端为 248px 抽屉，带遮罩，点击遮罩/路由变化关闭。
- 侧栏与主区共用纸面；左侧 3px 墨脊，右缘 1px 铜线，折影 18px。
- 顶栏：54px；左侧面包屑，右侧搜索、待办、快捷操作、界面设置、账号。
- 项目上下文条：40px；全局页显示“全局经营视图”，项目页显示项目切换与状态。
- 内容区：最大 1440px，左右 30px（移动 16px）；页脚为版本与版权。
- 移动端：侧栏抽屉 + 顶栏菜单按钮；命令入口收为图标；面包屑在 640px 以下隐藏。

### 3.2 页面模板

1. **册页首页（Dashboard）**：H1 + 一句话说明 → 合同额 Hero + 成本标尺 + 2×2 统计 → 左表右待办 → 近期变动。
2. **台账页（Budget/Costs/Contracts…）**：H1 + 说明 + 一主一次操作 → 统计条 → 筛选/搜索 → 表格 → 备注。
3. **工作台页（Reports/System）**：H1 → 入口/能力清单 → 选中对象设置 → 主操作。
4. **档案页（Project/Party）**：H1 → 全宽档案卡（左事实、右比率/日期）→ 关联业务。
5. **助手页（隐藏路由）**：H1 + 只读说明 → 三栏工作台（会话 / 对话 / 证据）；未启用时显示纸面空态。

## 4. 组件规范

组件实现以 `apps/web/src/components/Ui.tsx` 与 `apps/web/src/styles/v6.css` 为准。详细 API 见 `docs/组件库-v6-文房.md`。

### 4.1 PageHeader

- 结构：H1（衬线）+ 一句说明 + 右侧操作。
- 不渲染 eyebrow；不再使用“PORTFOLIO / OVERVIEW”等英文眉标。
- 每页最多一个主按钮（墨色）；其余为描边/文字按钮。

### 4.2 统计条（Metric / StatStrip）

- 桌面 4 列、移动 2 列；单元格之间用 1px 线，不用独立卡片。
- 标签 10.5px；数字 22–24px 衬线等宽；说明 10.5px。
- 不显示装饰性图标；图标只在需要解释动作时出现。

### 4.3 面板（Panel）

- 结构：标题（15–16px，前置铜线）+ 说明 + 内容。
- 默认无外框、无阴影；用 1px 顶线/底线组织。
- 只有需要强调的“档案卡”才使用 `surface` 底 + 1px 外框。

### 4.4 数据表

- 表头 `paper-2` 底、10.5–11px、字距 .07em；行高 40–44px；数字右对齐。
- 合计行 3px double 上框；行 hover 用纸色，不用蓝色。
- 首列主信息 12.5px 600；次信息 10.5px。
- 移动端表格允许横向滚动，禁止把项目名压成竖排；表格最小宽度 680–860px。

### 4.5 按钮

- 主：墨底纸字；次：纸底墨字；幽灵：无底；危险：描边朱砂。
- 高 32px；小 26px；圆角 3px；图标 14px。
- 一屏一个主按钮；移动端隐藏次要按钮，只保留“预览/导出”与主操作。

### 4.6 表单

- 输入高 34px；标签 11px；错误 10.5px 朱砂；焦点铜色 3px 外环。
- 下拉：纸面浮层、选中项朱砂勾、打开时底部朱砂手写下划线；支持键盘上下/回车/Esc。
- 日期：选中日朱砂手绘圈；今日铜点；支持上月/下月/今天/清除。
- 复选框：15px 方框；选中为淡朱砂底 + 手写勾；不改变业务含义（勾选≠审批通过）。

### 4.7 弹窗

- 宽 580px（大表单 760px）；纸面；2px 圆角；标题衬线 22px。
- 必须有 `role="dialog"`、`aria-modal`、Esc 关闭、焦点陷阱、关闭后焦点回到触发点。
- 底部操作条 sticky；主操作在右。

### 4.8 空态 / 加载 / 错误

- 空态：44px 圆框 + 衬线标题 + 一句可执行说明 + 主操作；不使用插画。
- 加载：16px 铜色 spinner + 文案；超过 300ms 才显示。
- 错误：左侧 2px 朱砂线 + 衬线标题 + 重试按钮。

### 4.9 助手

- 全局弹窗：标题栏快捷操作旁的 Sparkles 按钮打开；旧 `/cost/assistant` / `/assistant` 只作为兼容入口，不再占用工作台页面。
- 启用时为三栏：会话 236px / 对话 / 证据 300px；≤1120px 证据栏变抽屉，≤760px 左栏变横向会话条、弹窗近全屏。
- 只读徽标、项目 chip、证据引用是业务信息，不用装饰性渐变。


### 4.10 确认与焦点

- 全仓禁止 `window.confirm` / `window.prompt`；统一使用 `confirmAction({ title, description, confirmText, tone })` / `promptAction({ inputLabel, minLength, multiline })`。
- 危险操作使用朱砂实底确认按钮；取消按钮默认聚焦；退回原因等输入使用同一弹窗。
- 任何弹层打开时：焦点进入弹层、Tab 在弹层（含日期/下拉 portal）内循环、背景 `inert`、Esc 关闭、关闭后焦点回到触发按钮。
- 新弹层必须挂载 `.modal-backdrop` / `.ldg-drawer-layer`，由全局 `FocusTrap` 接管；不要在页面内另写不完整的焦点逻辑。

### 4.11 系统治理页

- 系统页是“管理工作台”，不是把表单和表格全部纵向堆叠：优先用页内页签分区，一次只呈现一个工作面。
- 页签是文字下划线，不用卡片式 segmented control；计数用纸色小标签。
- 账号/参数这类“创建 + 列表”页面采用左侧工作栏 + 右侧主表；移动端回落单列，页签与表格仍可横向滚动。
- 页签切换只控制 `hidden`，不销毁本地表单状态。

| 打开下拉 | 触发器底部朱砂手写下划线 |

## 6. 内容与语气

- 中文优先；英文只保留在必要的业务缩写（XLSX、CSV、MFA、TLS）。
- 标题用“动作/对象”，不用“赋能/洞察/一站式”。
- 说明句写“这页能做什么、数据口径是什么”，不写营销文案。
- 金额、比率、日期必须带口径；空值用“—”，不用 0 冒充。
- 不用“AI 驱动”“智能升级”等空话；助手页明确“只读试点/默认关闭”。

## 7. 可访问性

- 正文对比度 ≥ 4.5:1；大字/标签 ≥ 3:1；V6 纸/墨组合已按此校验。
- 键盘：所有交互可 Tab 到达；弹窗焦点陷阱；Esc 关闭；下拉/日期支持方向键。
- 触控目标 ≥ 30×30px（移动端按钮 32px、图标按钮 30px）。
- 表格横向滚动容器可键盘滚动；移动端不隐藏关键金额列，只滚动。
- `prefers-reduced-motion` 与界面设置“减少动态效果”双重尊重。

## 8. 治理与迁移

- `styles/legacy.css` 被包在 `@layer legacy`，只做兼容，不再新增规则；新样式只进 `v6.css`。
- 组件优先：页面不直接写颜色/圆角/阴影；使用 token 与组件类。
- 新增页面必须包含：PageHeader、一个主操作、空/错/加载态、移动端断点、键盘路径。
- 禁止：新的 9–10px 正文、新的蓝色强调、新的 9px+ 大圆角卡片、新的 `window.confirm`（迁移到 Dialog）。
- 主题：V6 收敛为单一“宣纸”纸面；此前的四套材质主题与独立强调色不再暴露。深色“墨夜”作为后续独立主题再评估，不在本版混用。
- 冻结项：`ReportStudio` 内嵌 Univer 的表格皮肤仍由 Univer 自身控制；V6 只统一外框、工具条与页头。

## 9. 验收口径

- 1440×900 与 390×844 无页面级横向溢出。
- 页面正文 ≥ 12.5px；表头/标签 ≥ 10.5px。
- 一屏 ≤ 1 个主按钮；移动端次要操作收起。
- 所有浮层有 Esc/外部点击关闭；弹窗有 role/aria-modal/焦点陷阱。
- 表格金额不截断；移动端用滚动而非压缩。
- 视觉检查：纸面连续、侧栏与主区无“两块板”断裂、朱批只出现在批注位置。

*V6 不是“复古皮肤”，而是一套把工程经营数据放回纸面秩序的工作方法。*
