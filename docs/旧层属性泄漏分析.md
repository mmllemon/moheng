# 旧层属性泄漏分析（2026-10-21）

工具：`scripts/analyze-property-leak.mjs`、`scripts/probe-live-selectors.mjs`
对象：`apps/web/src/styles/{legacy,v6,hana}.css`

## 结论一：级联结构比预期干净

`main.tsx` 的加载顺序 `styles.css → legacy.css → v6.css → hana.css`，但实测浏览器里的
样式表结构是：

| sheet | 内容 | 规则数 | 层 |
| --- | --- | --- | --- |
| 0 | projects-ledger.css | 51 | 无 |
| 1 | `@layer properties` | 39 | 层 |
| 2 | **legacy.css（整体包在 `@layer legacy` 里）** | 1（内含全部） | **最低层** |
| 3 | v6.css | 866 | 无 |
| 4 | hana.css | 1603 | 无 |
| 5 | content-contrast.css | 12 | 无 |

**legacy 被 `@layer` 包住，天然处于最低优先级。** 属性级比对结果：

- `leakHigherSpec = 0`（legacy/v6 没有任何规则靠更高特异度压过 hana）
- legacy 同名选择器 240 条有属性泄漏、v6 有 182 条，但都是同特异度，被 hana 按顺序覆盖

## 结论二：旧层规则 91% 匹配不到任何元素

浏览器实测（6 条路由，遍历全部选择器做 `querySelectorAll`）：

| 层 | 选择器总数 | 命中元素的 | 命中率 |
| --- | --- | --- | --- |
| legacy | 2360 | **206** | 8.7% |
| v6 | 943 | **194** | 20.6% |

命中的全是基础元素与公共容器：`:root`、`body`、`button`、`a`、`h1`、`h2`、`small`、
`.app-shell`、`.page-wrap`、`.status-badge`、`.icon-button`、`.route-transition`。
其余 2154 + 749 条选择器在当前界面上根本不存在对应元素。

## 结论三：禁用旧层，视觉几乎零变化

用 `document.styleSheets[i].disabled = true` 逐层禁用后对比关键元素的计算样式
（10 个目标元素 × 13 个属性 × 4 条路由）：

- 禁用 legacy：**4 处差异**，全部是 `button` 的 `background-color`
  `rgb(53,86,107)` → `rgb(70,107,128)`
- 禁用 v6：**同样这 4 处**
- 同时禁用：**同样这 4 处**

追查 `#35566B`：它**不是旧层的值，是 hana.css 自己的 `--accent-hover`**——
Playwright 的鼠标停在按钮上造成的 hover 态。移走鼠标后差异归零。

也就是说：**legacy/v6 对当前界面没有提供任何 hana.css 未覆盖的样式。**

## 为什么还不能直接删

真实阻断来自功能而非样式：临时注释掉两个 import 后，`ui-visual-regression` 的
对话框焦点陷阱检查失败（找不到「新建项目」按钮）。但该次运行的 API 处于 429 限流
（`Rate limit exceeded, retry in 2 minutes`），登录未成功，所以结论**未被证实**——
需要在无限流状态下重测才能判定。
