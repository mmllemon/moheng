# 多标签预览：替换单文件预览

日期：2026-10-25

## 它是什么

`chalkboard.tile.parallelPreview` —— 并行预览卡，不是简单的文件预览器。

```js
function Eit(n) {
  return {
    titleKey: 'chalkboard.tile.parallelPreview',
    surface: 'card',
    closable: true,
    sizing: { role: 'fixed', minPx: 320, defaultPx: 400 },
    Component: Xst,
    titlebar: { title: () => <PreviewTitle previewId fallbackTitle />, ...isBrowser ? { detachedHeader } : {} },
    chrome: [{ id: 'chalkboard.parallel-preview.actions', slot: 'titlebar-right' }],
    titleMode: 'show',
    cardForm: 'edge-to-edge',
    preferredPlacement: 'detached',      // 默认独立成窗
  };
}
```

`Xst` → `Gq({ variant: 'single', previewId })` → `_previewTileHost`。

## 未做的两项

「打开网站」按需求去掉。

`+` 新建标签按钮**不在 `VDe` 里**。`Gq` 的 return 里 `n2 === 'tile' || n2 === 'single'` 走 `_previewTileHost`，里面只有 `Vt`（标签栏 + 内容），没有 `+`。你截图那个 `+` 是 detached 窗口标题栏（`detachedHeader: hNe`）上的，依赖独立窗口能力。moheng 没有 chalkboard 窗口，所以没有 `+`。

空标签时的入口走空态选择器（`zq`），与 hana 一致：没有打开的标签就显示「打开文件」。

## 一处必要的偏离

hana 的「打开文件」走 `Ij(files, { openSink })`，文件先落到会话产物。moheng 没有会话产物层，改成：先传到当前项目工作区（`POST /workspace/file`，base64），再开标签。失败时在 `notice` 里提示，不静默失败。
