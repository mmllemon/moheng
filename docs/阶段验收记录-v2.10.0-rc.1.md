# 墨衡 v2.10.0-rc.1 阶段验收记录

日期：2026-10-15

## 1. 版本与仓库边界

- 本地基线：`v2.9.0-rc.1`，提交 `f2eafeb`。
- 新版本：`v2.10.0-rc.1`。
- 本轮只在本地 Git 仓库 `main` 分支继续开发；没有从 GitHub `main` 拉取或覆盖本地代码，也没有推送远程仓库。
- 本轮未修改既有财务金额规则和历史数据库迁移；新增自助改密 API，不新增 Prisma schema 或迁移。

## 2. 完成内容

1. 侧边栏重组为“经营中心 / 工作台 / 项目管理 / 系统管理”四个分组。原“工作台”更名为“经营中心”，原“成本业务”更名为“工作台”。
2. “项目档案”和“项目成员与权限”归入项目管理。规范成员路由为 `/projects/members`；历史 `/system/members`、`/workspace/members` 继续兼容跳转。
3. “操作追溯”移入系统管理导航并增加前端管理员路由门禁；经营总览只保留当前账号可见范围的操作摘要。后端审计 API 仍执行原有项目范围授权。
4. 系统管理首页改为状态与风险概览，展示启用账号、最近 200 条会话中有效的会话、最近 200 条事件中的近七日统计、待处理账号和风险事件；专门管理页面只通过侧边导航直达，首页不重复摆放项目/成员入口。
5. 顶栏增加个人中心与账号安全菜单。新增 `/account/security` 和 `POST /api/auth/password/change-self`，支持普通成员自行修改密码：需当前密码，新密码至少 12 位；已启用 MFA 时需新 TOTP 时间步或一次性恢复码。变更通过事务更新密码和 `authVersion`、撤销所有有效会话及刷新令牌，并写入审计和安全事件。
6. 自助改密页面在读取 MFA 状态失败时不显示可提交表单，避免错误地漏掉 MFA 校验；密码修改成功后短暂显示确认消息，再退出当前页面。
7. 扩充系统管理后续路线：组织与权限治理、审批与规则配置、运维与灾备、数据治理与集成；明确规划能力不代表当前已实现。
8. README、CHANGELOG、开发维护指南、用户操作手册和本版设计文档已同步更新。

## 4. 未完成的验证与上线限制

当前执行环境为 Node.js `v22.16.0`，项目 `package.json` 要求 Node.js `>=24.0.0`，且当前工作副本没有安装依赖。

- `npm run build` 未通过：TypeScript 报 `TS2688: Cannot find type definition file for 'node'`，原因是依赖/类型包缺失；这不代表已证明源代码能成功编译。
- `npm test` 未运行成功：系统找不到 `tsx`（`tsx: not found`），因此不是测试用例通过或失败的结果。
- `npm run lint` 同样被缺失的 Node 类型依赖阻塞。
- 尚未完成 `prisma validate` / Prisma Client 生成、真实数据库迁移、浏览器自助改密与 MFA 流程 E2E。
- 公网异地访问仍需部署端配置正式域名/DNS、TLS 证书、Caddy/反向代理、Windows 防火墙与 80/443 端口；尚未完成真实公网连通性与端到端登录验收。

因此 `v2.10.0-rc.1` 仍是开发/验证候选版本，不应标记为生产就绪。

## 5. 安全与兼容性

- 系统管理员页面仍有路由门禁与后端 API 授权；菜单隐藏不替代服务器端检查。
- 公司级 `ADMIN/USER` 身份与项目内角色保持分离。
- 自助改密必须验证当前密码；启用 MFA 时额外验证；变更后撤销旧会话。
- 历史导航 URL 保留重定向兼容。
- 本轮未推送 GitHub 远程；下一步若需发布远程版本，应先执行构建、数据库迁移和端到端验证，再按远程分支现状做非破坏性推送。
