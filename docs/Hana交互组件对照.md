## 页面落地

- /settings/appearance：主题、应用图标、标题字体、纸纹强度、动效、密度与宽屏。
- 系统管理设置：同一 960 设置窗、208px 导航、670px 内容区；搜索支持“主题/备份/模型/字典”等语义别名。
- 项目驾驶舱：身份 + 四指标 + 健康条主卡、带真实摘要的六入口、分供概览。
- 主合同：金额口径并入 hero；删除重复编辑入口与底部重复“关联业务”。
- 待办/报表/变更/账号：内缩行线、状态 token、窄屏账号行卡。
- 全局助手：标题栏 Sparkles 入口；236 / 1fr / 300 三栏弹窗；悬浮 composer；≤1120px 依据抽屉；≤760px 全屏。
- 全局命令中心：760px、范围筛选、键盘操作与分组结果。

## 已知例外

1. **Univer 画布**：ReportStudio/ReportDesigner 内部仍由 Univer 自身渲染，只统一外框、工具条、页头和按钮。
2. **助手真实消息**：本轮验证了弹窗布局、空态、打开/关闭、焦点恢复、深链接和 390/733/900 响应式；真实模型流式消息与工具来源仍需带凭据 E2E。
3. **Hana 未对应语义**：Hana 的贴纸、自定义字体导入、聊天宽度等属于其产品语义，墨衡没有对应业务，不为了像而造假开关。
4. **多主题目录**：当前保留墨衡三主题；不把 Hana 的九套主题硬塞进设置。
