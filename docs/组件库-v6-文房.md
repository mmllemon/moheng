## 2. 基础组件

### 2.1 Button

```tsx
<Button>新增条目</Button>                         // 主：墨底纸字
<Button variant="secondary">预览 / 导出报表</Button> // 次：纸底墨字
<Button variant="ghost">取消</Button>              // 幽灵
<Button variant="danger">归档</Button>             // 描边朱砂
<Button size="small">编辑</Button>                 // 26px
```

规则：一屏一个主按钮；图标 14px；移动端最多保留“首个次操作 + 主操作”；危险操作必须二次确认（Dialog，不用 `window.confirm`）。

### 2.2 PageHeader

```tsx
<PageHeader
  title="预算与目标成本"
  subtitle="维护清单层级、计划工程量和目标成本，为实际成本偏差提供对比基准。"
  actions={<><Button variant="secondary">预览 / 导出报表</Button><Button>新增条目</Button></>}
/>
```

- 不传 `eyebrow`；即使旧页面传入也不会渲染（CSS 兜底隐藏）。
- 标题使用衬线 34px；副标题一句，不超过两行。
- 操作区只放本页动作；全局动作放顶栏。

### 2.3 MetricCard / 统计条

```tsx
<div className="metric-grid">
  <MetricCard label="目标成本总额" value={formatMoney(total, 0)} detail="仅汇总末级清单项" />
  <MetricCard label="成本执行率" value="6.7%" detail="已录成本 ÷ 目标成本" />
</div>
```

- 桌面 4 列、移动 2 列；无卡片阴影，单元格之间 1px 线。
- 图标默认隐藏；数字使用衬线等宽。
- 金额口径写在 `detail`，不要只写“合计”。

### 2.4 Panel

```tsx
<section className="panel">
  <div className="panel-heading">
    <div><h3>成本明细台账</h3><p>当前筛选 {filtered.length} 条 · 合计 {formatMoney(total)}</p></div>
    <button className="panel-header-action">导出</button>
  </div>
  {/* table / empty / loading */}
</section>
```

- 默认无外框无阴影；用顶线/底线组织。
- 标题前铜线由 CSS `::before` 生成，不写装饰元素。

### 2.5 StatusBadge

```tsx
<StatusBadge status={project.status} />
```

- 2px 圆角、1px 描边、10.5px；颜色只表达业务状态。
- 不把“朱砂”用于“审批通过”；朱砂是批注，不是成功色。

## 3. 数据组件

### 3.1 DataTable

```tsx
<div className="table-scroll">
  <table className="data-table">
    <thead><tr><th>项目</th><th className="align-right">合同额</th></tr></thead>
    <tbody>{rows.map((r) => <tr key={r.id}>
      <td><strong className="table-primary-text">{r.name}</strong><small className="table-subtext">{r.code}</small></td>
      <td className="align-right numeric">{formatMoney(r.amount)}</td>
    </tr>)}</tbody>
    <tfoot><tr><td>合计</td><td className="align-right numeric">{formatMoney(total)}</td></tr></tfoot>
  </table>
</div>
```

- 必须放在 `.table-scroll` 中；移动端最小宽度 680px（Dashboard 860px），允许横向滚动。
- 数字列 `align-right numeric`；金额不省略小数点造成口径不一致。
- 空数据用 `EmptyState`；加载用 `LoadingBlock`；错误用 `ErrorBlock`。

### 3.2 SelectField

```tsx
<SelectField value={status} onChange={(e) => setStatus(e.target.value)} aria-label="项目状态">
  <option value="ALL">全部状态</option>
  <option value="CONSTRUCTION">施工中</option>
</SelectField>
```

- 自带键盘：上下、回车、Esc、搜索（>7 项）。
- 打开时触发器底部出现朱砂手写下划线；选中项朱砂勾。
- 不要用原生 `<select>` 直接替代（项目上下文条除外，使用紧凑样式）。

### 3.3 DatePicker

```tsx
<DatePicker value={date} onChange={setDate} aria-label="选择日期" />
```

- 选中日：朱砂手绘圈；今日：铜点；支持上月/下月/今天/清除。
- 不允许只做“样式日期”，必须真实过滤/提交。

### 3.4 Checkbox

```tsx
<label className="checkbox-line"><input type="checkbox" checked={checked} onChange={...} />纳入汇总</label>
```

- 全局 `input[type=checkbox]` 已统一为方框 + 手写勾；选中是淡朱砂底。
- 勾选表示“选择/纳入”，不表示“审批通过”；审批状态用 StatusBadge。

## 4. 浮层与反馈

### 4.1 Dialog

```tsx
<div className="modal-backdrop" role="presentation">
  <section className="dialog" role="dialog" aria-modal="true" aria-labelledby="dialog-title">
    <div className="dialog-header"><h2 id="dialog-title">新增清单项</h2><p>金额单位：元</p></div>
    <form>…</form>
    <div className="dialog-footer"><Button variant="secondary">取消</Button><Button>保存</Button></div>
  </section>
</div>
```

必须：role、aria-modal、aria-labelledby、Esc 关闭、焦点陷阱、关闭后焦点归位。大表单用 `.dialog-wide`（760px）。

### 4.2 EmptyState / LoadingBlock / ErrorBlock

```tsx
<EmptyState title="还没有实际成本记录" description="可以先录入人工费或材料采购费用。" action={() => setOpen(true)} />
<LoadingBlock label="正在汇总…" />
<ErrorBlock message={message} retry={refetch} />
```

- 空态不画插画；44px 圆框 + 衬线标题 + 可执行说明。
- 加载超过 300ms 才显示；错误必须给重试。

### 4.3 Toast / 成功提示

当前使用页面内 `.success-notice` / `.form-alert`（左侧 2px 铜线/朱砂线）。后续可抽成 Toast，但不得使用彩色大卡片。


### 4.4 ConfirmDialog / FocusTrap

```tsx
import { confirmAction, promptAction, confirmThen } from '../components/ConfirmDialog';

// 行内简单确认
confirmThen('确定归档这条成本记录吗？', () => archive.mutate(id), {
  title: '归档成本记录', tone: 'danger', confirmText: '归档',
});

// async handler
if (!(await confirmAction({ title: '确认过账', description: '过账后须通过调整单更正。', tone: 'danger', confirmText: '确认过账' }))) return;

// 需要填写原因
const reason = await promptAction({
  title: '退回结算单', description: '请填写退回原因，至少 3 个字符。',
  inputLabel: '退回原因', minLength: 3, multiline: true, tone: 'danger', confirmText: '退回',
});
```

- `ConfirmHost` 在 `Layout` 挂载一次；不要在页面里重复挂载。
- 弹窗必须有 `role="dialog"`、`aria-modal`、标题/描述关联；危险确认的取消按钮默认聚焦。
- `FocusTrap` 全局接管：Tab/Shift+Tab 循环、背景 `inert`、Esc、关闭后焦点归位；日期/下拉 portal 自动纳入循环。
- 不要再使用 `window.confirm` / `window.prompt`；CI 已检查。

## 5. 壳组件

### 5.1 BrandMark（印章）

```tsx
<BrandMark />
```

- 42×42；朱砂方框 + 粗糙边缘（feTurbulence + feDisplacementMap）+ 白色“墨”。
- 只用于品牌位；不用于按钮图标。
- 毛笔字“墨衡”由 `.brand-word strong` 使用 Ma Shan Zheng，30px。

### 5.2 AppShell / Sidebar

- 224px；折叠 62px；移动端 248px 抽屉。
- 侧栏与主区同一张纸；3px 墨脊 + 1px 铜折线 + 18px 折影。
- 当前项：纸色底 + 2px 墨色左线；不要用蓝色胶囊。

### 5.3 CostWorkspaceTabs

- 单行横向滚动；当前 tab 朱砂双圈；移动端自动把当前 tab 滚到中间。
- 分组之间用 1px 竖线；不使用彩色分组背景。
- 助手 tab 仅在服务端启用时出现。

### 5.4 CommandPalette / QuickActions / AccountMenu

- 纸面浮层；衬线标题；隐藏英文 kicker。
- 键盘：↑↓ 选择、↵ 打开、Esc 关闭；结果分组“项目直达/业务页面”。

## 7. Do / Don't

| Do | Don't |
| --- | --- |
| 用线和对齐建立层级 | 用阴影、渐变、大圆角堆卡片 |
| 一屏一个主按钮 | 七个同权重按钮并排 |
| 金额右对齐、等宽数字 | 金额居中/截断 |
| 朱批只做批注 | 朱批做普通按钮/成功色 |
| 中文标题 + 口径说明 | 英文 eyebrow + 营销句 |
| 移动端横向滚动表格 | 把项目名压成竖排 |
| 真实下拉/日期/排序 | 只做视觉假交互 |
