# 墨衡 v2.7.0-rc.1 阶段验收记录

- 基线：`v2.6.0-rc.1`
- 候选：`v2.7.0-rc.1`
- 性质：源码增量修复与静态候选检查，不等于生产验收签字

## 1. 本轮修改

1. 修复报表预览的返回导航。项目驾驶舱/往来单位档案快捷自动预览携带源路由，并用 `replace` 替换中间的 `autoPreview=1` 工作室路由；手动从工作室预览时返回到已保存模板对应的干净编辑路由；标准台账、报表中心和旧版设计器预览均记录返回目标。直接打开 URL 或刷新时使用路径校验后的 `returnTo`，默认回报表中心。
2. 排查全仓 history back 调用：业务页面中没有其他裸历史回退；仅保留预览页面中的一个受控 `navigate(-1)`，而且只有入口 state 明确标记来源有效时才使用，否则走安全内部路径。
3. 项目驾驶舱月度实际成本图将 ECharts grid 左边距由 44 增至 68，启用 `containLabel` 和标签边距，长金额用千分位或万/亿单位显示。
4. 项目工作台导航删除可见“项目管理”组名，保留组的语义 aria-label、视觉底色和分隔线。
5. `report-studio-xlsx.ts` 的局部字体构造类型由 `ExcelJS.Font` 调整为 `Partial<ExcelJS.Font>`。
6. 不修改 Prisma Schema、数据库迁移、财务规则或正式业务 API 数据契约。

## 3. 尚未实测

当前工具环境使用 Node.js 22.16.0，项目要求 Node.js 24+，且工作区未安装完整依赖。本轮不能在当前环境完成完整 `npm run lint`、生产 build、`npm test` 或浏览器 E2E。因此仍须在完整依赖的 Node.js 24+ 环境执行：

- `npm ci`、`npm run lint`、`npm run build`、`npm test`；
- 从项目驾驶舱/往来单位/工作台/报表中心分别进入预览并验证返回行为，特别确认无 auto-preview loop；
- 以不同长度的金额标签在宽屏及窄屏检查驾驶舱图表轴标签不被裁切；
- 验证 XLSX 渲染模块的 ExcelJS 类型与输出样式。

本版本仍是 RC，不应将静态候选检查描述为完整构建或真实浏览器验收通过。
