# 窗口控制区与顶栏真实归属：纠正我三个错误

日期：2026-10-24

## 三个错误

### 错误一：把窗口控制按钮当成了卡片按钮

我上一轮说「Hana 卡头有 4 个按钮（＋ ⋯ − ×），moheng 只有 3 个」，这是**看错了归属**。

那 4 个按钮里，**`−` 和 `×` 是窗口控制按钮**，不属于卡片。

真实结构：

```
窗口级（fixed 定位）
├─ _trafficStrip_e117f        左上角（侧栏开关等）
└─ _windowControlsIsland_5f7ae 右上角（最小化 / 最大化 / 关闭）

卡片级（卡头 titlebar-right）
├─ 面板按钮（order 10 / 20 / 25 / 30）
└─ 系统按钮（order 9000+：收藏 / 截图 / 导出 / 最小化 / 全屏 / 关闭）
```

**`Ua` 常量表证明这一点**：

```js
const Ua = {
  dockBack: -1000, pin: -990,
  favorite: 9000, favoriteStar: 9001, screenshot: 9002,
  export: 9005, minimize: 9008, fullScreen: 9009, close: 9010,
};
```

`minimize` / `close` 是**卡片级系统按钮**（只在卡片 `closable: true` 时出现），不是窗口控制。

### 错误二：主内容区顶栏没有左岛

我上一轮造了 `.titlebar-island-left`，这是错的。

**Hana 的 chat 卡片顶栏只有右岛**：

```js
[u4]: {
  titleKey: "chalkboard.tile.chat",
  surface: "bare",          // ← 无卡片边框，内容直接铺在画布上
  bleed: true,
  titlebarMode: "solid",
  titlebar: { customSegment: jHe },
  closable: false,          // ← 不可关闭，所以没有 × 按钮
  detachable: false,
  chrome: cit,              // ← 只有面板按钮 + 菜单，全在 titlebar-right
}
```

`cit` 里所有 chrome 的 `slot` 都是 `"titlebar-right"`：

```js
preview:   { slot: "titlebar-right", order: 10 }
workspace: { slot: "titlebar-right", order: 20 }
browser:   { slot: "titlebar-right", order: 25 }
panel-menu:{ slot: "titlebar-right", order: 30 }
```

`rve` 的渲染逻辑：

```jsx
function TitlebarFrame({ left, right, renderAction, titleSegment }) {
  const hasLeft = left.length > 0 || titleSegment != null;
  return (
    <div className={titlebarFrame} data-islands={hasLeft ? "both" : "right"}>
      {hasLeft && <div data-titlebar-slot="left">…</div>}
      <div data-titlebar-slot="right">…</div>
    </div>
  );
}
```

**chat 卡片的 `left` 是空数组，所以 `data-islands="right"`，只有右岛。**

### 错误三：预览卡和笺是两个不同功能

- **预览卡**（`By`）：`surface: "card"`，`closable: true`，渲染 PDF / Markdown / 媒体
- **笺**（`_jianDrawer`）：笔记抽屉，暖米色 `#FAF0E2`，只有开/合两态

我把「预览」标题改成「笺」是错的，两者不该混。

## 「关闭按钮主动让位」的算法

```js
// 测量：卡片右缘到窗口控制区左缘的距离
function wot(cardRect, wcRect) {
  const overlapY = cardRect.top < wcRect.bottom && cardRect.top + 44 > wcRect.top;
  const overlapX = cardRect.left < wcRect.right && cardRect.right > wcRect.left;
  if (!overlapY || !overlapX) return null;         // 没重叠就不用让
  return Math.max(0, Math.round(cardRect.right - (wcRect.left - 4)));   // 4px 间隙
}

// 左让位（trafficStrip）
```

`Sot` 的测量细节：

```js
function measure(cardEl) {
  const strip = stripRegistry.get(document);       // trafficStrip
  const wc = windowControlsRegistry.get(document); // windowControlsIsland
  const cardRect = cardEl.getBoundingClientRect();
  if (cardRect.width === 0) return "pending";

  let left = null, right = null;
  if (strip) {
    const d = strip.getBoundingClientRect();
    let contentRight = d.left;
    for (const child of strip.children) contentRight = Math.max(contentRight, child.getBoundingClientRect().right);
    left = vot(cardRect, d, contentRight);
  }
  if (wc) {
    right = wot(cardRect, wc.getBoundingClientRect());
  }
  return { clearance: { left, right }, signature: … };
}
```

**关键：它是运行时测量，不是写死的 padding。**

## 我该改成什么

### 1. 删掉左岛

`.titlebar-island-left` 是我造的。Hana 的 chat 卡片顶栏只有右岛。

正确做法：

```jsx
<header className="app-titlebar" data-titlebar-frame data-islands="right">
  {/* 没有左岛 */}
  <div className="titlebar-island titlebar-island-right" data-titlebar-slot="right">
    {/* 面板按钮 + 菜单 + moheng 系统按钮 */}
  </div>
</header>
```

面板按钮和系统按钮**在同一个右岛里**，靠 order 排序（面板 10/20/30，系统 9000+）。

### 2. 把 moheng 的 5 个系统按钮移到窗口控制区

按你说的：「用户按钮、快捷操作、全局搜索、待办预警、界面设置」放到窗口控制那几个按钮的位置。

即：新建一个 `.window-controls-island`（fixed 定位右上角），里面放：

```
搜索 / 待办 / 助手 / 快捷 / 设置 / 头像 + 最小化 / 最大化 / 关闭
```

### 3. 关闭按钮让位

卡片右缘与窗口控制区重叠时，顶栏内容右 padding = `cardRect.right - (wcRect.left - 4)`。

用 ResizeObserver 测量，不写死。

### 4. 卡头按钮按 `closable` 决定

```js
closable: false  →  不渲染 × 按钮（chat 卡片就是这种）
closable: true   →  渲染 × 按钮（preview 卡片）
```

moheng 的「文件」卡对应 chat（不该有关闭按钮），「预览」卡对应 preview（该有）。
