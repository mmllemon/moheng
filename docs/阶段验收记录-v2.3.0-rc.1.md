# 墨衡 v2.3.0-rc.1 阶段验收记录

- 基线：`v2.2.0-rc.1`
- 候选：`v2.3.0-rc.1`
- 日期：2026-10-15
- 性质：源码增量修复与静态架构候选检查，不是生产发布验收。

## 1. 本轮源码修改

### PostgreSQL 后台任务队列

- 新增 `BackgroundJob` / `BackgroundJobStatus` 模型及迁移 `20261015020000_postgresql_background_jobs`；旧迁移保持不变。
- 通过 PostgreSQL `FOR UPDATE SKIP LOCKED` 在事务中领取任务，增加租约、心跳、最大尝试次数、指数退避、过期租约恢复和结果文件保留清理。
- 新增稳定 handler 注册表，首个任务类型是 `report.xlsx.export`。
- 新增异步 XLSX 提交、状态查询和下载 API；保留现有同步 XLSX 和 CSV API，避免破坏既有调用方。
- 支持按用户作用域的幂等键和请求 hash；执行时复核用户状态、当前项目访问权限和模板读取权限。
- 输出文件名为任务 ID 派生值，路径保存在服务端受控目录，不向浏览器暴露物理路径。
- 默认由 API 进程内 worker 执行，不新增 Redis/RabbitMQ/Kafka。增加独立 worker 入口与可选 Docker Compose profile，未来可隔离 CPU/内存负载。

### TypeScript 构建缺陷

按所提供的 74 条报错/21 个根因汇总，进行了以下源代码修复：

- 正则捕获组、数组索引、日期 split 解构和映射表查询增加显式类型保护，保留 `noUncheckedIndexedAccess: true`。
- 补入分供合同缺失的 `calculateEffectiveContractAmount` 导入。
- 将进度款的金额转换完整改成 `bigint` 分单位链路，避免 `number` 与 `bigint` 混用以及二次 `.toFixed()`；业主侧金额字符串不再调用 `.toFixed()`；Decimal 比较改用精确分单位转换。
- 审计 JSON 在 Prisma 持久化边界序列化并收窄为 Prisma JSON 类型。
- 明确业务单位汇总 `reduce<number>` 类型；联合类型分支进行值存在检查；错误映射解构先检查查询结果。
- ExcelJS 的纸张代码采用类型兼容边界；ExcelJS 与新式 Node Buffer 泛型之间使用 `xlsx.load` 参数类型作为显式兼容边界。
- React/Lucide 图标类型对齐，`Button` 暴露现有 `.button-small` 样式对应的 `size` 属性，React 19 的需写 `current` ref 显式声明可变 nullable 类型；补导入 hooks、补足前端类型字段并明确空预览分支。
- 旧主题偏好类型显式兼容 `light`/`dark` 并先解析后映射，避免 TypeScript 错误窄化。

## 3. 本轮环境限制

- 当前可用环境为 Node.js 22.x，低于项目 `engines.node >=24.0.0` 的要求。
- 项目依赖安装尝试未能在当前环境完成；因此未能声称完整运行 `tsc -p apps/api/tsconfig.json --noEmit`、`tsc -b --noEmit`、Prisma Client 生成、前后端 production build、API 单元测试或 PostgreSQL 迁移成功。
- 尚未运行 PostgreSQL 16 上的并发领取/租约恢复/失败重试/幂等键冲突/文件过期联测，也未实测 Windows、浏览器、Excel 或 WPS。
- 当前没有据本轮生成 `package-lock.json`；发布前必须在 Node.js 24+、可以访问 npm registry 的干净环境中生成和审查锁文件后使用 `npm ci`。不能把锁文件或完整构建标记为已完成。

## 4. 正式发布前阻塞 Gate

1. Node.js 24+ 干净安装、锁文件、严格类型检查、lint、build 和完整测试。
2. 在 PostgreSQL 16 测试副本运行 `prisma validate/generate` 和 `prisma migrate deploy`，确认新迁移无误且旧迁移不变。
3. 后台队列集成测试：两个 worker 同时领取、任务进程中断后重新领取、最大重试次数、幂等键重复/冲突、项目权限撤销、过期结果下载与清理、文件目录 ACL。
4. 真实浏览器异步 XLSX 导出全流程；Excel/WPS 文件打开、打印和复杂工作簿回归。
5. 合同金额、外部确认状态、结算差额、业主/分供应收应付、到账退款冲销和审计规则的完整数据库回归。

在 Gate 全部完成前，本版本保持 `v2.3.0-rc.1`，不得标记为生产验收通过。
